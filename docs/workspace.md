# 工作区操作

启动 worldedit 时传入目录，或在目录选择框中选择目录。空目录会创建雾港示例；已有作品根目录须有 world.wl。新建世界先选择空目录。Ctrl+O 选择工作区，切换或关闭时有未保存修改会提示。

全部子目录递归发现 `.wl`，编辑器搜索与对象分析包含未 include 的源码。include 可以控制显式加载顺序。其他文件作为工程内容保留，导出不只打包被引用的附件。目录层级由作者自由组织，目录名不改变对象 ID。

桌面每秒检查目录变化。新增、删除与磁盘修改会更新源码和分析；编辑器内未保存的同文件修改保留，外部变化造成冲突时显示路径并阻止覆盖保存。冲突后可先另存一个完整副本，再合并原文件并重新载入。外部源码刷新会清除旧撤销记录，避免恢复过期版本；新版本的试玩应重新开始。打开中的旧表单保留输入，但外部源码改变后会阻止提交；请复制需保留的输入，再关闭并重开表单合并。

文件、include、图片、音频与其他附件必须在工作区内。选择外部附件时操作失败，应先通过文件管理器复制进去。程序禁止绝对引用、跨根目录路径、符号链接和 Windows 目录联接。兄弟子目录间的相对引用可以使用 `../`。

保存只写源码缓冲。另存保留所有文件并切换到新目录；导出校验作品后写入新目录，原工作区保持不变。两者目标须在当前工作区外且不存在。导出保留 `.agent`、README、子目录附件和未引用资料；不会重命名附件或覆盖用户说明。无事件的纯设定工程可保存和另存，但当前运行型导出仍要求至少一个事件。

浏览器从完整目录或 ZIP 导入工作区快照，磁盘外部变化需重新导入，保存下载完整工程 ZIP 并尝试浏览器本地备份。ZIP 上限 4096 个文件、64 MiB；浏览器存储配额可能更小。快照不是实时目录挂载。目录规范的唯一真源在同级 worldline/spec/workspace.md。
