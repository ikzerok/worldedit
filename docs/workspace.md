# 工作区操作

0.13的[稳定ID逐处预览](safe-id-refactor.md)和[查找返回上下文](search-author-context.md)保留普通文字与未应用稿。既有0.12时间前驱编辑、两条路径重放与应用/保存步骤见[时间约束与可信重放](replay-timeline-workflow.md)。

启动 worldedit 时传入目录，或在目录选择框中选择目录。空目录会创建空白世界，不再自动写入雾港示例；已有作品根目录须有 world.wl。新建世界先选择空目录，再按需添加内容。Ctrl+O 选择工作区，切换或关闭时有未保存修改会提示。

全部子目录递归发现 `.wl`，编辑器搜索与对象分析包含未 include 的源码。include 可以控制显式加载顺序。其他文件作为工程内容保留，导出不只打包被引用的附件。目录层级由作者自由组织，目录名不改变对象 ID。

语言版本由 `.world/project.json` 的 `language_version` 明确选择；未配置的旧工程继续使用1.9。使用 `entity` 声明的作品须显式选择1.10或更高支持版本，编辑器底部显示当前工程版本，源码高亮遵循该版本。实体可以经搜索、地图资料入口和源码定位阅读；分类、说明及属性来自 core 目录。实体与同名人物/标签保持独立身份，不会因名字相同而合并。实体资料已有独立创作表单，也可通过源文件编辑；持续字段约束见下文schema工作台。

1.10 的 `relation_type` 和 `relation_def` 声明也采用版本化高亮。独立关系资料页显示核心目录中的类型、方向、反向读取名称、两端对象、说明、来源、作者范围和属性；点击端点进入同一个资料阅读窗口。地图标记可引用 `relation` 稳定 ID，打开关系资料不会创建反向关系或修改源码。独立关系表单和局部世界关联界面共用core；既有“事件关系图”仍表示事件控制流。

桌面每秒检查目录变化。新增、删除与磁盘修改会更新源码和分析；编辑器内未保存的同文件修改保留，外部变化造成冲突时显示路径并阻止覆盖保存。冲突后可先另存一个完整副本，再合并原文件并重新载入。外部源码刷新会清除旧撤销记录，避免恢复过期版本；新版本的试玩应重新开始。打开中的旧表单保留输入，但外部源码改变后会阻止提交；请复制需保留的输入，再关闭并重开表单合并。

文件、include、图片、音频与其他附件必须在工作区内。选择外部附件时操作失败，应先通过文件管理器复制进去。程序禁止绝对引用、跨根目录路径、符号链接和 Windows 目录联接。兄弟子目录间的相对引用可以使用 `../`。

保存写入当前源码缓冲和已注册展示文档；普通 JSON、附件和未注册文件按原工作区内容保留。另存保留所有文件并切换到新目录；导出校验作品后写入新目录，原工作区保持不变。两者目标须在当前工作区外且不存在。导出保留 `.agent`、README、子目录附件和未引用资料；不会重命名附件或覆盖用户说明。纯内容工程可以完整导出；只有启动试玩需要可用入口。

浏览器从完整目录或 ZIP 导入工作区快照，磁盘外部变化需重新导入，保存下载完整工程 ZIP 并尝试浏览器本地备份。ZIP 上限 4096 个文件、64 MiB；浏览器存储配额可能更小。快照不是实时目录挂载。目录规范的唯一真源在同级 worldline/spec/workspace.md。

浏览器保存使用 core 当前缓冲生成完整文件快照：`.world/project.json`、已注册展示 JSON、未注册 JSON、源码和附件都按原始字节进入包；旧版 `worldedit-project.json` 只记录浏览器入口，不替代新清单。两个入口记录不一致时拒绝导入或保存。`.world/.transactions` 是保存暂存区，不进入工程包；发现未解决事务时拒绝打包。下载请求记录 `last_export_revision`，localStorage 写入成功才推进 `local_snapshot_revision` 和保存基线，配额失败保留脏状态。

目录、桌面 ZIP 与浏览器严格 ZIP 导出共用“已应用工程快照”确认。只要仍有未应用的正文、资料表单、schema、书稿编排、地图、本地化或导入等创作输入，就按种类与来源列出；可返回对应页面处理、取消，或明确继续导出已应用版。已应用但尚未保存的工程修改会进入副本，列出的未应用输入不会进入副本。导出从不自动应用、清空草稿或推进当前工程的保存状态；确认时重新扫描输入。完整副本仍保留未引用附件、未知普通文件和已注册展示文档，并沿用错误、恢复事务、目标已存在及工作区越界的严格拒绝边界。已有外部冲突仍可沿用救援副本路径导出本地缓冲，但不解除冲突或覆盖原盘。

桌面“导出 ZIP 工程包…”先打开应用内目标路径决定点，与目录导出一致。可以直接输入 ZIP 文件的绝对完整路径（相对路径会拒绝）；预填路径仅是建议，不会自动写入。也可点“系统选择器（可选）”挑选目标；系统选择器取消或未返回结果时，保留已填路径且不触发导出。只有点击“校验并导出”才进入共用未应用输入确认，仍有未应用输入时还须明确继续。范围确认中可“修改目标路径”返回改正；任一决定点取消都不写出文件，不清空创作草稿；换工作区会关闭旧的目标与范围确认。

ZIP使用严格导出内容写入新文件；目标必须在当前工作区外，已有文件拒绝覆盖，写入失败不改变工程保存状态。核心错误、只读能力和恢复事务等既有校验不放宽。桌面 ZIP 可直接在浏览器中打开，浏览器保存仍会下载同一格式的完整快照。

发现外部冲突时，工程菜单或错误提示中的“查看冲突差异”会打开只读快照，分别显示保存基线、本地缓冲和磁盘版本。删除或尚不存在的一方标为缺失，无法按 UTF-8 解码的展示文档保留并显示原始字节提示。快照不会覆盖或合并文件；关闭窗口后再次打开冲突查看，才会重新读取当前磁盘内容。需要保留本地稿时使用既有另存副本路径，再人工合并。

## 公开资料字段

“发布给读者”先选择对象，再逐项勾选要公开的属性。字段默认不选，“选择全部资料”也不会选中属性。
预览列出实际生成的每页内容，空正文显示警告；所有页面均可展开核对，修改字段或源码后须重新预览。
引用字段的目标未另外公开时只显示“未公开内容”。人物台词只公开正文，不自动显示说话者身份或演出备注。
这是离线包选择，拿到包的人可以阅读包内全部内容；完整工程 ZIP 仍保留所有作者资料。

## 0.9 连续写作

- 资料索引中的“持续资料约束”打开 schema 源码工作台。显式语言1.12方可编辑；编辑完整源码后先“预览约束影响”，核对稳定字段身份与受影响实例，再应用。取消预览不改工程，关闭窗口保留未应用输入。应用只改内存、一次可撤销；源码草稿允许有诊断，发布前必须修复。旧模板不自动升级为 schema。
- 选择卡片的“可见但禁用”把显示条件与可选条件分开：旧显示条件不成立仍隐藏；新可选条件不成立则显示不可点的选项及作者写的静态说明。仅显式1.12启用，说明不求值，全部锁定时继续组后内容。试玩使用运行时提供的可选状态，不由UI猜测条件。
- 阅读预览默认当前章节；“整书”明确扩展到书稿顺序。宽屏为编辑/预览分别分配空间并独立滚动，窄屏使用编辑/预览标签。有效未应用稿由core只读编译；无效或冲突稿显示“预览过期”，同目标上次有效投影有明确标识，输入不会丢失。预览不执行故事、不消耗随机数、不应用或保存。
- 专注模式保留章节身份、写作/结构/源码、草稿状态与主动作，“书稿管理”渐进展开编排、完整路径和说明；继续支持双参考、字号/行距、明暗主题和个人布局恢复。

本地化仍是白名单文本交换，交换成功不是全作品已译，也不表示runtime已切换语言。禁用说明不自动加入交换包。Linux原生与AI模拟验收仅说明已执行的Linux范围；Windows/macOS原生交互、物理IME和屏幕阅读器未执行时不得称已通过。Web仍是导入快照，不持续监视磁盘。

## 当前稿查找、替换与编辑命令

“编辑”菜单统一提供当前稿查找（Ctrl/Cmd+F）、工程查找（Ctrl/Cmd+Shift+F）、正文替换（Linux/Windows 为 Ctrl+H，macOS 为 Cmd+Alt+F）、撤销和重做。工程查找包含未应用的书稿 WritingBuffer，同文件被多章引用只搜一次；未修改的旧缓冲不会遮盖最新工程内容。查找窗口提供当前文稿、打开时捕获的选区、工程文件清单，支持字面量、大小写、整词、首次 Enter 定位已选首项，其后 Enter 下一处与 Shift+Enter 上一处。Unicode 整词按字母数字和下划线的边界判断，连续中文作为一个词；不做正则或语言特定分词。

默认正文范围保护稳定 ID、声明、引用、内插、链接和行标记。打开“源码”可查这些内容，但包含保护 token 的替换会明确拒绝；对象身份请用重命名。替换只接受普通正文文字，不引入换行、引号、转义或新语法；锁定选项的 disabled 静态说明也可替换，其中花括号和链接外形保留纯文字语义。预览显示具体文件、次数、修改前后内容；更改范围、选项、工程或草稿后须重新预览。无效、无法安全识别的片段仍可源码查找，不能强行批量替换。

当前书稿替换留在其未应用草稿中。跨文件确认应用把清单中命中文件的当前稿一起提交为一个可撤销工程事务，不保存磁盘。取消和关闭零修改。撤销跨文件替换也恢复此前未应用草稿；后续输入冲突时拒绝覆盖。只读、未知能力、外部磁盘变化和过期基线均不能应用替换。

输入框内 Ctrl/Cmd+Z 使用当前输入的局部撤销，离开输入框使用工程或当前稿替换事务；重做为 Ctrl/Cmd+Shift+Z，非输入上下文也接受 Ctrl+Y。Escape 按打开层级仅收起最上层临时搜索、命令、设置或选择入口，并将焦点交回相应编辑区；已确认的查找导航不会因关闭而撤回，回原作者位置使用“返回”；下层无论是干净或脏的资料表单都不会阻止上层无损关闭，也不会被关闭或改写。新打开的复杂表单位于临时层上方时，仍须使用其明确取消或应用操作；嵌套临时层逐层退出，窗口关闭按钮与 Enter 的既有操作保持一致。输入法候选和组合的 Escape / Enter 优先交由输入法，不触发临时层操作；输入法组合期间不会截获查找和撤销快捷键。Linux 自动键盘回归不代表真实 macOS、Windows、物理输入法或读屏认证。

正文工作区的完整来源路径保留在悬停提示中；长路径在行内截断，不通过多行换行把窄窗正文挤出首屏。

## 就地批注与修订清单（0.11）

正文的写作/结构/源码模式和源文件页可从当前选区“添加批注”。预览显示真实相对路径、行范围与原文；v1 批注覆盖完整行，局部字符选区会明确扩大为所在行。未应用稿或过期选区不会悄悄锚定旧版本：先由作者应用对应文件，再重新选择；入口不自动应用或保存。

协作审阅提供未解决/全部/已解决、锚定状态与正文/作者/ID搜索，显示总数与命中数；列表独立滚动，键盘当前行跟随进入视野。解决和失锚是两个维度，失锚保留原quote，不能自动找相似段落；回原文只使用准确来源。统一待办另有全部未解决批注入口，原有失锚待办含义不变。

批注修改未应用时，重开同条、选另一条、新建、改筛选、关闭或离页均保留输入并给出取消/明确仅放弃该批注的选择。保存失败与外部变化不会丢输入，旧基线禁止覆盖。只读/未知文档不可写，扩展字段往返保留；批注不改变试玩指纹，公开读者包不携带讨论。
