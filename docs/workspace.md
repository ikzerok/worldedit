# 工作区操作

启动 worldedit 时传入目录，或在目录选择框中选择目录。空目录会创建雾港示例；已有作品根目录须有 world.wl。新建世界先选择空目录。Ctrl+O 选择工作区，切换或关闭时有未保存修改会提示。

全部子目录递归发现 `.wl`，编辑器搜索与对象分析包含未 include 的源码。include 可以控制显式加载顺序。其他文件作为工程内容保留，导出不只打包被引用的附件。目录层级由作者自由组织，目录名不改变对象 ID。

桌面每秒检查目录变化。新增、删除与磁盘修改会更新源码和分析；编辑器内未保存的同文件修改保留，外部变化造成冲突时显示路径并阻止覆盖保存。冲突后可先另存一个完整副本，再合并原文件并重新载入。外部源码刷新会清除旧撤销记录，避免恢复过期版本；新版本的试玩应重新开始。打开中的旧表单保留输入，但外部源码改变后会阻止提交；请复制需保留的输入，再关闭并重开表单合并。

文件、include、图片、音频与其他附件必须在工作区内。选择外部附件时操作失败，应先通过文件管理器复制进去。程序禁止绝对引用、跨根目录路径、符号链接和 Windows 目录联接。兄弟子目录间的相对引用可以使用 `../`。

保存写入当前源码缓冲和已注册展示文档；普通 JSON、附件和未注册文件按原工作区内容保留。另存保留所有文件并切换到新目录；导出校验作品后写入新目录，原工作区保持不变。两者目标须在当前工作区外且不存在。导出保留 `.agent`、README、子目录附件和未引用资料；不会重命名附件或覆盖用户说明。纯内容工程可以完整导出；只有启动试玩需要可用入口。

浏览器从完整目录或 ZIP 导入工作区快照，磁盘外部变化需重新导入，保存下载完整工程 ZIP 并尝试浏览器本地备份。ZIP 上限 4096 个文件、64 MiB；浏览器存储配额可能更小。快照不是实时目录挂载。目录规范的唯一真源在同级 worldline/spec/workspace.md。

浏览器保存使用 core 当前缓冲生成完整文件快照：`.world/project.json`、已注册展示 JSON、未注册 JSON、源码和附件都按原始字节进入包；旧版 `worldedit-project.json` 只记录浏览器入口，不替代新清单。两个入口记录不一致时拒绝导入或保存。`.world/.transactions` 是保存暂存区，不进入工程包；发现未解决事务时拒绝打包。下载请求记录 `last_export_revision`，localStorage 写入成功才推进 `local_snapshot_revision` 和保存基线，配额失败保留脏状态。

桌面“导出 ZIP 工程包…”使用严格导出内容写入新 ZIP；目标必须在当前工作区外，已有文件拒绝覆盖，写入失败不改变工程保存状态。桌面 ZIP 可直接在浏览器中打开，浏览器保存仍会下载同一格式的完整快照。

发现外部冲突时，工程菜单或错误提示中的“查看冲突差异”会打开只读快照，分别显示保存基线、本地缓冲和磁盘版本。删除或尚不存在的一方标为缺失，无法按 UTF-8 解码的展示文档保留并显示原始字节提示。快照不会覆盖或合并文件；关闭窗口后再次打开冲突查看，才会重新读取当前磁盘内容。需要保留本地稿时使用既有另存副本路径，再人工合并。
