# 源码自动换行与位置保持

状态：v0.18 B 实施规范，2026-10-03 冻结；测试结果另记，本文不等于已验收。

## 作者选项与兼容

- “视图”和“阅读与外观 · 仅此设备”提供同一个“源码自动换行”开关。
- 默认关闭，保持旧版横向滚动习惯；开启后按源码编辑区实际可用宽度折行。偏好随现有设备个人设置保存，重启恢复；旧版设置缺此字段时仍关闭。
- 此项只适用于可编辑 `.wl` 源码，不把书稿阅读宽度强套到 JSON、地图或其它编辑器。关闭时继续双向滚动，开启时正文不要求横向滚动。
- 只改变高亮 galley 的排版宽度，不插入换行，不格式化 DSL，不调用保存或应用；源码字节、dirty 状态和撤销历史不能因开关、字号、行距或面板缩放改变。

## 坐标与上下文

- UTF-8 字节位置、Unicode 字符光标和逻辑行/列保持原有合同；视觉折行不生成新逻辑行。
- gutter 继续沿用 galley 的物理 newline 标志，只在物理行首显示行号；不以固定行高估算。行号字号与正文一致。
- 高亮 layouter 使用 TextEdit 传入的真实宽度，并扣除布局已分配的 gutter、间距及编辑器内边距；长 ASCII、中文、emoji、内插和链接均允许视觉折行。
- 显示宽度、字号、行距或自动换行改变时，不改变字符选区及方向。优先保持原可见光标的位置；光标原本不在视口中时保持视口的逻辑字符锚点，不突然跳回光标。
- 搜索命中、源码引用弹层与诊断定位使用当前真实 galley 的字符坐标。显式跳转/搜索优先于旧视口保持；不以旧像素、固定行高或字节列代替新排版坐标。
- Back 保留原来源基线检查：来源没变才恢复光标/选区。布局没变时保持原像素滚动；布局已改变时用逻辑锚点重算。失效来源不恢复旧锚点，不覆盖当前草稿。
- 个人位置可保存不含正文的逻辑显示锚点；旧位置缺锚点时仍兼容。IME 与未应用草稿保护保持既有规则；换行选项不提交、删除或改写草稿。
- 问题工作台打开文档级来源后，Back也保留有效UTF-8展示文档的真实原文基线、独立编辑器选区和滚动；未知格式继续只读。坏UTF-8只保留原始字节，不从lossy预览建立基线或字符坐标。此项不把源码软换行扩到JSON。

## 边界

不新增语言解析、全局 Forward/MRU、源码格式化或外部资源读取。core 报告的位置有效性由 core 决定；源码渲染不把无效诊断位置伪装成精确定位。

## 验收合同

1. 同一段包含 3000+ 中文字符、emoji、`${...}`、链接及无空格长 ASCII；混合空行、尾 newline 与 CRLF。窄/宽编辑区和 16/28 字号开关往返，源字节完全一致，视觉行确实增加且逻辑行号不变。
2. 真实 egui 帧中保留双端选区及方向、可见字符锚点；调窗口/面板宽度、字号、行距和开关后选区仍指向相同原文。
3. 搜索定位、诊断/来源跳转、主位置→相关位置→Back 在折行后落在当前 galley 正确位置；返回原稿不丢选区、滚动上下文及未保存内容。
4. 旧个人配置能读取；新开关序列化/恢复为原选择，不写入作品。来源基线变化仍拒绝旧位置。
5. 重复切换、失焦、IME 组合草稿、外部变化和 Back 的现有回归仍通过。
6. 自动单元/真实 egui frame 验证与独立 native GUI 验收分开记录。系统 IME、平台、高 DPI 或读屏未实测时明确列为未测，不用 frame 测试替代。

## 独立 native 操作步骤

在本轮隔离的新作品中打开长源码；先记录未保存内容及选区，再从“视图”开启“源码自动换行”。缩放窗口与问题/参考面板，在 16/28 字号间切换，检查 gutter、选区及当前段落。搜索段落尾的中文/emoji/链接；跳一个主位置与关联位置，然后 Alt+← 返回，确认原选区和上下文。关闭/重开隔离实例确认开关保留，比较工作区字节与 dirty 状态。不要借用旧窗口、旧草稿或浏览器 file/loopback 绕行。
