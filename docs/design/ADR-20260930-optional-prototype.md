# ADR：修改后采用可选原型，继续试验

关联：#31、#42、#43。

## 决定

采用修改后的原型作为明确开启的可选实验入口，继续试验，不替换默认编辑器。默认生产工作流保留，不迁移既有作品，不打开真实用户工程，不持久化实验布局与输入草稿。

两个虚构内存 Project 中，J1 接真实 core 展示命令与撤销，J3 接真实 Story，J4 接真实三方比较预览。J2 保留布局、焦点与草稿恢复实验；尚未接通的解决与采纳继续醒目标注，不伪装完成。集成沿用当前固定 core 配对，不将旧原型分支整体覆盖主线。

## 验收与采用边界

维护者明确采用云端 Linux + 标注的 AI 模拟作为本轮验收口径。功能、自动检查和实际 AI 操作通过后，仍需精确候选 CI、合并审查与合并后复验；正式发行在工单完成并合并后进行。验收材料按维护者要求本地保留，不附原始记录。

没有真人参与者、真人原话、满意度或人类 A/B 数值。Windows 实际会话、物理 IME/DPI 和 Web 实际交互未执行，不能由构建或 AI 操作推导其通过。历史研究要求不被改写；若未来恢复真人研究，应以真实参与者和预注册方法重新执行。

采用可选入口不等于批准替换默认 UI，也不取消生产安全门。后续试验必须继续保持取消零写、陈旧拒绝、目标身份与草稿隔离；若不能保持，应修正或拒绝相应设计。
