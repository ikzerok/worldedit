# EDS-04：六区域显隐与工作台比较

关联 worldedit#35。依据[系统指南](guide.md)、[任务与对象](eds02-tasks-and-objects.md)、[状态契约](eds03-state-contract.md)。这是低保真决策记录，尚无作者实测；“首选”只表示下一轮原型优先级，不是生产布局批准。四个方案场景使用同一组示例资料：正文 A、固定旁查资料 B、地图入口 P、事件 E 和待审提案 R。未实现的书稿、待办及重放能力一律为标注的样例数据。

## 六种职责与最小外壳

六种职责是导航、主编辑/阅读、检查器、时间/图、资源/命令、状态/诊断；不要求六块面板同时出现。主区域随任务成为正文、地图/关系图、运行解释或差异对照。导航至少提供返回与目标定位；状态层始终显示工程身份、只读/冲突、内容未保存、当前工具和正在编辑的 owner。被隐藏区域必须有可见按钮或键盘命令恢复，不能依赖记住一个快捷键。

| 输入轴 | 值 | 对显隐的确定性影响 |
|---|---|---|
| `task` | 写作 / 世界组织 / 演练 / 审阅 | 决定默认主区域和导航索引；不是不可返回的流程阶段 |
| `view` | 正文 / 地图 / 图 / 差异 | 决定主区域投影；切换不覆盖 target、草稿与运行位置 |
| `selection` | 空 / 单个 / 多个 | 空时检查器给导航说明；选中时仅跟随模式更新检查器；多选明确批量 owner |
| `pin` | 未固定 / 固定 B | 固定时检查器持续显示 B，选中 A 不覆盖；窄窗转可恢复标签 |
| `draft` | 无 / A 未应用 / 过期 / 冲突 | 有草稿时切目标、工程、专注或关闭区必须保留或明确决策；过期/冲突状态始终可达 |
| `capability` | 可写 / 只读 / 未知 | 只读仍可检查；提交入口禁用并解释；未知不作猜测写入 |
| `space` | 宽 / 窄 / 专注 | 宽屏可并列，窄屏辅助区转抽屉/标签；专注保留退出、状态和恢复原布局的会话快照 |

优先级：安全状态和草稿警告高于空间折叠；用户固定高于任务默认；任务默认高于临时选择建议。空间只决定位置与同时可见数，不能销毁 pin、草稿、选择、输入焦点或返回点。相同输入轴组合应生成同一布局；用户手动开合属于个人会话覆盖项。恢复默认布局只清个人布局覆盖项，不重置 `Project` 或内容撤销。

## 同一任务数据下比较 A/B/C

| 方案 | 结构与入口 | J1 建档放地图 / J2 写作旁查 | J3 演练 / J4 审阅 | 结论 |
|---|---|---|---|---|
| A 固定三栏 | 左导航、主区域、右检查器始终稳定；工具嵌在栏内 | 易定位，但写作行宽与地图面积受右栏挤压；固定 B 持续占位 | 演练输出与差异稿争主区域，窄屏需改成标签 | 保留为低复杂度比较基线；若 B 误改/找回成本更高则回退 |
| B 稳定外壳 + 任务预设 | 保持项目/状态外壳，主区域随任务切，辅助区可固定或抽屉 | J1 图形主区与资料检查器；J2 正文主区、B 临时/固定旁查，能还给正文宽度 | 演练主区显示路径与状态；审阅主区并列差异，冲突队列可开合 | **待验证首选**：在稳定定位与任务空间之间折中；须证明 pin/草稿/焦点恢复 |
| C 自由 dock/split/多窗 | 每块区域可移动并存为个人布局 | 最多同时信息，但 J2 的返回点与固定 B 容易散在多窗；初学者寻找入口成本高 | 可自定专用监视布局，跨 Web/原生和 DPI 恢复成本最高 | 首轮拒绝完整任意 dock；只保留有限分区作为后续假设 |

三者都必须通过身份、基线、只读和保存安全门；外观评分不能抵消误写或丢稿。这里没有真实计时、成功率或偏好票。下一轮同一组任务和输入数据实测后，记录方案、作者原话、偏差与恢复成本，再决定采用/修改/拒绝。

## B 方案的默认区域矩阵

| 场景 | 主区域 | 导航 | 检查器 | 时间/图 | 资源/命令 | 状态/诊断 |
|---|---|---|---|---|---|---|
| J1 世界资料 | 地图或资料列表 | 常显，可折叠 | 跟随入口；明确标记和实体两种 owner | 地图为主时不另开图；按需切换 | 创建/关联/图层工具抽屉 | 锁层、未知能力、未保存常显 |
| J2 写作旁查 | 正文 | 大纲可折叠 | B 临时阅读或固定旁查；窄窗标签 | 默认隐藏 | `@` 检索、建档按需出现；能力缺失标“样例” | 正文 owner、草稿、基线常显 |
| J3 演练 | 控制流或运行解释 | 事件/诊断索引 | 选中定义的属性 | 世界时间单独按需；不得冒充运行路线 | 开始/停止显式命令 | 当前快照、runtime 位置、错误常显 |
| J4 审阅 | 原稿/提案/结果对照 | 冲突/待审队列 | 锚点与影响按需固定 | 默认隐藏 | 采纳/拒绝/重新比较，明确基线 | 冲突和未应用状态常显 |

资源抽屉只有无输入、拖放、子菜单或模态时才能因失焦退场；关闭抽屉不提交候选。专注模式记录原布局、焦点、滚动及 pin，保留可见退出和关键冲突提示；退出按快照恢复，若目标已经失效则显示原身份和失效原因。窄窗优先保主区域，辅助区按用户 pin 保留为标签，不降低字体到无法阅读。只读项目不隐藏目标身份或错误，仅禁用修改命令。

## 抛弃式原型与验证脚本

同一份可直接打开的 HTML 原型已保存在独立分支 `codex/eds04-prototype` 的提交 `ae23509`，路径 `docs/design/editor-system/20260926/eds04-prototype-throwaway.html`；不进入生产分支。底部切换条和 `?variant=A|B|C` 可比较三种结构，任务选择复用上述 A/B/P/E/R 数据。状态栏显示输入轴、预览位置、运行位置与 `Project writes=0`；可模拟窄窗、专注恢复、抽屉、固定检查器、只读、陈旧基线及草稿切任务。JavaScript 已通过 `node --check`，尚未有真实作者或双端实际操作证据。

原型让 A/B/C 在同一数据和任务间切换。每条路径均先在宽屏完成，再缩窄窗口，进入/退出专注，打开/关闭资源抽屉，重置布局，最后带 A 的未应用草稿切换任务：

1. J1 建档并放地图：从资料 B 打开 P，核对入口与资料 owner 不混淆；锁层时不能提交。
2. J2 写作旁查：编辑 A，固定 B，选择其他对象；返回 A 原光标和滚动；窄屏仍能找回 B。
3. J3 演练：选 E、查看时间图、预览分支；runtime 位置只有显式运行后变化。
4. J4 审阅：R 基线变陈旧，保留解决草稿并重新比较；关闭抽屉或重置布局不采纳提案。

记录找入口时间、误改/丢稿、恢复次数和原话；没有参与者前这些只是可执行任务，不填结果。原型中的假数据不得连到生产 `Project` 写入。若 B 的定位/误改/恢复问题明显超过 A，缩回固定三栏或减少布局可变轴，再复测。
