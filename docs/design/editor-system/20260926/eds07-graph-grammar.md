# EDS-07：书稿、世界时间、控制流与关系图的视觉语法

关联 worldedit#38。依据 [EDS-02 对象模型](eds02-tasks-and-objects.md)、[EDS-03 状态](eds03-state-contract.md)、[EDS-05 跨投影](eds05-cross-projection.md)。以下是设计约束与验证方案，不宣称所有投影已经生产实现；书稿能力按 CAP-02A 实际交付状态接入。用户已排除游戏引擎适配器。

## 四种顺序/关系不得共用一条线

| 投影与标题 | 节点/边文字语义 | 主动作 | 禁止暗示 |
|---|---|---|---|
| **书稿阅读次序** | 卷/章条目按作者显式数组顺序排列，节点显示章节 ID、引用正文目标与可用性；父 section 是编排容器 | 在明确编辑书稿时重排章节、预览引用正文 | 不改 event 声明顺序、世界时间、控制流或运行出口；不存在的正文不级联删章 |
| **世界时间偏序** | `during` 是事件所在直接时段，`within` 是时段包含；`follows` 是作者声明的同直接时段先后边；并列 rank 表示无法断定先后 | 查看约束和源声明；新增/修改约束必须走 core | 不把文件顺序、视觉左右、同 rank 或执行跃迁推断为时间事实；无日期不画成比例时长 |
| **可执行控制流** | 有向箭头标识选择/跳转和条件；未知条件明确标注；终止和汇合不同 | 明确运行/停止/选择，再查看本次会话路径 | 看节点、选中边、切图、预览原文不执行；时间偏序不门控 runtime |
| **世界语义关系** | 关系类型、方向、来源说明、独立关系 ID 均可见；同端点平行边保持独立 | 筛选/查看/明确编辑某条关系 | 视觉距离、层级或布局吸附不生成祖先、因果、传递或新关系 |

顶部投影名称必须始终可见，例如“世界时间 · 偏序，不代表运行路径”。每个投影有文字图例说明节点、边、箭头、虚线/问号和可用动作；缩小时图例不消失，只可折叠并提供键盘重开。FCP 磁性时间线的自动吸附用于其媒体编辑场景，在此只能作为误导反例：拖动书稿章节不会自动重算事件先后，移动时间节点不会自动改程序出口。

## 同一对象的四种可见状态

| 状态 | 语义和表现 | 持久化/执行 |
|---|---|---|
| `selection` | 实线边框/列表选中标记，标题显示 kind+ID；多选列各身份 | 个人会话状态，零 Project 写入 |
| `preview_cursor` | 明确“预览”文字和虚线位置标记；临时原文卡可返回来源 | 不推进 runtime，不进入内容撤销 |
| `runtime_position` | 单独的“本次运行位置”徽记、会话/编译快照 ID 和路径历史 | 仅 runtime 显式动作改变；不反写源码 |
| `hover_target` / 键盘焦点 | 悬停底色与清晰焦点环；焦点控件接收键盘 | 不等于选择或运行；中文 IME 不触发图快捷键 |

同一对象可同时选中和处于运行位置，但两个标记并列展示，不能只换一种颜色。图与文字索引共享稳定 ID；单击索引定位并保留返回点，打开详情列来源文件/行、条件或关系 `source_note`。来源行变化时需重新核对身份和基线。无日期事件仍可在控制流和资料列表出现；时间视图给“未分配时段”文字入口，不把它放在凭空推算的日期轴上。

## 图形复杂性和文字后备

平行语义边按独立关系 ID 并列列出，图形上可错位或聚合计数，但不能合并其类型、方向或来源；展开后每条有独立详情与操作。自环用独立环标与文字“自环：A→A”；控制流条件附在对应边，过长时图上摘要加详情，不靠颜色解释 true/false。世界时间无绝对单位时使用离散列/偏序层，不能画比例长度或拖成“3 天”。长标签截断时提供完整文本、可聚焦列表和屏幕阅读器名称；来源/关系类别用文字或形状双重编码。

密集关系图查询沿用 core 最高 250 节点/500 边、最多 2 层的边界；`truncated`、实际计数和继续入口必须出现，换快照后废弃旧 continuation。文字索引保留同一查询与筛选，显示“当前页/总数或更多结果”，可用键盘前进。当前页没有某对象不表示它不存在。缩放、平移和布局改变只改个人投影；稳定 ID 与来源仍可从图、索引和搜索抵达。混合图若难以读懂，拆回四个有名称的投影，而不是让一条线同时表示偏序、执行与语义。

## 原型任务与负例

| 路径 | 验收观察 |
|---|---|
| 章 X 引用事件 E 后重排 | 书稿列表改变；E 的源码、时间 rank、执行图和 runtime 均不变 |
| 同时段 E1/E2 并列、E3 follows E1 | E1/E2 不被画成同时；E3 有明确先后边和来源；执行仍可直接进入 E3 |
| 无日期 E4 与无时长时段 | 文字索引可找到；不出现伪造的日期刻度、持续宽度或换算 |
| 选中、临时预览、切到关系图再返回 | `runtime_position` 不变，选择和预览可分别恢复；Project 内容指纹不变 |
| 两条 A→B 关系及 A→A 自环 | 三条独立 ID、类型、方向、来源均可通过图与列表辨别，删一条不删其余 |
| 条件长标签、超过图上限 | 图上摘要/聚合但详情完整；列表可达、截断可见、继续页与当前快照绑定 |
| 中文 IME 与键盘操作 | 输入焦点先接事件；图命令不误执行，所有图上详情有键盘后备 |

原型数据可以标假；真实验收需使用公开 core 查询和 egui 事件，并记录作者是否把四种边读错。本文没有作者测量结果，也不添加精确历法、世界自动运行或 CAP-06 重放能力。
