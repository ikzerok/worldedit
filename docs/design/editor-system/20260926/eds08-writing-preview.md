# EDS-08：正文、临时侧览与可恢复专注

关联 worldedit#39。依据 [EDS-03 状态与路由](eds03-state-contract.md)、[EDS-04 区域策略](eds04-layout-comparison.md) 和 [EDS-06 草稿](eds06-inspector-drafts.md)。本票只约定呈现与交互；CAP-01B 就地建档、CAP-02C 多面板及 CAP-02A 书稿的真实可用性以各自实现/验收为准。

## 四种阅读/编辑容器

| 容器 | 打开与替换 | 关闭与返回 | 写入权 |
|---|---|---|---|
| 主文稿持续编辑 | 从源文件/书稿条目显式打开；切视图先保存会话返回点和草稿 owner | 不能因旁查或布局变化被替换；有未应用输入需保留或明确决策 | 仅明确文本编辑与 core/Project 命令 |
| 临时侧览 | 链接、搜索候选、选文命令可打开；下一次临时预览可替换同一临时位 | Escape/关闭归还原焦点、光标/选区、滚动；预览历史可返回 | 浏览零写入 |
| 固定旁查 | 用户显式 pin 当前资料；标题显示 kind/ID 与“已固定” | 选 A 不覆盖固定 B；解除 pin 可回临时侧览，关闭后仍可回主文稿 | 阅读零写入；编辑 B 必须显式开 B 事务 |
| 完整阅读投影 | 从目录/书稿导航打开，可承担长文阅读 | 返回栈恢复来源投影和位置；失效显示原身份 | 默认只读；不能把阅读滑动当编辑 |

临时侧览只承载当前目标；固定旁查可按 CAP-02C 实际上限同时存在，超上限给明确说明而非静默替换。每个固定面板有独立身份、导航历史、关闭和定位入口；主文稿永远占主区域。窄窗将旁查变成可恢复的标签/抽屉，标签仍显示 B 的身份和 pin，切回正文不销毁 B 的状态。复杂多窗能力不可用时，一个临时侧览足够完成“查后返回”；UI 必须清楚说明限制。

## 写作中调用工具

正文选文或光标弹出轻量命令入口；同一命令还可从菜单和键盘访问，触控不依赖 hover。候选搜索显示 kind、稳定 ID、名称/别名和来源；同名保留多项，不选第一个。选文建档先冻结来源 `(project,file,baseline,char_range,selected_text)`，但不冻结整个输入控件：用户继续输入时要么更新明确的选区，要么显示基线已变并要求重新选择，不能用旧偏移改另一段文字。建档表单绑定所选 owner 和原始草稿；确认才调 core 组合意图，取消、Esc 或关窗不改 Project。已有链接可旁查其资料并回原编辑位置；失效链接保留原 kind/ID 与修复入口。

IME 组合阶段 `@`、Enter、Escape 和单键快捷键交给文本控件，不能触发候选、建档、关闭或图命令；组合结束后再识别明确触发。候选列表可用方向键遍历，Enter 选择，Escape 关闭并恢复编辑焦点，Tab 的行为须与平台焦点导航一致。复制长文仅复制作者实际选中的源文本，不夹带行号、按钮标签或隐藏工具；粘贴/撤销仍归文本控件。高亮命令按钮须有可访问名称、焦点样式和触控命中区，不以手绘浮层替代语义控件。

## 专注与窗口宽度

进入专注前保存个人会话快照：主文件/章节身份、光标/选区、滚动、焦点、选中资料、旁查 pin、每个面板历史、工作台预设、区域展开与镜头。专注只隐藏非必要工具，保留明显退出入口、草稿/保存/冲突和只读提示；出现验证错误时允许打开诊断。退出以快照恢复区域、位置和焦点；目标已删或基线变化则显示失效/冲突，不能跳同名对象。专注切换不进入内容撤销、不保存作品、也不丢当前输入。恢复默认布局只重置个人布局偏好，不能清稿。

窄窗优先保正文可读宽度；导航和旁查转标签/抽屉，固定 B 优先有可见恢复入口。页面仍显示当前 owner 与未保存状态。行宽、字号、行距、信息密度和旁查占宽在原生/Web、长中文段落、长英文单词、缩放及窄窗下比较；现有 880 逻辑点只作为旧基线，不作新固定答案。阅读长文按段落/来源锚点可恢复滚动，低性能机器可分页或虚拟化，但不能丢失查找命中和复制范围。

## 验收路径

| 路径 | 观察点 |
|---|---|
| A 正文选中文字 → 临时看 B → pin B → 返回 | A 的未应用输入、真实光标/选区和滚动保持；B 的标题与历史独立，Project 无浏览写入 |
| 固定 B 后打开 A 的另一段 | B 不被 A 覆盖；A 的操作 owner 明确，关闭 B 不关闭 A |
| 同名候选、失效链接、外部刷新 | kind/ID 消歧；失效保留原 ID；陈旧选区拒绝提交而草稿可复制 |
| 中文 IME 与无鼠标 | 合成态不触发 @/Enter/Esc 命令；菜单和键盘完成候选、取消、返回 |
| 专注/窄窗/重置布局 | 退出恢复位置与焦点，pin 可找回；重置只改个人布局，有稿不静默丢失 |
| 长文/缩放/复制 | 测得可读行宽与触达，不预设 880；复制内容无 UI 杂质，定位后可回同一段 |

实际作者效率、行宽偏好和双端可达性尚未测量；后续原型应记录原话、误触、返回失败与恢复成本，不填虚构成功率。
