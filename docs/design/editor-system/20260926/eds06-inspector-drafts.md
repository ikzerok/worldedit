# EDS-06：检查器、参数与正文草稿交互契约

关联 worldedit#37。依据 [EDS-03 状态契约](eds03-state-contract.md) 和 [EDS-05 跨投影交互](eds05-cross-projection.md)。本票交付界面设计规则，不新增模板类型、持久历史或合并算法；当前表单能力及批量能力须以 core/Project 实际支持为准。

## 检查器 owner 与选择矩阵

检查器标题固定显示 kind、ID、路径/来源和 `跟随选择` 或 `已固定`。标题旁提供“定位此对象”“解除固定”；当图上选择 A 而检查器固定 B 时，B 的标题、编辑按钮和提交摘要都写 B，不能把 A 的高亮当提交目标。目标删除/改 ID/外部刷新后，检查器保留旧身份，显示失效与重新定位入口；不能自动绑定同名对象。

| 选择状态 | 检查内容 | 可编辑范围 |
|---|---|---|
| 无选择且未固定 | 解释当前投影和选择方法 | 无 |
| 单选 A、跟随 | A 的摘要、来源、当前能力与诊断 | core 支持的 A 字段；打开事务时捕获 A 与基线 |
| 单选 A、固定 B | B 的摘要和“已固定：B”；另给 A 的选中提示 | 默认编辑 B，所有命令明确 B；不能静默改 A |
| 同类多选 | 数量、各 ID、共同可读字段与差异状态 | 仅 core 提供原子批量命令的字段；否则逐个入口 |
| 异类多选 | 每类数量和完整 owner 列表 | 只读汇总；不伪装有共同可写字段 |
| 某对象只读/未知能力 | 仍显示当前值、来源和原因 | 禁用提交，保留可复制草稿；不把按钮消失当解释 |

批量编辑若将多个字段互相约束，预览必须列出每个对象的旧值、新值和验证结果。core 不支持原子提交时，不串接多次写入假装“一次批改”；先退回单对象表单。只有一个对象能提交时也不能把另外对象默默跳过。

## 字段呈现与作用域重置

常用字段保持固定顺序：身份/显示名、最常用语义字段、正文/描述、来源；高级字段按主题分组而非一个无名折叠堆。字段同时有值状态和写入能力状态：`explicit`（本对象明确值）、`default`（系统默认但尚未写入）、`missing`（未提供且可能需补）、`inherited`（来源/父对象值，标出来源）、`unknown`（当前版本无法解释，原字节保留）。这些标签与 disabled/只读分开，不能把未知值画成空白或默认值。当前 core 没有继承语义的字段不虚构 inherited。

高级组折叠时，组标题显示错误数、修改数与冲突数；点击错误摘要展开并聚焦具体字段。校验失败保留输入和旧值，不只弹 toast。字段旁显示“已修改/未应用/已应用缓冲/已保存”与基线；标题汇总不替代逐字段解释。数值参数同时提供可键入精确值和可取消的拖动预览；拖动中不得写 Project，键盘调整有等价路径。单位、上下界、取整规则、非法值和未知字段保护来自 core 契约，UI 不猜。

“重置”必须写明范围：当前字段到打开表单时值、当前字段到 core 默认值、当前分组或整个个人布局是不同命令。不存在 core 默认的字段不显示“重置为默认”；继承值的“清除覆盖”不能说成“删除父值”。重置先改变草稿候选，应用仍需完整基线校验；个人布局重置不得碰作者正文。多字段/多对象重置先预览影响，再用 core 支持的原子命令提交。

## 预览、应用与保存

每个编辑会话绑定工程、对象 owner、来源、原值和内容基线。状态路径与 EDS-03 一致：`Idle → Previewing → Validating → AppliedToBuffer → Saved`；取消、陈旧、只读、冲突各有显式出口。预览区与实际值并排，滑块/正文输入只改本地候选；确认后由 core 验证并一次应用到 Project 缓冲，才出现内容撤销记录；磁盘保存另报成功位置。外部变化使基线失效时保留输入、显示旧/当前/候选，要求重新比较；确认弹窗不能绕过 core 冲突检查。

正文保持自然文本编辑，不强制拆为参数模板。源文件未应用输入需要原光标、选区和滚动返回点；旁查、面板折叠、专注或切工程不能静默销毁它。中文 IME 组合时 Enter/Escape、单键快捷键归输入控件；组合结束后的显式提交才进入验证。只读可复制和检查原稿，但不接受写入。失效引用显示原 kind/ID 和修复入口，不用同名资料替换。

三方比较展示 `base`（打开时来源）、`current`（刷新后工程）、`proposal`（本地草稿）与字段来源；相同字段双边修改时标冲突并保留所有输入。采纳/拒绝是明确命令，依托 core 的比较和安全采纳；UI 不实现另一套字段赢家或自动 merge。若无法获得可信的共同基线，禁用“直接应用”，提供重新载入、复制草稿和取消。

## 验收路径

| 路径 | 观察点 |
|---|---|
| 固定 B 后选 A | 检查器标题和提交摘要持续为 B；选择 A 不改变 B 的事务 owner |
| 高级组字段错误 | 折叠标题显示错误数，点击可展开定位；修复前保留输入 |
| 精确输入与拖动 | 移动/键入只更新候选，Escape 恢复；提交一次产生一次内容撤销 |
| 同类/异类多选 | 没有 core 原子批量能力时只读汇总或逐个编辑，不发生部分成功 |
| 缺失/默认/未知 | 原值与来源可解释；未知原字节保留；重置范围不会越到其他字段或 Project |
| 过期与三方冲突 | A 草稿保留，base/current/proposal 可比较；不默认覆盖，取消仍有原稿 |
| 只读与中文 IME | 可检查但不能应用；组合输入期间 Enter/Escape 不提交/关闭表单 |

这些是待执行的 egui 事件与真实双端验收入口。现有 [authoring_forms.rs](../../../../src/app/authoring_forms.rs) 捕获表单基线，[app.rs](../../../../src/app.rs) 对切换有表单保护；它们不等于上表整套渐进披露和三方比较已生产化。
