# EDS-05：主区域、结构索引与资料库的跨投影交互

关联 worldedit#36。依据 [EDS-02](eds02-tasks-and-objects.md)、[EDS-03](eds03-state-contract.md)、[EDS-04](eds04-layout-comparison.md)。这是设计契约；还没有真实作者的寻找/拖放测试，CAP-01C/03B/08B 的未交付能力不能因本文标为已有功能。

## 一次导航意图

结构树、资料库、文字索引、地图和关系图发送同一种导航意图：`target_id / projection / source_view / reveal_mode / return_point`。`target_id` 必须是带类型的 `TargetRef`、地图的 `(map_id,placement_id)`、来源范围及基线，或已存在的其他稳定身份；`reveal_mode` 区分“只定位”“临时预览”“选中”“打开编辑”。名字、屏幕坐标、列表序号不作身份。`return_point` 保存来源投影、原焦点、滚动/镜头、筛选、展开项与当前面板 pin 状态，按会话栈有限保存；返回时先核对身份和基线，失效则保留原 ID 并给定位/刷新/关闭入口，不跳同名替代对象。

| 发起处 → 目标 | 接收行为 | 明确不做 |
|---|---|---|
| 资料树 → 地图 | 用 `TargetRef` 查映射，列出 0/1/多处 `MapPlacementRef`；作者选择一个实例后才定位镜头 | 没有入口时不自动创建标记；多入口不默认第一个 |
| 地图入口 → 资料 | 先显示 map/placement owner 与关联 TargetRef；“打开资料”明确切至资料检查器/源声明 | 选中或拖动标记不改资料事实；删入口不删资料 |
| 关系文字索引 → 图 | 使用 core 返回的稳定边/节点 ID，保留筛选和页游标，镜头聚焦可见对象 | 不因图形距离推断隶属、传递或时间先后 |
| 正文引用 → 资料/正文 | 记录当前文件、光标范围、基线、滚动和焦点；进入目标，返回原编辑位置 | 不把阅读投影当作编辑提交，也不丢草稿 |
| 诊断/搜索 → 源 | 以文件、行列及当前基线定位；改动后重新核对位置 | 不把旧行号当永久对象身份 |

每次导航只改个人会话状态，`Project` 内容指纹与内容撤销栈不变。读者在主区域切正文、图、地图或差异稿时，检查器的 `Follow`/`Pinned(B)` 规则沿用 EDS-03；图/树选择 A 不可偷换固定 B 的编辑 owner。不同投影可显示同一资料 ID，但标记实例、语义关系、引用文本和资料本体各有独立操作名和删除范围。

## 临时资料库、固定资料库与插入

资料库有临时抽屉与固定侧区两种个人投影，使用同一 core 目录搜索。抽屉可在明确唤出、正文 `@` 或工具按钮后出现；固定只改变布局，不复制资料或绑定草稿 owner。打开时保留原主区域光标/滚动。搜索候选显示 kind、稳定 ID、显示名、来源和同名消歧；键盘上下只改变候选预览，Enter/明确按钮才选择，Escape 取消并将焦点还给来源控件。中文 IME 组合中不把 `@` 或 Enter 当提交。抽屉失焦自动关闭只允许在无输入、拖放、子菜单或模态时；关闭不插入、不创建、也不改 Project。

选择和插入是两步：选择已有资料可临时预览；插入正文稳定链接或地图入口必须由该场景的显式命令取得 owner、源基线与能力状态，再交 core 组合意图验证。拖放开始只持有候选 `TargetRef` 与来源快照，移动仅画预览；命中区必须说明“将创建展示入口 P”或“将插入引用”，不能仅靠颜色。释放前核对地图、目标、层锁、只读、几何及完整基线；仅一次提交。Escape、拖出有效区、锁层、失效目标或核心拒绝均丢弃预览且不残留半成品，失败输入仍可恢复。地图入口创建绝不隐式创建语义关系或改变资料隶属。结构树拖动只重排该树明确拥有的顺序；布局吸附不生成任何世界事实。

## 大图与长标签的后备

文字索引与图形共享同一目标身份和筛选快照。索引逐行给 kind/ID、完整可展开标签、边类别/方向、来源与“在图中显示”；键盘能分页、定位与返回。图上长标签可截断以保画布，但焦点/悬停/详情必须展示全名，并有列表等价入口；遮挡或缩放不应使对象永久不可达。节点和边使用不同计数，不把渲染裁剪当作查询结果。

现有 core [语义关系查询](../../../../../worldline/core/src/relations.rs) 默认最多 250 节点、500 边，深度最多 2，返回 `truncated` 与 continuation；[图视图过滤器](../../../../../worldline/core/src/graph_views.rs) 也限制 1–250 节点、1–500 边。UI 显示“已截断，继续加载/缩小范围”，并在同一目录快照与相同筛选下使用 core continuation。刷新或项目修订改变后从第一页重新查询，不拼接不同快照；过小的自定节点上限可能无法前进，采用有效默认界限。索引也不得把前 300 条显示上限冒充全部结果；当前 [搜索窗口](../../../../src/app/search.rs) 已显式提示“显示前 300 行”，未来统一索引应继续标明结果数与截断原因。

## 当前实现接缝与验收

现有 [地图画布](../../../../src/app/maps.rs) 有局部拖动预览、图层锁检查、基线意图提交和未提交导航保护；[阅读跳转](../../../../src/app/reading.rs) 可定位地图入口；[网络视图](../../../../src/app/network.rs) 有独立拖动状态。这些状态不可直接合并成一个全局 selected。迁移先让各投影产生/消费类型化导航意图与返回点，再验证真实 egui 事件下的焦点、锁层、取消和 Project 零写入；core 保持语义查询与变更唯一入口。

| 验收路径 | 必须观察 |
|---|---|
| 树定位资料 B，再到两处地图入口 | 列出两个 placement ID；任选一个定位后返回树，筛选、展开项、焦点和镜头可恢复；无 Project 写入 |
| P → B 与删除 P | 检查器先显示 P owner，显式打开 B 才切 owner；删 P 的预览/影响不包含 B 正文 |
| 拖 B 到锁层或无效区 | 只有预览，释放被拒/取消后文件字节、内容指纹和撤销栈不变 |
| 大关系图超过上限 | 图与文字索引都显示截断、上限和继续入口；跨快照页游标失效后重新查 |
| 长标签、同名、失效身份 | 键盘可到达完整标签；显示 kind/ID；刷新失效保留旧 ID，不偷换同名对象 |
| 旁查固定 B 后选择 A | pin 与返回点保留，明确编辑 owner；抽屉关合、图形定位均不提交 A/B |

上述为后续原型和集成测试入口，尚未运行作者实测。若图形操作无法达到列表同等可达性，保留列表操作，不用裁剪隐藏真实结果。
