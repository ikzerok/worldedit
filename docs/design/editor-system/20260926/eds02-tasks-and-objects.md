## 角色与任务假设

这些是同一作者可随时切换的任务角色，不是账户权限或强制生产阶段。频率仅作待验证排序，没有人数或统计证据。

| 角色 | 目标 / 假设频率 | 风险假设 | 需要验证 |
|---|---|---|---|
| 世界设定作者 | 找对象、建档、关联与地图定位 / 高 | 混淆资料与入口，误删共享对象 / 高 | 是否主要从搜索、地图或分类进入 |
| 长文作者 | 连续写作、旁查、回到原位置 / 高 | 丢光标、未保存正文与同名误引用 / 高 | 常见旁查对象数及键盘偏好 |
| 逻辑演练作者 | 检查条件、运行并追溯结果 / 中 | 把阅读顺序当运行顺序，旧快照误判 / 高 | 无执行内容工程如何理解入口 |
| 审阅者 | 定位变更、讨论、接受或拒绝 / 中 | 过期提案覆盖修改、只读被绕过 / 高 | 最小对比单位及批注粒度 |

## 五种组织关系不得混名

| 名称 | 真源与用途 | 禁止推论 |
|---|---|---|
| 文件目录 | 工作区相对路径；保存与交付组织 | 文件夹不是世界隶属关系 |
| 世界关系 | 显式语义关系的类型与两端 | 地图包含、图形连线不是语义事实 |
| 阅读/编排次序 | 正文概览投影；未来书稿由专用契约定义 | 排前不表示先发生或必定执行 |
| 时间偏序 | follows、时段及 core 分析 | 不推导绝对日期、时长、访问状态 |
| 控制流 | 跃迁、选择、进入和漂流的 core 图 | 连线存在不证明条件可满足或必然执行 |

## 对象身份与生命周期

所有 UI 会话目标还须带工程会话上下文，避免切工程后同 ID 误命中。该要求不新增持久身份格式。

| 对象 | 身份 / 来源 | 创建与引用 | 删除边界 |
|---|---|---|---|
| 源文件 | 工作区内相对路径；Project 原始缓冲 | 工作区 API 创建；include/附件路径按声明文件解析；移动须重审路径引用 | Project 墓碑与保存语义；不能绕过边界删除磁盘路径 |
| 实体/人物 | TargetRef(kind,id)；`.wl` 声明 | core 草稿/事务；显示名、别名用于查找而非唯一键 | 先完整影响计划；不得因删除一个入口删实体 |
| 地图 | MapId；清单注册展示 JSON | 显式创建并注册；独立 NavigationTarget | 删除地图不是删除其目标资料；原字节与未知字段受保护 |
| 标记实例 | (MapId,PlacementId)；地图 placements | 可引用 TargetRef，同一目标可有多个实例，annotation 仅为入口说明 | 删除实例只移除展示入口，不级联正文或关系 |
| 语义关系 | relation ID；`.wl` 独立关系声明 | 明确类型、from/to；图形线可引用关系但不能暗建关系 | 删除关系不删端点；图中隐藏不删关系 |
| 事件/场景 | event ID / 完整 scene 名；源码声明 | core 作者接口；场景归属事件；图节点索引不是身份 | 检查控制流、内容与展示引用；顺序调整不改 ID |
| 正文引用 | 目标 TargetRef；引用出现位置来自源文件与文本 | 显式链接由 core 导航规则解析；命中词不是自动关系 | 删除链接不删目标；位置会随编辑失效，不能假造持久片段 ID |
| 标签/状态/锚点 | 各自 TargetRef；源码及 core 索引 | 标签引用对象；状态有明确目标；独立锚点与运行锚点分开 | 走对应影响计划，不能把运行记录当设定来源 |
| 批注/提案 | 协作文档 ID 与锚点/基线；注册文档 | 独立记录讨论/建议；接受由 core 校验应用 | 删除讨论不删除正文；接受失败不强制覆盖 |
| 个人投影 | 会话中的视图/面板身份、镜头、筛选 | 本地导航状态；共享视图只能显式保存为展示文档 | 关闭面板不删对象；切工程清理旧目标与历史 |
| 未来书稿章节 | CAP-02 契约待实施验收，不预造 ID 格式 | 未来引用正文，不复制真源 | 未批准契约前不承诺级联或自动迁移 |

## 四条完整旅程

以下是设计与验收脚本，不能标为已经运行通过。每条都保留进入、定位、修改、确认、保存、取消、失败和返回。保护要求由 core 执行；新入口仅负责呈现和命令调用。

### J1 世界设定：从空作品建立地点并定位

1. 选择独立空目录创建作品；取消目录选择应回到原工程。源码仓库不是作品。纯设定工程没有可执行事件仍合法。
2. 从资料搜索/创建入口建立地点；先显示 kind+ID、目标文件及语言能力要求。同名“白塔”候选并列显示类型和 ID，由作者选择。
3. 打开表单填写草稿；取消不改 Project。应用必须校验打开基线，成功后显示未保存状态。只读或未知必需能力时允许阅读/另存原字节，阻止编辑。
4. 将已存在地点作为地图标记目标；地图新建地点并放置的组合事务属 CAP-01C，未经独立验收时只提供分步现有操作，不展示假成功。
5. 检查 marker owner 与 entity owner；移动标记只改展示文档。删除标记后资料仍可搜索；删资料必须展示完整引用影响，错误分析不能视为可删。
6. 保存成功才推进基线；保存冲突保留缓冲。切工程前处理草稿和未保存内容；取消切换返回原位置，成功切换清理旧对象目标。

验收证据需求：空目录、同名、只读、删除影响、保存冲突及切工程前后源码差异。依据工作区/展示契约、FormGuard、DeletionImpact；当前文档没有这些 RUN 结果。

### J2 长文写作：旁查后续写

1. 从正文概览或源文件进入明确事件/场景，记录 owner、光标与滚动位置；空工程给创建正文入口，不能要求先搭控制流。
2. 输入未保存正文，搜索人物/地点；同名以 kind+ID 消歧。阅读链接不能静默替换正在编辑的草稿。
3. 临时阅读返回原正文；多资料钉住属于 CAP-02C，本轮实现状态由专票验收记录决定；基线只有单 reading_target，不把研究图当已支持多窗。
4. 正文 `@` 引用、选文建档属 CAP-01B，书稿章节、目标统计属 CAP-02A/B；未验收前显示未来能力说明，保留现有显式链接与源编辑入口。
5. 应用正文并保存。外部更新导致基线过期时保留输入、阻止覆盖，重新打开后合并；浏览器重新导入不是持续监视。
6. 切工程/关闭时，未应用表单与 Project dirty 分别检查；保存失败不得继续关闭，取消应原位返回。只读工程允许旁查，不能通过正文快捷入口绕过限制。

验收证据需求：Unicode/IME、光标返回、同名选择、只读、陈旧表单、切工程保护。基线 request_action 的 dirty 检查不能证明未应用表单安全；本轮补丁须单独验证。

### J3 逻辑演练：解释条件而不改设定

1. 从事件或诊断入口选择“控制流/演练”；只想阅读时不启动 runtime。无可运行事件时解释缺少入口，保留设定编辑。
2. 从 core 图定位 event ID，分别查看时间偏序和控制流；同名显示名不代替 ID；图中的显示位置不是执行位置。
3. 有未保存修改时明确运行所用编译快照版本；存在编译错误则先定位错误。启动后改源码必须标旧运行版本，不能伪装已经刷新。
4. 作者显式选择运行分支，观察 transcript/错误，链接仅旁查。停止/重开是运行会话操作，不改作品正文。
5. 需要修正时返回源对象，表单应用校验基线，再重新启动。只读仍可在允许的范围阅读/演练，不能把演练状态写回设定。
6. 切工程清理旧 play 与链接目标；取消切换保留原会话。确定性重放、状态对比和完整失败解释属于 CAP-06A/B 待独立验收能力。

验收证据需求：无事件工程、编译错误、旧快照提示、预览零运行副作用、切工程清理。不包含游戏引擎适配器，也不增加世界时钟。

### J4 审阅：从提案定位到受保护应用

1. 从待审条目或对象上的批注入口进入，显示提案来源、目标和基线；空列表说明当前无提案，不虚构待办。
2. 定位正文/字段并显示当前内容。锚点失效或目标删除应明确报告；同名对象不能自动替代。
3. 阅读讨论并拟定修改；取消编辑保留原提案。接受前检查只读、未知字段、引用影响和当前基线。
4. 应用成功才形成工程修改，保存另行反馈；过期/冲突不靠“确认”强制覆盖。逐字段三方审稿属 CAP-04A/B；未验收时保留现有提案流程，不假称已有逐段合并。
5. 外部文件变化时保留本地缓冲并阻止覆盖。另存冲突草稿是救援，不是冲突已解决；未解决保存事务须走事务原稿救援路径。
6. 关闭或切工程先处理未应用批注/表单和未保存工程；取消回到原提案。历史检查点与受保护恢复属于 CAP-04C/D 待专票验收。

验收证据需求：提案陈旧、锚点失效、只读、保存失败、切工程取消。未安排访谈，不能声称审阅者偏好三栏。

## 关键命令到入口映射

| 命令族 | 候选入口 / owner | 保留的失败、取消与后备入口 |
|---|---|---|
| 新建/打开/切换作品 | 稳定工程菜单 / Project | 目录选择取消；草稿与未保存保护；不使用源码仓库作作品 |
| 保存全部/另存/导出 | 工程菜单和状态入口 / Project | 冲突、事务恢复和只读原因可到达；浏览器下载完整快照 |
| 搜索/定位源码 | 全局搜索及对象详情 / 查询目标 | 零结果、失效目标与同名消歧；键盘入口保留 |
| 新建/编辑实体、人物、事件 | 对应对象列表与详情 / 明确 TargetRef | 统一草稿校验；空工程有入口；禁用说明可见 |
| 修改显示名/重命名 ID | 对象详情，分开命名 / TargetRef | ID 变更先看引用计划；过期计划拒绝 |
| 删除对象/删除标记/隐藏节点 | 各对象上下文，分别命名 | 影响不完整拒绝删对象；取消无内容变化 |
| 新建关系/编辑出口/时间约束 | 各自具名视图和详情 | 世界关系、控制流和 follows 不共用含混“连线”命令 |
| 钉住/返回/专注/重置布局 | 阅读或工作台工具 / 个人状态 | 未提交内容不静默丢弃；重置不删作品 |
| 撤销/重做 | 稳定编辑入口 / core 内容会话 | 不混个人导航历史；外部刷新使旧快照失效须说明 |
| 运行/停止/重新开始 | 演练入口 / 运行快照 | 编译错误、无入口和过期版本明确可见 |
| 批注/提案捕获/应用 | 对象上下文与审阅列表 / 协作文档 | 锚点与基线失效保留输入；不可强制覆盖 |

## 可评审结论与未决项

本稿完成角色假设、四条旅程、对象生命周期、全部 12 页面和关键命令迁移映射。它保留现有能力并明确未来 CAP 边界；没有批准新导航、没有实现页面合并、没有关闭能力票。

下一轮验证须让目标作者分别从搜索、地图和正文起步完成相同任务，记录实际频率、误认对象、返回成本及未保存处理。比较固定布局、有限任务预设和自由布局时复用上述脚本；在获得证据前不以竞品名气确定导航数量。公开 Project/core、CLI/RPC、egui 真实事件是已批准的实现测试边界，但本研究未新增或执行这些行为测试。
