## 角色和任务假设

角色表示一次工作的目标，同一作者可随时切换，不对应强制账户类型或固定线性阶段。

| HYP 角色 | 当前任务与成功终点 | 频率假设，待访谈 | 主要风险与验证问题 |
|---|---|---|---|
| 世界资料作者 | 建立资料并在地图/关系中找到同一身份 | 建档、查找较频繁，结构重构较少 | 同名误绑、把标记误当资料；能否说清正在修改谁？ |
| 长文作者 | 保留正文草稿，旁查资料后回到原编辑位置 | 写作和旁查较频繁，编排阶段性发生 | 跳转丢位置、未提交稿被替换；能否取消并继续原句？ |
| 逻辑演练作者 | 解释一条选择路径的实际状态结果 | 调试阶段高频，其余阶段可完全不用 | 把时间偏序当运行路径、选中即执行；能否区分定义与本次结果？ |
| 审阅者/修改者 | 识别提案目标、基线与冲突，再明确采用或拒绝 | 审稿阶段集中，不推断每日次数 | 误采纳旧基线或不完整修改；能否说明尚未应用什么？ |

尚无 USER 数据支持上述频率。EDS-12 应采实际切换、误改、恢复及分段耗时；不在本文填成功率、效率提升或满意度。

## 必须分开的五种结构

| 名称 | 回答的问题 | 禁止暗示 |
|---|---|---|
| 文件层级 | 源码和附件存在哪里？ | 文件夹嵌套等于国家/组织隶属 |
| 世界语义关系 | 作者显式声明哪些对象有何联系？ | 所有连线都可传递、对称或有因果 |
| 书稿阅读次序 | 读者按什么顺序阅读章节？ | 等于事件发生顺序或运行出口；CAP-02A/B 尚未交付 |
| 时间偏序 | 源码声明哪些事件/时段先后或包含？ | 必有绝对日期、统一世界时钟或唯一全序 |
| 可执行控制流 | 本次演练条件和选择允许走到哪里？ | 图上选中或拖动就执行，或自动改写历史关系 |

依据 CODE-C2/C3/C5；候选界面必须分别命名，不以一种树或时间线掩盖语义差别。

## 对象身份、来源与生命周期

| 对象 | 身份和来源 | 创建/引用边界 | 删除、失效与恢复边界 |
|---|---|---|---|
| 源文件 | Project 内工作区路径；源码原文为真源 | 工作区内显式创建，遵守活动源码集合；路径重命名不是永久不变 ID | 删除以墓碑进入缓冲；include/引用诊断来自 core；按 Project 快照与保存基线恢复 |
| 实体资料 | `TargetRef(entity,id)`；目录的 file/line 指向声明 | 显式 1.10，名称、别名是查找入口；不按同名合并 | 删除前 core 影响检查；改显示名保留身份，改 ID 须显式重构 |
| 地图标记实例 | map ID + placement ID；注册地图 JSON | 独立引用内容目标，有图层与几何；同一资料可有多个入口 | 删除实例不等于删除资料；锁层/未知能力受保护；引用失效显示原身份 |
| 语义关系 | `TargetRef(relation,id)`；relation_def 源声明 | 关系类型、方向、端点由作者明确指定；不从地图坐标推导 | 删除/端点重构使用 core；旧 CharacterRelation 不伪装成已有永久独立 ID |
| 事件/场景 | event ID / 限定 scene ID；源码声明 | 正文、选择和运行语句来自 core；浏览只选择对象 | 删除引用影响与编译诊断先于提交；演练会话不是源码快照恢复工具 |
| 正文显式引用 | 目标 TargetRef + 当前源文件/位置；位置随文本变化 | `[[kind:id|label]]`，纯显示提及不自动创建 relation_def | 不宣称每处引用已有独立永久 ID；修改前校验来源与基线，断链可定位修复 |
| 标签/别名/素材引用 | 各自声明或目标与来源位置；目录提供索引 | 按已有 core 契约写入；附件不得越界 | 不把删别名或删展示入口等同删目标；附件缺失保留诊断 |
| 批注/提案 | 独立文档 ID、锚点/受控文件及基线 | 明确作者意图后创建；提案提交不等于已经采用 | 失锚和陈旧提案保持可见；不能猜测锚点或强制覆盖 |
| 个人投影 | 本会话面板 ID、目标和历史，或个人镜头/筛选状态 | 不复制资料真源；现有保存网络布局等必须是单独显式操作 | 关闭/切工程可清理个人状态；不得进入内容撤销或删除资料 |
| 书稿/统一待办 | CAP-02A / CAP-03A 尚待契约 | 原型可展示明确标记的假数据 | 不能先在 UI 建第二套持久身份，再要求 core 追认 |

来源：CODE-C1/C2/C3/C4/C5。这里的“稳定”各有作用域：内容 ID、地图内实例 ID、会话面板 ID 与可变化的来源位置不能互换。

## 四条完整任务旅程

### J1 世界资料：建档并放到地图

1. 从资料库寻找目标，候选展示 kind+ID；同名需显式选择，不默认第一项。
2. 若缺资料，打开创建草稿，选择真实源文件与独立 ID。纯内容空工程不要求先创建可运行事件；1.9 工程明确不提供未启用的实体能力。
3. 已有能力可先创建资料，再在编辑展示模式创建标记；候选就地建档流程依赖 CAP-01A/C。不能把两个旧操作宣称为一个原子撤销。
4. 预览明确区分“资料”与“地图入口”。取消保留原工程；浏览模式、锁层、未知能力不得绕过保护。
5. 应用后从地图、库和正文到达同一 TargetRef；来源信息可回到声明。
6. 删除入口时不删实体；若明确删资料，先展示 core 引用影响。保存或切工程时保留未提交草稿与外部冲突。

验收问题：作者能否解释两个 ID？锁层失败是否留孤立资料？本文未执行用户测试。

### J2 长文：边写边查再回到原句

1. 打开现有正文/源文件，保留当前光标、滚动与未保存输入；空工程给出创建源码入口。
2. 从显式链接或候选词条进入临时阅读，同名以 kind+ID 消歧。
3. 需要持续旁查时钉住两个对象，各自链接/返回独立；窄窗口用可发现的切换控件。CAP-02C 本轮代码待实际双端验收。
4. 阅读内容从快照刷新；被删对象显示失效，不跳到同名替代品。只读工程仍可阅读。
5. 关闭旁查或返回编辑区，不改作品、不进入内容撤销、不覆盖已有表单草稿。
6. 正文内 @ 和选文建档属于 CAP-01B；书稿组织、状态、目标属于 CAP-02A/B。原型中必须显示“未来能力”，当前使用既有源文件/正文概览入口。
7. 保存遇外部变化保留本地稿，禁止旧表单覆盖。切工程先处理草稿，再清理旧工程个人导航。

验收问题：失焦与真正提交能否分辨？中文输入法组合态、Esc 与返回位置需要实际事件/用户证据。

### J3 逻辑演练：从定义到一次路径结果

1. 从事件或控制流进入，明确选择的源码对象及声明位置；时间偏序另行查看。
2. 编译失败先定位诊断；纯内容工程可以保存/浏览，但试玩入口解释“没有可运行事件”。
3. 显式开始演练，选择行为消费 runtime；浏览事件、状态、地图不会自动推进会话。
4. 比较初始定义与本次实际变化，保留条件和来源；未经过的分支不当作已发生事实。
5. 停止或重启不反写源码；源码修改后明确会话基于何快照，不把旧结果混入新稿。
6. CAP-06A/B 的确定性重放、检查点、失败条件定位属于未来增强，不将现有试玩包装为已经完成。
7. 非法存档/不兼容指纹按既有错误契约说明；切工程清理旧会话，但不能丢弃未提交创作输入。

验收问题：作者能否区分当前选中事件、控制流位置与世界时间？没有引擎适配路径。

### J4 审阅：理解来源后明确采纳

1. 从待审提案或批注进入，显示目标身份、原文件及基线；空列表解释为空，不伪造任务。
2. 同名对象不合并；批注失锚仍可见，不能自动绑定附近文字。
3. 使用现有提案预览检查原文件与候选结果；CAP-04A/B 的逐字段/逐段落三栏增强标为未来能力。
4. 只读或旧基线阻止写入，允许查看和保留输入。冲突需回到明确来源处理，不能在 UI 自行实现合并。
5. 明确采纳才调用 core 命令；取消不改变 Project。采纳后通过现有保存协议落盘；不能宣称跨文件磁盘原子性。
6. 持久历史和受保护恢复属于 CAP-04C/D；当前内容撤销不宣称可替代跨会话历史。
7. 切工程前处理当前表单/草稿，再清理个人选择。若不批准候选布局，保留原入口作为回退。

验收问题：审阅者能否指出当前只是预览，哪些内容真正应用？未知字段与冲突失败负例须进入后续验收。

## 旧 12 页面到候选入口的完整映射

以下是 HYP 入口归组，不是导航数量决定；允许共享外壳，不能删除表中能力。CODE-E1 是旧入口清单真源。

| 旧 Tab | 必须保留的关键入口/动作 | 候选可到达位置 | 不能混淆 |
|---|---|---|---|
| 正文概览 | 故事线筛选、事件正文、资料链接 | 写作预设的正文投影 | 不是书稿章节编排 |
| 时间线 | 时段、事件先后、来源与状态变化 | 结构观察/时间投影 | 不是运行播放头 |
| 事件关系图 | 事件/场景控制流定位与编辑 | 逻辑预设主区 | 不是世界语义关系 |
| 世界关联 | 显式语义关系、局部查询、保存视图 | 世界组织主区/关系投影 | 个人布局与共享布局分别提交 |
| 协作审阅 | 批注、提案预览、采纳与失败定位 | 审阅预设 | 不是未经批准的三方自动合并 |
| 地图画布 | 浏览、编辑展示、标记/图层/栅格、资料定位 | 空间投影 | 入口实例与资料身份不同 |
| 人物 | 人物资料、属性及已有关系入口 | 资料库类型筛选与检查器 | 不将全部人物自动迁成 entity |
| 资料与状态 | 标签、素材、状态、锚点及来源 | 资料库与相应详情 | 状态定义与实际演练状态不同 |
| Wiki 词条 | 名称/别名查询、出现位置、阅读/编辑 | 临时侧览、旁查、资料详情 | 自动关键词命中不创建语义关系 |
| 世界观 | 世界资料与属性编辑 | 资料库世界类型/检查器 | 世界资料不是作品全局任意配置 |
| 源文件 | 文件树、源码/JSON 原文、诊断跳转 | 文件投影与文档编辑区 | 文件层级不解释世界结构 |
| 试玩 | 显式开始、继续、选择、停止/重启 | 逻辑预设中的运行观察 | 运行操作不由图选择触发 |

共享命令还必须保留：打开/新建工程、保存、另存、完整导出、ZIP 导入导出、撤销/重做、搜索、诊断定位、冲突查看与救援路径、语言/能力状态、模板和展示预设入口。来源为 [工作区 UI](../../../../src/app/workspace.rs)、[应用动作](../../../../src/app.rs)、[桌面打包](../../../../src/app/package.rs)、[浏览器工作区](../../../../src/app/browser.rs)。跨端不支持项必须明示，不能用按钮存在推断已经支持。
