## 研究问题、参与者与顺序

问题是：同一组作者任务下，候选 B 相比 A 固定三栏，能否在不增加误写、丢稿、失去焦点/目标的前提下，让作者更快找到正确入口并恢复原工作？C 自由布局只作为结构理解/风险探查；它尚非完整产品候选。预先保留拒绝 B、缩小 B 或回到 A 的决定空间。

建议 6–8 位目标作者，覆盖首次使用者、已有世界资料经验者、长文作者和有逻辑演练/审阅经验者；同一人可兼多个角色。招募来源、经验、设备熟悉度与实际人数匿名记录；人数变更时写明原因，不作统计显著性承诺。每位在 A/B 两种布局上完成等价但内容不同的任务，半数先 A 后 B、半数先 B 后 A；任务数据/目标/冲突难度对齐，顺序和训练时间记录。C 可在末尾短探查，不能和 A/B 结果混算。指导语只说目标，不提示具体按钮或布局优劣；主持人介入记为事件。

## 四个等价任务包与安全门

| 任务 | 成功终点 | 关键观察/错误 |
|---|---|---|
| J1 世界资料 | 找到资料 B 的两个地图入口，定位 P，说明 P 与 B 各自 owner；锁层下取消无残留 | 同名选错、把入口删除等同删资料、拖放失败仍改 Project |
| J2 长文旁查 | 在 A 的指定句选词，旁查并固定 B，返回 A 原光标/选区继续输入 | 输入丢失、光标/滚动未恢复、IME 误触、旁查覆盖主稿 |
| J3 逻辑演练 | 找到 E 的时间约束和控制流区别，预览后再显式运行一次 | 把偏序当运行路径、看图推进 runtime、无日期伪排序 |
| J4 过期审阅 | 发现 R 的外部更新，保留本地解决草稿，重新比较后取消或明确采纳 | 旧基线强制覆盖、默认字段赢家、冲突提示被折叠隐藏 |

任何实际作品丢稿、错误对象写入、只读/未知能力越权写入、陈旧基线覆盖都构成安全门失败：停止该路径，保存匿名复现材料，候选不得进入生产实施，先修复并重新测试。外观满意度不能抵消安全失败。测试使用可清理的样例作品，不接真实私有作品；原始文本/截图去除身份信息后存储。

## 记录字段与计算口径

每段计时分为“读目标→第一次正确入口”“入口→正确对象”“对象→完成操作”“错误/中断→恢复”，记录原始时间戳而非只记总秒数。每个任务记录独立成功、需提示成功、失败，误改/误触次数，查找动作、投影切换、恢复入口次数，取消/返回成功，作者原话与观察者备注；不把一次停顿推断为不理解。浏览零 Project 写入由前后内容指纹和撤销栈观测。所有稿件版本、原型分支 SHA、worldline 配对 SHA、平台、窗口逻辑尺寸、实际 DPI/浏览器缩放、输入法与设备一并记录。

匿名原始记录每人一份，建议字段：`participant_code, experience, platform, input_method, order, task, variant, dataset_id, start/end timestamps, segments, success_category, miswrite_count, draft_loss, wrong_owner, lookup_count, switch_count, recovery_count, hint_count, verbatim_quote, observer_note, project_hash_before/after, screenshot_ref`。空值写 `未测`，不得填 0 冒充已测。原始证据不直接提交含个人信息的仓库；可提交去标识摘要及可复现的样例作品标识。

只描述观察到的样本：任务成功人数/分母、误写/丢稿事件、各阶段耗时的中位数和范围、恢复成本与原话；小样本不作普适效率提升或显著性声明。性能另按冷启动/暖运行、平台、DPI、内容规模、运行次数报告 P50/P95/最差、内存峰值与采样方法；旧基线只能明示并列，不能借旧数字当新结果。静态检查、真实交互和作者理解分别报告，不互相代替。
