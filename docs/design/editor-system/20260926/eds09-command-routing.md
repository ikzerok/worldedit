# EDS-09：统一命令、工具模式、焦点路由与撤销

关联 worldedit#40。依据 [EDS-03 状态契约](eds03-state-contract.md)、[EDS-05 图文交互](eds05-cross-projection.md)、[EDS-08 写作旁查](eds08-writing-preview.md)。本票是命令与事件设计契约，不宣称当前代码已经有完整命令总线，也不在 UI 重写 core 的解析、身份、权限或合并。

## 命令描述与执行边界

每个可执行操作有唯一 `id`，中文 `label`，明确 `owner`（project/对象/字段/面板/运行会话）、`allowed_contexts`、类型化 `arguments`、`enabled_reason`、`preview`、`commit`、`undo` 和 `persistence_domain`。菜单、按钮、快捷键、右键与无拖动替代入口只是同一个命令的调用者，禁用原因与结果一致。危险写入若 owner 不可唯一确认，禁用并说出当前冲突对象；不能猜最后点击的窗格。界面仅收集意图、展示候选和 core 返回的结果；结构、解析、合并与引用影响由 core 唯一决定。

| 命令例子 | owner 与域 | 预览/提交 | 撤销/失败 |
|---|---|---|---|
| `navigate.reveal_target` | 带类型目标、个人会话 | 预览/定位只改选择和镜头 | 返回栈；不进入内容撤销 |
| `map.move_placement` | map+placement、作者共享展示 | 拖动中几何候选，释放后基线校验一次提交 | Project 内容撤销；锁层/过期保持原实例 |
| `source.insert_reference` | file+选区基线、作者源码 | 候选显示 kind+ID，确认调 core 组合事务 | Project 内容撤销；IME/陈旧选区拒绝 |
| `run.step` | runtime 会话及编译快照 | 显式执行，无“看一眼就走一步” | runtime 返回/重放按其能力；不改 Project |
| `layout.reset` | 个人布局偏好 | 显示影响区域 | 只重置个人布局；不触内容撤销 |
| `text.undo_local` | 有焦点文本控件/未应用草稿 | 控件自身处理 | 只撤销本地输入；不动已应用 Project |
| `project.undo` | 当前 Project 修订 | 显示将撤销的已应用内容命令 | Project 撤销；不清个人布局/未应用输入 |

每个 `commit` 返回成功/只读/陈旧/冲突/校验失败和新基线等可见结果。预览与查询零 Project 写入；“应用缓冲”和“保存到文件”各有不同命令及反馈。工具模式（选择、拖动、连线、框选等）是编辑区的会话状态，不替代命令 owner；离开模式先结束/取消局部动作。用户宏和随意拼接命令不在范围。

## 路由优先级和焦点矩阵

路由顺序固定：最上层模态 → IME/文本控件 → 有焦点编辑区 → 全局安全命令。焦点标记比鼠标悬停优先；悬停只产生预览。Web 浏览器保留平台快捷键时，界面不能声称已拦截；提供可点/键盘可达菜单后备。每个命令在菜单显示实际可用快捷键，冲突时只保留一个有效绑定并解释禁用原因。

| 当前接收者 | Delete / Backspace | Escape | Ctrl/Cmd+Z | 字母工具键 / Enter |
|---|---|---|---|---|
| 模态确认/冲突 | 不穿透到背景 | 先取消当前模态，保留草稿 | 模态内文本则本地撤销 | 只操作模态按钮/文本；不可触发全局工具 |
| 中文 IME 组合中的文本 | 由 IME/文本控件处理 | 先由 IME 取消组合，不关窗口 | 文本控件处理已提交的输入 | 只组成文字；不唤工具、不选择候选 |
| 普通正文/参数文本 | 删文本或选区 | 关闭候选/局部预览，未应用草稿仍保留 | 未应用部分本地撤销，已应用内容另有清楚入口 | Enter 按控件语义；候选框优先于图命令 |
| 地图/图编辑区有焦点 | 仅当单一 owner 和能力确认才删除对象 | 先取消拖动/连线，再退出临时工具 | 已应用命令走 Project 撤销；布局移动可走个人位置撤销 | 仅当前编辑区的可用工具命令 |
| 资源抽屉/检查器有焦点 | 当前控件处理；固定 B 须明确 owner | 先关内层候选，再关抽屉/表单 | 按草稿或 Project 域选择，不改选中的 A | 不因画布 hover 触发图命令 |
| 没有明确焦点 | 禁用危险删除并提示 | 取消最内层仍在活动的会话动作 | 不猜最近点击对象；可显示撤销目标供确认 | 只允许全局安全导航/查找 |

`Ctrl/Cmd` 由平台映射，Web 中浏览器占用组合键时展示替代菜单；触控没有 hover，所有常用命令都有可见按钮。焦点从临时侧览/模态关闭后回到发起控件及原光标；如果已失效，落到稳定、可见的主区域入口并告知。焦点不可被浮层遮住；按钮有可访问名称、角色、启用状态，错误与禁用原因能被键盘访问。

## 分层取消与等价操作

Escape 顺序：IME 组合 → 当前候选/自动完成 → 拖动/连线预览 → 子菜单/抽屉 → 当前表单或模态 → 临时工具模式。每一步只处理最内层 owner；有未应用草稿时关表单要保留或明确选择，不直接丢弃。`pointer_move` 仅预览，`pointer_up` 至多发起一次提交；核心拒绝后恢复原几何与输入，不能留下半条边。确认后的 Project 修改使用对应内容撤销，不再以 Escape 伪称未写入。

拖动有等价路径：地图实例可从列表选中后用“移动到坐标”精确输入并预览；连线可从源节点的“建立连接”菜单选择目标/关系类型；书稿重排可用“上移/下移/移至章节”命令；图平移/缩放有键盘与菜单入口。等价路径使用同一命令 ID 和校验，命中区/焦点/状态可读；不能只为鼠标和触屏提供安全检查。复制/粘贴仍以实际有焦点文本为 owner，不能在未应用正文中误触全局粘贴节点。

## 验收矩阵

| 路径 | 必须观察 |
|---|---|
| 同一地图移动从按钮、菜单、快捷键进入 | 相同 owner、预览、只读/锁层原因、提交结果和一次撤销 |
| 正文中文组合中 Delete、Enter、Escape、字母键 | 只影响 IME/文本；不删图对象、不提交引用、不切工具 |
| 固定检查器 B、画布选 A、焦点在 B 表单 | 所有命令标 B；A 不因选择被写；退出返回原焦点 |
| 连线中 Escape、失效目标、只读 | 候选零写，取消只退最内层；输入和原图可恢复 |
| 文本本地修改、Project 已应用修改、个人布局改变 | 三个撤销/重置 owner 明确，互不覆盖，反馈指明受影响域 |
| Web 平台快捷键被浏览器占用 | 菜单可达，提示实际快捷键；不会吞输入或伪称成功 |

验证需使用真实 egui 输入事件与公开 Project/core 边界；目前只有设计与现有局部测试，不能把本矩阵记为通过。无法确认 owner 时回退为只读检查并解释，而不是借悬停猜测。
