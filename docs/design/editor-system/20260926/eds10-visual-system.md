# EDS-10：按状态组织的视觉系统与组件规范

关联 worldedit#41。依赖 [EDS-04 布局](eds04-layout-comparison.md)、[EDS-05 跨投影](eds05-cross-projection.md)、[EDS-06 检查器](eds06-inspector-drafts.md)、[EDS-07 图例](eds07-graph-grammar.md)、[EDS-08 写作](eds08-writing-preview.md)、[EDS-09 命令](eds09-command-routing.md)。这是待验证候选规范，不批准替换现有主题，也不宣称完整无障碍认证。旧深色、间距、图标与 880 逻辑点行宽均可推翻。

## Token 角色与禁用混用

| token 类 | 作用 | 不能代替 |
|---|---|---|
| `surface` | 主文稿、工具区、浮层、冲突层的层级与边界 | 不能仅用阴影隐藏冲突和只读原因 |
| `text` | 正文、辅助、禁用、代码/ID 的可读层级 | 浅灰不能用来表示“无关紧要”的错误 |
| `state` | hover、selection、keyboard focus、active tool、dirty、preview、error、conflict、read-only | 选择、焦点、活动工具和未保存不共用单一颜色/图形 |
| `edge` | 时间约束、控制流、语义关系、书稿引用的各自线型/箭头/文字图例 | 颜色不能独自承载关系类型或来源；布局线不冒充语义边 |
| `spacing` | 组内、组间、区域边界和最小触达间隔 | 紧凑模式不能挤掉完整焦点轮廓与错误摘要 |
| `type` | 正文、标签、ID、长文、代码的字级与行高 | 不用等宽字体承载所有长文，也不靠字号区分只读/可写 |
| `motion` | 面板/预览过渡的时长与降动效规则 | 动画不能暗示保存完成、运行已推进或掩盖失效 |
| `hit_target` | 图元、按钮、菜单、拖动把手的可操作区域 | 图标视觉大小不等于命中区域，hover 不能是唯一入口 |

每个 token 变化关联具体任务和验证记录：例如提高正文行距只服务 J2 长文阅读，增加关系边文字标签服务 J1/J3 的类型辨识，强化冲突层级服务 J4 的过期提案。没有对应任务证据时保留候选状态。主题由语义 token 映射到明/暗、舒适/紧凑组合；布局、owner、命令状态与文本内容不因换主题变化。

候选浅色的普通正文 `#24303b`/`#ffffff`、辅助文字 `#52606d`/`#ffffff`、白字按钮 `#ffffff`/`#1768be` 分别按 WCAG 相对亮度公式算得约 13.45:1、6.46:1、5.58:1；候选深色 `#edf2f7`/`#182635` 与辅助 `#bbcfe1`/`#182635` 约 13.63:1、9.60:1。它们只是特定色对的数值，不能替代真实悬停、禁用、图形、半透明叠层和最终平台渲染检查。普通 Web 文字参考至少 4.5:1，大字存在 3:1 条件；不能四舍五入未达阈值的结果。[W3C 对比度说明](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)。

Web 指针目标参考 24×24 CSS px 或标准列明的间距/等价等例外，拖动动作要有单指针非拖动后备；原生 egui 逻辑点和 CSS px 不直接等同。键盘焦点至少不被作者内容完全遮蔽，项目原型优先采用完整可见焦点与滚入视野。[W3C 目标尺寸](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)、[拖动后备](https://www.w3.org/WAI/WCAG22/Understanding/dragging-movements.html)、[焦点遮挡](https://www.w3.org/WAI/WCAG22/Understanding/focus-not-obscured-minimum.html)。上述标准是 Web 参考口径，不能把局部色比检查称为全应用符合性认证。

## 组件状态矩阵

每个可交互组件至少定义以下状态的语义、视觉、文字/辅助信息和键盘行为。状态可叠加，例如 `selected + keyboard_focus + dirty`；不能互相覆盖。

| 状态 | 可见规则 | 必须可读的信息 |
|---|---|---|
| default | 稳定边界与标签 | 对象 kind/ID 或命令名 |
| hover | 轻微表面/边框变化 | 只做辅助提示，不给独占命令 |
| focus | 独立高对比外轮廓，窄窗滚入可见 | 可访问名称与当前操作范围 |
| selected | 固定选中形状/列表标记 | 所选对象身份；与 focus 同时可见 |
| disabled | 控件仍可发现，说明不能执行 | 禁用原因与恢复入口 |
| read-only | 属性可看/复制，提交禁止 | 只读来源、能力或锁层原因 |
| dirty | 内容尚未落盘的标记与文字 | “应用缓冲”还是“未保存文件” |
| preview | 虚线/临时色及“预览”文字 | 尚未写入、取消入口 |
| error | 字段定位 + 组标题错误数 | 中文诊断及修复方法，折叠时仍可见 |
| loading | 进度/占位而不挪走 owner | 上次有效内容、取消/等待界限 |
| empty | 任务相关空态与创建/返回入口 | 无数据、无匹配与无权限分开 |
| conflict | 高优先级层与 base/current/proposal 入口 | 输入保留、不能默认覆盖 |

图节点/边、地图标记、正文链接、检查器字段、命令按钮、资料候选、阅读标签和诊断行均按矩阵逐项审查。未实现的状态用明确的“样例”文案而不是伪装可执行。焦点与选择在图上同时出现时轮廓形状不同；运行位置另有文字徽记，不能与 hover 共用高亮。错误/风险不能为了减噪被折叠成不可发现的角落。

## 四任务与主题/密度比较

| 任务 | 舒适/紧凑需比较 | 明/暗需比较的代表状态 | 窄窗/失败状态 |
|---|---|---|---|
| J1 世界资料与地图 | 图标命中区、长标签、密集索引 | 入口 P 选中、资料 B 固定、锁层与预览 | 图裁剪/截断、只读层、坏目标 |
| J2 长文写作旁查 | 正文行宽、行高、辅助栏占比 | 光标焦点、选文、B 固定、未应用草稿 | 窄窗标签、IME、长段复制、失效引用 |
| J3 演练 | 图边文字、运行位置、时间偏序并列 | 选中 E、预览分支、实际 runtime 位置 | 条件长标签、错误诊断、无日期 |
| J4 审阅 | 三方对照列宽、字段差异密度 | base/current/proposal、冲突、禁用采纳 | 窄窗逐列切换、外部刷新、输入保留 |

先以无品牌中性色结构样例比较两种亮度和两种密度，记录可读性、误认状态、找恢复入口、滚动/缩放成本，再决定 token 值；不按“深色更专业”选择。设计原型必须至少有 J2/J4 窄窗和失败画面。若某个视觉 token 与安全操作或可达性冲突，回退 token 或结构，不牺牲诊断/取消/恢复入口。现阶段没有参与者结果，高保真定稿与全组件生产化仍待后续验收。

独立 `codex/eds04-prototype` 分支的 [低保真 HTML 比较](https://github.com/ikzerok/worldedit/blob/5e44564/docs/design/editor-system/20260926/eds04-prototype-throwaway.html) 提供 A/B/C 结构、四任务、明/暗、舒适/紧凑、窄窗、只读与陈旧草稿的相同示例状态，`node --check` 通过。它只回答结构和状态能否被区分；还不是本票要求的高保真组件覆盖，也没有真实平台的目标尺寸、焦点遮挡或作者理解测试。
