# 按当前范围审稿并交付Markdown

工具0.32在原有书稿树、列表、卡片及全分支审稿上增加“当前筛选范围”。筛选仍由core处理，不新增跨书稿集合或第二份正文。

## 完整路线

1. 打开书稿，用文字、状态、POV或“仅此分节”筛选。导航显示的匹配数量覆盖整个书稿范围
2. 打开阅读预览，切到“当前筛选范围”。核对条件，点击“生成同范围审稿”
3. 等待真实逐章进度；需要时点击“取消生成”。整批包含匹配的全部章，当前导航页和折叠分节不会漏掉其它匹配章
4. 在“连续审稿与来源”逐批阅读。每批按core实际节点/字节预算分界，最多8章；批数和当前完整读序范围会明确显示。范围显示编排出现数、唯一源数及重复次数；缺源或坏章保留错误占位，不漏掉后续章
5. 点击“定位原文”进入准确的当前文件草稿，用“返回审稿”或Alt+Left返回原查询、章节和审稿模式。来源锚仍一致时恢复原正文选区和滚动；正文修改后不恢复旧正文选区。同一份审稿材料仍在时可恢复其原批次与滚动；若已修改正文，材料继续标为过期
6. 修改后旧审稿标为过期。再次点击“生成同范围审稿”，明确生成新版
7. 切到“完整Markdown原文预览”，核对范围和全部文字，勾选作者私密材料确认，再复制或导出

Ctrl+Shift+R仍切换编辑/审稿。来源按钮支持Tab聚焦和Enter，输入法组合中不会抢走作者位置。高度充足时范围控件与正文分别滚动；真实剩余高度较小时，完整筛选、来源说明、Markdown选择与复制/导出放入可滚动的“范围与交付”菜单，生成/取消仍可直接操作。批次与正文共用一个滚动内容区，Markdown分段说明与原文也共用滚动区，避免200%缩放下只有头部能滚、正文和批次落在视口外。长条件和路径仍可换行。

## 这份材料包括什么

材料明确区分已应用工程稿与包含未应用正文/编排的当前稿。可展开已纳入正文文件列表，逐一查看工作区相对路径、草稿代次和字节数。生成时列出被排除的未提交表单、未插入输入和其它草稿，不会自动应用它们。

全部条件分支和各选择按静态源码顺序保留。条件、随机和状态没有执行；call只显示未展开的调用说明。书稿顺序不代表一条真实路线。同名章仍按稳定ID区分，同一源被编排两次会完整出现两次。

Markdown是作者私密审稿本，与公开阅读站授权分开。不会自动增加公开章，不附带源文件全文、物理路径、隐藏JSON、批注、运行值或附件。Markdown中的用户文字会转义，不当作HTML、图片或脚本运行。

## 复制、文件和过期

完整预览将core生成的Markdown原文按UTF-8安全边界连续分页，每段标明字节区间和总字节数；用“上一段原文/下一段原文”读完全部内容。分页切片拼接后与完整原文逐字相同，长行、中文、emoji和原有行尾均不改写。复制和导出始终使用完整材料，不限正在显示的一段，也不重新整理或渲染。

桌面选择工作区外、父目录已存在的全新`.md`绝对路径；目录链含符号链接、联接或非目录会拒绝。已有目标不会覆盖。先写入并同步完整暂存文件，再无覆盖发布，不改变工程保存状态。浏览器显示“已请求浏览器下载”，无法保证浏览器已经写到磁盘。

仅打开原文查看并返回，正文、编排、筛选和工程观察均未改变时，材料仍有效；打开未改动的正文文件不会成为新增草稿输入。正文实际修改、编排、筛选或工程观察变更后，旧材料留作只读证据，来源、复制和导出停用；没有后台热替换。取消或失败保留输入和原位置，不产生新交付材料。导出再次核对完整来源，外改或恢复冲突不能被旧预览绕过。

不完整范围和坏章必须先修复，不能导出残稿。零匹配会得到明确零章材料，不表示作品没有问题。默认完整交付限4096章、100000节点、4MiB范围身份、16MiB审稿投影、8MiB Markdown；达到预算应明确缩小筛选，而不是无声截断。

首版只有真实Markdown交付，不承诺DOCX/PDF/EPUB、印刷页码或双向批注导回。机器使用说明见同级worldline仓库的 `docs/manuscript-delivery.md`。
