# 地图浏览

从左侧导航进入“地图画布”，在右侧选择已注册地图。首次显示会适配画布。滚轮围绕鼠标位置缩放，拖动画布平移；“适配全图”重新显示整张地图，“重置镜头”恢复原尺寸和原点。地图可以没有栅格图层，点、折线和多边形使用地图自己的坐标。

右侧图层开关只改变当前浏览显示。点击标记可查看说明、用途和关联对象，选择“打开资料”阅读对象当前内容。浏览操作不会修改地图文件，也不会产生撤销记录。

工具栏中的“临时绘图预览”提供选择、点、线、面四种工具。点按或拖动会先显示在本地渲染草稿中，提交前会检查坐标范围、点数、退化和面边界自相交；不合法的操作会显示中文原因并被拒绝。线和面双击完成，Esc 取消当前草稿。预览明确不保存到工程，也不产生撤销记录；“放弃预览修改”会退出临时预览并丢弃本地绘图。

PNG/JPEG 素材缺失、格式不支持或超过平台预算时，界面显示占位和原因。桌面图片边长上限 4096，浏览器为 2048；纹理缓存预算分别为 128 MiB 与 64 MiB。地图结构错误由 core 提供诊断，其他有效地图仍可浏览。

当前入口提供已有地图的阅读和临时绘图预览，创建地图与保存标记编辑由后续标记、图层功能交付。地图须在作品的 `.world/project.json` 注册；开发验证样例及格式位于配对 worldline 仓库的 `spec/examples` 和 `spec/presentation.md`。作品应放在独立目录。

浏览器使用导入时的工程快照；素材或地图在磁盘上变化后，需要重新导入。
