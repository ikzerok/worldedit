# 地图浏览

从左侧导航进入“地图画布”，在左侧地图索引选择已注册地图，右侧查看当前选择或图层/对象树。首次显示会适配画布。滚轮围绕鼠标位置缩放，拖动画布平移；“适配全图”重新显示整张地图，“重置镜头”恢复原尺寸和原点。地图可以没有栅格图层，点、折线和多边形使用地图自己的坐标。

浏览模式下右侧图层开关只改变当前浏览显示。点击标记可查看说明、用途和关联对象，选择“打开资料”阅读对象当前内容。浏览操作不会修改地图文件，也不会产生撤销记录；定位隐藏图层时，确认“临时显示并定位”也只改变本次浏览。

地图、搜索和 Wiki 共用同一资料窗口。窗口中的“地图中的位置”列出该对象的全部标记，没有标记则显示“未放置在地图上”；选择位置与地图页对象反查使用同一个定位动作，隐藏层仍先询问临时显示，不复制或重写资料。

有子地图入口的标记提供“进入子地图”。右侧访问路径记录实际经过的地图，允许循环和不同入口；“返回上一级”恢复上次离开该地图时的镜头，最多保留最近 64 步。阅读资料不会清空地图路径。这些状态只影响本次浏览，不生成地图归属关系或撤销记录。

资料编辑区的“引用来源”同时列出内容引用与地图标记，可跳转到来源或定位标记。删除事件前由 core 重新查询影响计划；仍有引用时须先明确解除或重新绑定，内容或地图损坏导致检查不完整时也会拒绝删除。取消删除不会修改工程，删除标记不会删除资料。

进入“编辑展示”后，未启用 scene 的地图保留选择、点、线、面与独立文字工具；显式启用矢量工具后，还可直接拖绘矩形、椭圆、Bezier 与多子路径，并编辑真实节点/控制柄。新标记和已有标记的拖动会先显示本地草稿，提交前由 core 检查坐标范围、点数、退化和面边界自相交；不合法的操作会显示中文原因并被拒绝。线和面双击完成，Esc 取消当前草稿；单击已有标记只改变选择，不创建历史。一次真实拖动提交一个展示命令，可用一次 Undo 撤销；Delete 只删除展示标记，关联资料仍保留。编辑模式中的默认可见性、图层锁定和上下重排会明确写入地图文档，取消预览会恢复未提交的本地状态。

地图 JSON 损坏时可在源码页修复有效 UTF-8 的原文；原始字节不是有效 UTF-8 的文档只提供只读预览，原字节保持不变。素材缺失、断链或其他诊断会提供对应的打开原文、重绑定或修复入口，不会用空文档覆盖作者内容。

PNG/JPEG 素材缺失、格式不支持或超过平台预算时，界面显示占位和原因。桌面图片边长上限 4096，浏览器为 2048；纹理缓存预算分别为 128 MiB 与 64 MiB。地图结构错误由 core 提供诊断，其他有效地图仍可浏览。

“编辑展示”中的[新建空白地图](map-creation.md)会为旧工程补齐清单并注册新地图，不要求启动试玩。地图注册于作品的 `.world/project.json`；开发验证样例及格式位于配对 worldline 仓库的 `spec/examples` 和 `spec/presentation.md`。作品应放在独立目录。

浏览器使用导入时的工程快照；素材或地图在磁盘上变化后，需要重新导入。

## 原生矢量与安全 SVG（0.15）

完整作者流程、viewBox/affine/根 viewport 保真、共享渲染资源和验收边界见 [矢量作者契约](vector-authoring-0.15.md)。地图工具与选择操作位于上下文工具条，右侧检查器提供 typed 几何、文字片段、样式、变换、对象绑定和导航；图层/对象标签保留稳定树序、显隐锁和多选。

“导入 SVG”选择本地文件或粘贴源码，后台由 core 安全预检。预览与确认应用共享核心 viewport 变换；确认一次添加独立图层，曲线、控制柄、多子路径及 Close 保持原生可编辑，不再把新的作者导入降成近似折线。旧地图第一次导入在同一事务显式启用 scene，可整体撤销。失败保留输入和位置诊断，取消零工程变更。

支持的元素、路径、基础文字/样式、变换与最小根 viewport 矩形裁剪以配对 core 的 `spec/vector-scene.md` 为准；不支持项整批拒绝，不宣称接受任意 SVG。脚本、外部资源、任意 clip/mask/filter 与嵌套 svg viewport 不会被静默执行或丢弃。

旧标记需要作者选择“预览迁移本层全部旧标记”或全图迁移，核对稳定 ID 后确认。迁移保留引用/批注与层叠顺序，移除旧持久表示；不自动留下另一份副本。非连续分组跨过未选兄弟时，核心警告在确认预览中列出，不能无提示改变叠放。

“导出矢量 SVG”后台生成已应用文档默认可见的旧标记与 scene，按每层真实顺序输出；个人临时显隐和未应用草稿不进入该交换文件。源码可完整复制或保存，目标已存在时拒绝覆盖。raster、资料正文与附件仍由完整工程备份保留。SVG 交换不推进工程保存状态。

画面按实际 zoom 与 DPI 重绘；新矢量与导入预览共享最多两个实际渲染任务，容量不足明确指出图层与预算，不降 DPI 或悄悄漏层。具体 RGBA 缓存/工作缓冲与内部合成表面额度按正式契约和 core 阈值表执行。

## 独立文字标签（工具 0.5.0）

进入「编辑展示」，点选「文字」，在地图上点按文字左上角位置；面板填写纯文本，再按「保存文字标签」。这不会创建地点资料，也不需要关联对象。输入前可以取消草稿或按 Esc，取消不写地图。

支持中文与最多4行普通换行，总计最多160个Unicode字符。字号12–64为地图逻辑单位，随地图缩放；浅白、墨色、琥珀、青蓝提供常用颜色，使用内置字体。文字不解析Markdown/HTML，不支持外部字体或富文本。

「选择」工具点选文字后，在面板按「编辑文字标签」修改内容、字号、颜色或删除；拖动文字本身移动锚点，释放后一次提交。每次保存/拖动可一步撤销；隐藏图层上的文字不显示，锁定图层不可改。编辑草稿期间画布不会写入其他几何，以免丢失草稿；外部地图变化导致旧草稿保存被拒绝时，先复制草稿文字，取消后重新选择标签编辑。

保存工程后重开保留标签；面向读者发布仍要逐项选择文字标签，不会自动公开所有标签。发布文字被安全转义，尖括号仅作为文字显示。

兼容提醒：首次保存独立文字标签在该地图内登记必需能力 `presentation.geometry.text.v1`；不支持该能力的旧编辑器将该地图只读保留，需新版编辑。既有点标记「自定义标签」保持原样，不做批量迁移。

## 两点校准与只读尺子

先进入「编辑展示」，在工具栏选择「两点校准」（已有比例时为「重新校准」），在地图内依次点选参照点 A、B。填写两点之间的已知距离和单位，再按「确认保存校准」。距离须为有限正数，可用科学计数法；单位为 1–24 个 Unicode 字符的非空纯文本，不接受控制字符。比例只由作者输入决定，程序不猜测实际单位，不进行千米、米、里等单位换算。

参照点齐备后冻结，防止填写时误点改线；需要重选时按「重选两点」。确认前只是本地草稿，不修改地图；「取消校准」或 Esc 零写入。未确认校准会阻止切图，工具栏始终保留取消入口。浏览/编辑展示切换会保留校准输入和原有绘制草稿；浏览时校准暂停，返回编辑展示再继续。请先完成或取消已有绘制、文字或 SVG 表单，再开始校准。

确认后生成一个可撤销的展示命令；保存工程后重开仍保留比例，重新校准也可一次撤销。外部变更导致基线冲突时保留两点和输入，不覆盖新文档；可按当前版本重试或取消。首次确认在该地图登记必需能力 `presentation.measurement.v1`，旧版本不理解此能力时只读保留该地图。

完成校准后，浏览模式点「尺子 · 只读」，依次选择起点 A 和终点 B，画布及工具栏显示平面直线距离；第三次点按重新开始。拖动可平移、滚轮可缩放，缩放、窗口尺寸、平移和适配全图不会改变测量值。测量使用地图逻辑宽高和归一化端点，不依赖屏幕像素或栅格图片分辨率；不是地球测地距离，也不沿路线绕行。重合点、越界点或超出可表示范围的结果会明确报错。极小与极大距离用科学计数法显示，不将非零距离误报为零。

尺子的点、线、结果与开关均为临时浏览状态，不写入工程、不产生撤销记录；「清除测量点」、「退出尺子」、Esc 或切换地图可清除。完整工程导出保留已确认的校准；面向读者的网站不公开校准数据或临时尺子，也不会因此添加网站脚本。


## 有界 SVG 虚线（工具 0.16）

矢量样式检查器和新建样式可选择继承、实线、航道 15/12、短虚线 6/4，或逐项自定义数列和独立偏移。数值使用图形本地 user unit（SVG 中也接受 px），随 Affine 和视图一起缩放；奇数列表逻辑重复，全零显示实线。不会把曲线改成离散线段，也不会在打开旧图时自动启用能力。

应用继续走核心 SceneBatch 的预览、基线检查与一次撤销。超长数列、过密虚线、负长度、非法单位或非有限值会保留当前输入并整批拒绝；不要通过删属性把拒绝当作成功。文字/tspan 的非零虚线暂不支持，应为文字或相应片段明确选择实线，不能把全图静默改成实线。核心限额与能力契约见同级 worldline 的 spec/vector-scene.md。

导入预览、桌面画布、浏览器 worker、整图/选择 SVG 与阅读站使用同一个带能力保护的 typed scene 和安全 serializer。完整工程保存保留未知可选样式扩展；“样式应用到全部选择”只复制已知字段，仍保留每个目标自己的扩展。
