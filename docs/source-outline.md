# 当前源码结构与可信定位

0.25 的“本文件结构”服务于普通“源文件”编辑页。它列出当前文件中正式语言解析确认的显式声明，帮助作者在一份长稿内辨认与跳转；不会改变书稿编排、事件执行顺序或作品正文。当前仍须以[版本说明](https://github.com/ikzerok/worldedit/blob/main/docs/releases/v0.25.0.md)核对完成的验收范围。

## 打开与定位

1. 打开一份源文件，也可用 Ctrl/Cmd+P 按文件名或对象来源找到它
2. 点击“本文件结构”，或按 Ctrl/Cmd+Shift+O；编辑菜单与任务命令也提供入口
3. 按名称、完整 ID 或类型筛选。每项以显示名为主，类型、稳定 ID 与真实行号辅助区分；同名声明不会自动合并
4. 用上下键选择，Home/End 到首项/末项，Enter 定位；直接选择可见项也可以定位
5. 定位发生在同一份源码缓冲，选中精确声明头，不切换为另一份表单。Esc 或“收起并回到源码”关闭列表并归还编辑焦点
6. 使用“返回作者位置”或 Alt+Left 返回。原文版本一致时恢复选区与滚动；稿件已改变时不套用旧字符偏移，保留当前稿并说明原因

查询刚改变、结构刚刷新或输入法正在组合时，不会把同一帧的 Enter 用来执行旧选择。视野外的选择先显示出来再定位。列表是临时浮层，收起后源码恢复原有编辑面积；窄窗不常驻增加一个大侧栏。

## 看懂当前编辑位置

文件标题下的“编辑位置”表示源码光标所属的最深显式声明。它与图上的选择、目录里的对象及试玩的运行位置不同。光标在注释、空白、独立关联行或无法确认归属的位置时，不猜测最近声明。

结构保留源顺序与真实嵌套。事件与嵌套场景可分层，场景使用完整路径；人物、实体、规则、片段和其它支持声明按自身来源列出。period 的包含关系属于世界资料，不会伪装成源码缩进。正式支持范围与预算见[core契约](https://github.com/ikzerok/worldline/blob/main/spec/source-outline.md)。

当前项和键盘选择是不同状态：当前位置有文字标记，键盘待定位项有焦点轮廓。中文长名允许换行；类型和 ID 帮助辨认相同标题。

## 当前稿、错误与外部变化

结构来自 core 对精确当前源码的正式解析。普通源码编辑、撤销/重做、文件切换或工程刷新后，旧结构不能继续用旧坐标定位。点击定位前仍要校验工作区、活动来源、当前正文、内容基线、外部刷新代次和磁盘保存基线。

输入法组合或未提交的输入无法与当前来源确认一致时，界面明确提示暂不可定位，完整输入继续保留。语法坏稿、未知能力、非活动来源、外部冲突和未完成保存事务不使用此前成功列表。空文件或没有显式声明的合法文件仍可直接编辑，不属于错误。

这些操作是只读导航，不自动应用表单、保存、创建撤销记录或执行故事。修改源码仍走原有编译、撤销与保存路径；保存是否成功以现有状态栏为准。

## 范围

本轮不改变书稿“写作/结构/源码”模式，不提供符号重命名、跨文件移动或全工程重构，也不新增 CLI/RPC 遥控编辑器。共享 Rust API 与编辑器使用同一 core 投影；机器接口范围见[CLI覆盖表](https://github.com/ikzerok/worldedit/blob/main/docs/cli-coverage.md)。

超出有界源码、行、深度、声明数或输出预算会整份提示不可定位，而不会把截断列表当完整结果。原文始终保留；作者可以继续编辑或用既有文件组织功能拆分稿件。
