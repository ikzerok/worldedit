# 资料与地图的作者位置往返

## 交互契约

- 从源码、资料目录或对象阅读页成功定位地图前，记录实际离开的作者位置。Alt+← /「返回上一个作者位置」恢复该入口；资料浮窗恢复原对象及词条访问路径，源码沿用当前版本选区/滚动校验。
- 地图作者位置仅保存设备个人状态：稳定地图 ID、标记或场景节点选择、镜头及已有子地图访问路径。返回不得应用表单、旧几何、旧对象资料、源码或共享展示文件。
- 返回地图前重新查询当前 core 地图索引，并确认地图来源仍是同一文档。丢失地图时保留当前入口并明确提示，不按标题或同名对象替换。标记/场景节点已丢失时返回有效地图但不恢复失效选择；地图来源变化时使用当前 core 几何，不恢复旧镜头或选择。
- 隐藏图层继续遵循既有可见性：历史恢复不自动显示图层或隐藏的场景祖先。隐藏选择给出说明；明确的「定位」仍由图层界面提供临时显示确认。
- 有未提交的地图几何、表单、导入/生成操作或失败预览时拒绝离开及历史恢复，保留历史条目供处理后重试。源码输入法组合沿用原有保护。
- 地图内部「返回上级地图」保留原有独立路径；恢复地图作者入口时先验证路径中的当前身份，再恢复有效路径，不额外插入重复作者历史。
- 资料与地图反查以地图标题和标记/对象标题为主，稳定地图、placement 与图层 ID 为次级消歧。长名称换行，完整身份不靠悬停才可读。

## 验证边界

事件级回归覆盖资料→地图→返回、地图 A→源码→地图 B→逐次返回、marker/scene、多次返回、删除身份、当前稿变化、隐藏层、草稿阻止和字节/dirty/编辑历史不变。原生键盘与 supported-width 像素验收单独记录，不将 headless 通过视为原生通过。
