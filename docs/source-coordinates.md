# 当前源码行列定位

0.26 在普通“源文件”页提供物理行与字符列定位。当前实现和实际验收状态见[0.26版本说明](https://github.com/ikzerok/worldedit/blob/main/docs/releases/v0.26.0.md)；核心规则以[坐标契约](https://github.com/ikzerok/worldline/blob/main/spec/source-coordinates.md)为准。

## 从位置提示到准确原文

1. 打开一份 `.wl` 源文件。当前位置显示真实光标的物理行、字符列，与旁边的声明归属分别理解；空白、注释和未完成稿仍有文本位置
2. 点击当前行列位置，使用 Ctrl+G（macOS 为 Control+G），或编辑菜单、任务命令中的“跳转到行列”
3. 输入行号，例如 `12`；列默认为1。也可输入 `12:8`。核对当前文件、范围与目标原文预览，再确认定位
4. 确认后回到同一份源码的准确插入点，随后可以继续编辑。Esc 或取消只关闭输入框，不改变稿件或导航历史
5. 用“返回作者位置”或 Alt+Left 返回原选区和滚动。原稿已经改变时不使用旧偏移，保留当前稿并说明原因

行列入口不代替[本文件结构](https://github.com/ikzerok/worldedit/blob/main/docs/source-outline.md)、[查找与返回](https://github.com/ikzerok/worldedit/blob/main/docs/search-author-context.md)或[工程问题回源](https://github.com/ikzerok/worldedit/blob/main/docs/project-problems.md)。这些入口保留各自用途和来源保护。

## 怎么计算行与列

行、列从1开始，按原始文本计算；自动折行不会增加物理行号。每个 Unicode 标量计一列，中文与 ASCII 都计1，制表符也计1；emoji组合、变音符等可能由多个标量组成，不承诺按视觉字形计数。列不是 UTF-8 字节或屏幕宽度。

LF、CRLF各算一次物理换行。空文件只有 `1:1`；末尾换行后的空行仍可定位。目标行有N个标量时，1到N+1列合法，N+1是该行末尾插入点，不落在CRLF的中间。

输入两端空白可去除，内部空白不接受。只允许ASCII十进制数字和一个英文冒号；零、负数、正号、溢出、缺行/缺列、额外冒号和超界值都有明确提示，不悄悄跳到其它位置。长行预览只显示目标附近，并明确省略两端；定位仍使用原文的真实位置。

## 当前稿与安全边界

行列定位读取精确当前文本，不需要语法正确，也不沿用旧AST。声明尚未写完或没有所属对象，不代表无法定位。已跟踪的归档源码也可纯文本查看，不会因此加入活动集合。

源文件、正文或工作区基线变化时，旧预览不能继续提交；应核对重新生成的预览。外部冲突、未完成保存事务、未知清单/必需能力和越界来源继续受core保护。输入法组合期间不把Enter或快捷键当作定位命令，不丢未提交输入。

查看、预览、取消和跳转不应用表单、不保存、不运行故事，也不产生文字撤销记录。成功定位才记录可返回的作者位置。源码仍只有一份；实际编辑和保存继续走原有路径。

## 预算与平台

单文件最多2MiB UTF-8、65,536物理行，原始请求最多128字节（包含两端空白）；预览最多240个Unicode标量。超限提示不可定位而原文继续保留，工具预算不改变语言合法范围。

原生最小窗口1040×660保持，位置入口和取消/确认需在小窗可达。合成输入、Node/WASM测试及各平台GUI验收分别记录，不能互相替代。此功能限普通源码，不增加书签、折叠、多光标、跨项目跳转或CLI遥控。
