# 读者公开页的目录与查找（0.29）

此功能只核对已经由 core 按本次显式选择生成、并逐文件验证的阅读包，不添加公开授权、不生成内容，也不改变原文件、读者站资源或公开搜索索引。未生成、已失效或已取消的预览没有可查询的页面。

## 数据与身份

目录唯一输入为当前 `ReaderExportPreview.content` 的公开 `title`、`text`、`output_path` 和 `empty_content`。不读取全工程目录、源码、排除明细、未选属性、对象备注或任何隐藏内容。匹配标题、公开正文或公开相对路径，采用 Unicode 小写后的子串比较；中文无需分词。仅修剪搜索词两端空白，不改变页面正文。

每一页以当前已验证预览中的 `output_path` 定位，重复标题保持不同页；显示顺序沿用 core 的公开内容顺序。作者搜索不重排页面、不扩大对象选择、不把目录筛选写入 profile。目录显示总公开页数、当前匹配数和明确分页；每页至多12个匹配项，不以静默截断替代完整结果。无匹配时显示“当前公开页中没有匹配内容”，不推断整个世界里没有对应资料。

## 导航与反馈

“页面目录 / 查找”可随时进入，搜索后显式打开某页；标题、相对路径、空正文状态共同帮助区分。键盘在目录搜索/结果区内支持上下移动和 Enter 打开，IME组合和重复按键不触发打开；按钮、Tab与Shift+Tab保持原生行为。页面内有“返回页面目录”，保留本次搜索和页码，不把Backspace当导航键。

原“上一阅读页 / 下一阅读页”继续表示全部已公开页面的原顺序，与目录筛选区分。搜索词变化重置目录候选和页码，绝不自动跳到另一阅读页。新的预览、选择变化、源码基线变化、取消或工程切换清除旧目录缓存与页身份，不能把旧下标套到新包。打开实际HTML沿用已有目标校验与临时预览机制，不能仅凭搜索词拼接路径。

目录与阅读正文属于不同视图；长标题和路径可换行，窄宽度保持返回/查找/页码可见。查找仅在查询或当前审核包变化时更新缓存，不每帧重新编译工程。成功显示目录不表示已发布，导出仍遵守既有最后确认、字节核验、取消和新目标保护。

## 验证边界

回归包括千页末项可达、同名页区分、中文/大小写/空词、未公开秘密搜索零结果、空正文、查询变化/重新生成/取消清旧缓存、结果分页与上下边界、键盘打开/返回/IME守卫、保留选择/稿件/磁盘不变。真实Linux操作与egui模拟、native/WASM编译分别报告；本功能不承诺浏览器宿主或所有平台GUI已实测。
