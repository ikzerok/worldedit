# 逐处审阅后替换（v0.23）

相同文字可以有不同处理：例如同稿三次出现“九扇窗”，仅修订两处客观叙述，保留人物证词。以下操作使用真实字面命中；编辑器不会判断证词真假，也不会自动选择应修改的叙述。

## 从查找到确认

1. 在正文或源码中打开“编辑 → 替换”（Windows/Linux 为 Ctrl+H，macOS 为 ⌘⌥F）；也可先查找，再勾选“替换”。
2. 输入查找文字与替换文字。选择“当前文稿”“捕获选区”或“工程文件”。捕获选区必须在打开查找前选好文字；工程范围在“文件与对象”中明确勾选，包含各文件当前唯一未应用草稿。
3. 每行原文上下文中的强调范围是真实命中，次级文字给出相对路径、行列与第几处。长行会围绕匹配处显示，不再只截取行首。省略提示单独显示，不是原文字节。超长匹配或组合字符受限时会明示，使用“查看当前原文”核对完整内容。
4. 点击结果正文只设置导航的“当前项”。左边的“待改”复选框才决定替换集合；同一行的多个命中也能独立勾选。“只选当前处”将集合设为当前这一处。“全选本范围可替换 N 处”覆盖本范围全部分页中的可替换命中，不包含标为“保护”的项。“清空选择”不修改正文。
5. 选择“预览已选 N 处”。“选中项前后预览”逐处列出原文与修改后的上下文、原/新 UTF-8 字节范围。预览和结果共享一个有界滚动区，底部计数与确认动作保持独立；可在两者间切换。
6. 确认后选择“确认应用 N 处”。计数来自已通过 core 校验的实际事务；修改仍未保存。零选择不能生成选择式预览。“取消预览”不修改正文，保留勾选以便继续审阅。

## 查看原文、分页与键盘

- “查看当前原文”暂时收起审阅窗口，在原有正文/结构/源码入口定位真实范围；必要时会解释为何使用同一稿的源码模式。“返回审阅”或 Alt+← 恢复原作者入口和有效审阅状态。仅查看不会应用或复制稿件。
- 结果每页最多 40 处，全部页均可到达。上一处/下一处定位会切回结果区，显示并滚动到当前项所在页；翻页只改变当前项，不把该页自动加入待改集合。
- 在查询输入框中，Enter 定位当前项或下一处，Shift+Enter 定位上一处。在其他输入框、复选框和按钮上，Enter 不再被全局查找抢走。Tab 移动焦点，Space/Enter 按控件本身的行为勾选或执行。
- “取消预览”“清空选择”及成功应用后，焦点明确回到“命中与勾选”页签，方便继续审阅；这是非文本焦点，不会让下一次 Ctrl+Z 误改查询文字。
- “关闭查找”或 Esc 收起查找并返回实际编辑区焦点，不暗中撤销已经执行的替换。输入法组合期间保留原有快捷键保护。

## 计数与旧的全部替换

底部区分命中、可替换、保护、已选和已应用数量。范围文字说明是当前文稿、捕获选区，还是工程中显式选择的文件；“全部载入”仅指该范围，不代表未知的完整工程。

core 的命中上限仍为 10000。超过上限时整次查找报错，界面不显示被截断的局部列表，也不会把未知剩余结果说成已全选。页大小不是命中上限。

原有全部替换可从“更多 → 预览本范围全部命中”进入。它检查完整当前范围，若含任何受保护命中便整批拒绝；这与明确“全选可替换”是两种不同操作，不能把前者的拒绝悄悄变成跳过保护项。

## 什么时候需要重新审阅

| 变化 | 处理 |
| --- | --- |
| 查询、范围、大小写/整词选项、正文/源码范围、来源快照变化 | 清空旧选择和预览并提示；不按旧列表序号重新选择 |
| 修改替换文字 | 保留仍有效的命中选择，旧预览失效 |
| 增删待改项、只选当前、全选、清空 | 旧预览失效，必须重新确认准确集合 |
| 仅查看原文及返回 | 来源未变化时保留选择、当前项与有效预览 |
| 已捕获选区的稿件被编辑 | 旧选区失效，需重新选中文字并打开查找 |
| 磁盘外部变化、只读文件、保存冲突、过期草稿或保护结构变化 | core 拒绝整批应用，原稿不会部分写入 |

“已应用 N 处”的提示绑定成功后的来源状态；撤销、重做或后续来源变化后不继续冒充当前完成结果。应用前后仍由 core 校验精确来源及命中身份；UI 不新增语言、正则或保护 token 解析器。

## 撤销、保存与边界

当前草稿内的替换仍更新那个唯一 `WritingBuffer`；跨文件替换把涉及文件的当前稿一起作为一个 Project 事务应用。一次撤销恢复本次完整选择集合及原有未应用草稿，一次重做恢复该事务；若之后又有输入，原有拒绝覆盖保护继续生效。

确认应用不会自动保存。当前稿仍需按既有“应用到工程”流程纳入工程，再“保存全部”；跨文件已应用的事务可直接保存。保存后重开工程核对所改处和刻意保留处。不要把“预览”“应用到内存”“保存到磁盘”当成同一步。

正文替换不承担 ID 重构、引用目标更换或语言结构改写。替换中不允许换行、引号或转义等会破坏既有边界的输入；结构性改动请使用原编辑入口。

事件级回归覆盖键盘与布局，但不等于物理输入法、读屏、Windows/macOS GUI 或真实浏览器验证。具体平台覆盖以本次发布验收记录为准。
