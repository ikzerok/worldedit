# 新建空白地图

地图页在“编辑展示”模式中提供“新建空白地图”入口。表单需要填写地图 ID、
显示名称和画布宽高；ID 使用工程展示文档的标识符格式，宽高必须是正整数。

提交后，core 会在一次展示命令中完成两件事：为没有 `.world/project.json` 的旧
工程创建 schema 1 清单，并在 `.world/maps/` 创建对应的空白地图文档。地图包含
自己的 `normalized` 逻辑坐标系、一个空的“地点”图层和空标记集合，不会添加栅格
素材、故事字段或可运行事件。新清单会写入符合 schema 的 `project_id`；已有清单
中的 `project_id` 原值保留。地图变更只进入展示修订，不编译 `.wl` 故事。

已有清单中的未知可选字段和扩展值会保留。清单使用未知必需能力、未知格式版本、
重复地图 ID、非法地图或网络视图注册、路径冲突或外部基线已变化时，命令会失败且不留下半个清单或地图；
表单输入保留，关闭后重新打开可捕获新的修订和清单基线。创建成功后地图页选中
新地图，整个清单与地图变更作为一次 Project 历史记录，可用一次撤销恢复。

进入浏览模式不会显示创建入口，也不会写入工作区。创建地图不要求工程可以启动
试玩；保存全部时，清单和地图文档沿用 Project 的展示文档保存与恢复事务。
