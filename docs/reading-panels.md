# 钉住资料旁查

从正文、资料页或关系入口打开对象时，临时阅读窗显示该对象的聚合资料。需要对照时，点“钉住旁查”：阅读窗会成为独立面板，原来的临时阅读入口仍可打开另一对象。最多同时钉住两个面板；标题始终显示对象类型和 ID，同名资料因此仍可分辨。

面板中的关联链接只导航当前面板，并将旧目标放入该面板自己的返回历史。点击其他入口仍使用临时阅读窗。宽屏可同时查看两个面板；窗口窄于 1300 点时改为切换式显示，可用“旁查 1 / 旁查 2”切换当前面板。

面板可拖动、调整大小，也可点“关闭旁查”或窗口关闭按钮移除。点“返回源码编辑”回到当前源码并恢复键盘焦点。钉住和浏览只保存在当前编辑会话，不修改工程内容、保存基线或撤销历史；切换工程后旧目标会清空。

对象被改名或删除后，面板按原来的类型和 ID 查找，不会跳到同名对象。被删除或改 ID 的目标会显示失效提示；保留 ID 的对象则显示最新工程内容。带有未提交输入的创作表单时，工程切换会被阻止并保留输入。
