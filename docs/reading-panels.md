# 多资料旁查（CAP-02C）

临时 Wiki 阅读窗口可通过“钉住旁查”保留当前资料。最多同时打开两个钉住面板，各自保存目标与最多 64 步返回历史；链接按类型、显示名和稳定 ID 消歧，不按同名合并。未钉住的临时阅读仍独立存在。

宽窗口显示两个可调整尺寸的窗口；宽度低于 1300 逻辑点时只显示选中的面板，用“旁查 1 / 旁查 2”切换。每个面板提供返回、关闭和返回源码编辑按钮。切换工程清除面板，关闭、尺寸和浏览历史均只留在本次会话，不写入作品，也不进入内容撤销。

钉住面板只用于旁查，不直接编辑对象或别名。内容始终读取当前 core 快照；显示名更新后随快照刷新，删除或修改 ID 后显示原身份的失效提示，不猜测替代对象。打开的创作表单必须先应用或取消，才能切换或关闭工程。

自动回归覆盖双面板钉住、独立有界历史、1040×660 切换/关闭、返回源码入口、失效对象和草稿保护。egui 输入回归不等同实际桌面/Web 用户验收；实际双端交互、键盘焦点和缩放恢复仍须补充验收记录。
