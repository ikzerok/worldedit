# 钉住资料旁查

从正文、资料页或关系入口打开对象时，临时阅读窗显示聚合资料。点击“钉住旁查”保留当前对象，仍可用临时窗打开其他对象。最多两份参考；完整对象类型和ID决定身份，同名资料不混淆。

0.8默认把参考停靠在右侧，真实分配空间而不盖住正文。主区可用宽度足够（1450逻辑像素以上）时双份并排，否则用“参考1/参考2”切换。参考栏可调整宽度；“收起”隐藏它，“视图→显示固定参考”重新显示。正文专注模式隐藏导航和诊断，参考仍可自行收起或保留。

选择“浮动”保留自由拖动/大小调整模式；浮动模式在窗口窄于1300点时使用单面板标签。每份参考有独立的关联浏览与返回历史，其他资料入口不会替换它。“关闭参考/关闭旁查”只移除个人面板，不删除对象。

导航、停靠方式、宽度、最后参考对象及最近作者位置保存在此设备/浏览器的个人设置，不写入作品或完整导出，不改变撤销和运行指纹。重新打开同一工程可恢复两份参考；失效目标明确提示，绝不跳到同名对象。个人恢复不保存正文草稿、不自动应用任何编辑。没有可用个人存储时仍能正常创作，但跨会话布局不保证恢复。

真正未应用输入由草稿管理对话框保护；仅打开未改的对象表单不阻断切换或关闭。保存文件与应用表单是两步，状态栏会指出未应用输入。完整界面设置见 [作者工作区](author-workspace.md)。

## 临时资料窗的键盘进入与安全返回

逐句对白中的“人物资料”、行内人物与正式链接，以及角色台本中的人物入口，共用同一临时资料窗。打开时，焦点应落到清楚可见的“关闭资料并返回”；有源码返回位置时保留“返回源码编辑”的原有含义。正向、反向 Tab 在此临时资料层内移动，不能落到底层仍可编辑的对白字段。文本字段保留自己的光标、文字和输入法组合行为。

Esc 或“关闭资料并返回”仅关闭临时资料，并恢复原作者入口的焦点；不应用、清空或重绑原对白输入，不修改正文草稿、工程、磁盘或撤销历史。来自源码链接的 Esc 仍返回同一源码文件和原光标位置。更上层的菜单或受保护对话框先处理取消，不能借此越过确认。

“编辑此对象”继续遵守已有未应用输入保护。若当前还有修改过的对白字段，进入对象编辑会被拒绝；保留原字段和正文后返回作者位置，不把读取资料当作已经提交输入。资料的阅读焦点域仅对当前实际显示的内容处理上下滚动；它不接管文本框方向键或组合输入。固定旁查仍是独立的只读参考，不改成临时对话框。

“新建人物…”仍使用已有宽屏侧栏或窄屏人物档案窗，姓名字段先获焦；未应用人物编辑和原对白分别保留，返回作者位置不自动应用任何一方。

## 同稿关联计划的完整阅读

从当前正文的真实选区打开“关联世界资料…”，预览沿用该文件当前唯一正文草稿；已纳入正文的逐句变更不会在这里回退成磁盘稿。先核对稳定目标、固定选区和全部变更文件，再展开“应用前（已应用工程）”与“关联后（完整候选）”。每个 16 KiB 字节页保持 UTF-8 边界，页内内容也应能通过明确的“关联预览阅读区 · ↑↓滚动”完整读到末尾；能聚焦折叠标题不等于已经看完展开全文。

打开关联窗时，焦点先落在可见的“返回正文，保留输入”。Tab/Shift+Tab 在此窗当前可交互控件间循环，不进入底层正文。查询结果的内层滚动与完整计划阅读的外层滚动各属其域。

关联阅读域仅在当前有效关联预览实际显示时接收未修饰的上下键；普通查询/资料文本框保留光标与输入法组合。Tab/Shift+Tab 应显露本窗真实控件及可辨焦点。上层菜单、确认或命令窗先处理取消。Esc 和“返回正文，保留输入”沿用原来的安全返回：保留关联输入、当前正文草稿和原作者选区，不应用、不保存、不增加历史。后续正文或来源变化会使旧计划失效，必须重新核对，阅读功能不能偷偷重绑或替用户确认。
