# 钉住资料旁查

从正文、资料页或关系入口打开对象时，临时阅读窗显示聚合资料。点击“钉住旁查”保留当前对象，仍可用临时窗打开其他对象。最多两份参考；完整对象类型和ID决定身份，同名资料不混淆。

0.8默认把参考停靠在右侧，真实分配空间而不盖住正文。主区可用宽度足够（1450逻辑像素以上）时双份并排，否则用“参考1/参考2”切换。参考栏可调整宽度；“收起”隐藏它，“视图→显示固定参考”重新显示。正文专注模式隐藏导航和诊断，参考仍可自行收起或保留。

选择“浮动”保留自由拖动/大小调整模式；浮动模式在窗口窄于1300点时使用单面板标签。每份参考有独立的关联浏览与返回历史，其他资料入口不会替换它。“关闭参考/关闭旁查”只移除个人面板，不删除对象。

导航、停靠方式、宽度、最后参考对象及最近作者位置保存在此设备/浏览器的个人设置，不写入作品或完整导出，不改变撤销和运行指纹。重新打开同一工程可恢复两份参考；失效目标明确提示，绝不跳到同名对象。个人恢复不保存正文草稿、不自动应用任何编辑。没有可用个人存储时仍能正常创作，但跨会话布局不保证恢复。

真正未应用输入由草稿管理对话框保护；仅打开未改的对象表单不阻断切换或关闭。保存文件与应用表单是两步，状态栏会指出未应用输入。完整界面设置见 [作者工作区](author-workspace.md)。
