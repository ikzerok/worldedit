# 正式对白创作与角色制作台本

## 在原书稿里写正式台词

书稿正文中的“插入正式台词”先列出 core 可确认的插入位置。正式台词有明确的人物身份、文字与演出备注；同名人物会同时显示正式 ID。普通文字里的冒号或姓名不会自动变成说话者。

默认保留原有普通正文直接输入；文稿含 Say 也不会自动切换视图。明确勾选“逐句对白”，即可在同一份稿件中连续阅读、编辑正式台词与普通 Text；“插入正式台词”和确认后的续句也会进入这个子模式。普通 Text 在逐句模式中同样可编辑、预览并纳入正文草稿，也可明确转换为 Say。条件、选择、场景、call 与去向仍显示结构边界，内容没有被当作一条已经执行过的对话。

取消勾选回到原正文输入。切换写作、结构、源码或逐句模式时，原字段先收齐本帧输入；尚未纳入的 typed 字段保留，重新进入可继续。原文光标只有在完整稿件及目标仍匹配时恢复，不把 typed 文字位置猜成源码偏移。输入法组合和 Commit 同帧不能切换。

选择“编辑此句”后，文字、speaker 与 direction 留在受保护的局部输入。表达式和强链接是独立 typed token；添加或修改 token 后由 core 验证。普通字段里的特殊字符不会被 UI 重新解释成 DSL。复杂源码始终可从原来的“结构”与“源码”入口继续修改。

Enter 在当前字面文字里换行。Ctrl/Cmd+Enter 在已有、未修改的语句编辑框直接打开下一句；已有待提交输入时先生成当前句的完整计划，确认“纳入并写下一句”后才进入下一句。下一句只沿用刚确认的正式角色作为可修改默认值，不自动轮换。输入法组合与 Commit 同帧不能触发这些动作。

## 三种保存状态

1. 尚未纳入正文：typed 字段受保护，切换章、源码、旁查和查询不会悄悄应用或丢弃
2. 已纳入正文草稿：唯一文件 WritingBuffer 已变化，按原有“应用正文草稿”进入工程；可撤销
3. 已应用未保存：工程内存已变化，保存仍是另一步

修改先预览正式语句范围、变更前后、旧/新角色和可能损失。取消、无变化和失败不写内容。源文或工程基线改变时，字段完整保留；需要作者明确选择新的接收语句或插入锚再预览，不按显示名或相似文本自动合并。

旧语言作品使用 Say 需要明确预览 1.11 能力。计划会显示全稿关键字重新解释、运行指纹可靠性、诊断和完整文件前后字节。确认后，所列全文稿与语言清单在同一工程事务中应用；一次撤销，尚未保存。

### 用键盘核对语句与迁移预览

当前逐句表单有有效语句计划时，普通计划提供“语句预览阅读区 · ↑↓滚动”，语言迁移计划提供“迁移预览阅读区 · ↑↓滚动”。用 Tab 到达该入口后，上下方向键按行滚动当前正文视口；阅读区保持可辨的焦点边框。方向键没有修饰键且阅读区确实获焦时才用于滚动，不接管文字框的光标、空格或输入法组合。

Tab 或 Shift+Tab 到达这份预览表单的按钮、复选框和折叠标题时，控件会滚入可见范围。普通计划可逐行核对变更前后；迁移计划展开重新解释、诊断与完整文件内容后，可在阅读区继续核对只读文字；长文件仍使用原有连续字节分页。滚动和焦点移动不勾选确认、不应用计划。

在语句或迁移预览阅读区及其导航控件上按 Escape，只撤回本次预览和确认状态，并回到可见的“预览语句变更”按钮。角色、正文、作者私密备注及“明确预览启用语言 1.11”选项全部保留，可重新预览。文字输入框内的 Escape 沿用已有字段取消保护；弹出菜单和上层窗口优先处理各自取消，不穿透到预览。撤回预览不新增工程历史，不改变正文草稿或磁盘。

这项阅读入口不出现在普通正文、结构、源码或没有有效计划的逐句表单中；这些模式保留原来的 Tab 与方向键行为。普通计划的“纳入正文草稿”仍只改变同一文件的正文缓冲，另行应用后才进入工程；不会升级语言、改动磁盘或跳过演出备注损失确认。

Text→Say 只接受正式单语句；glue 或不支持的 tags 等情况明确拒绝。Say→Text 的 direction 必须经作者明确确认损失，不静默丢弃。稳定本地化 ID 与旧译文保留，kind 改变按原规则使译文 stale。

解码文字目前没有已证实的字面选区源码映射；该区域不会启用假偏移批注或资料关联。需要这些动作时，进入真实完整源码定位后使用既有选词工具。

正文列足够宽时，逐句对白、插入和台本入口直接显示；空间不足时收进“对白工具”。更窄的正文列优先保留写作、结构、源码切换，应用、丢弃和对白入口收进“正文工具”；窄短窗口的全部正文操作位于该菜单。每次重新展开从主要操作开始，保持展开时仍可滚动到确认与取消。收拢不改变当前草稿或模式。

## 同稿角色台本

从正文“角色台本”或工程菜单“角色制作台本”进入。查询包括已经进入正文缓冲的当前稿；仍在局部 typed 表单或输入法保护区的输入需要先处理，不能把遗漏它们的材料称作当前稿。

范围有三种：当前正文目标、同一书稿完整筛选中的全部/明确勾选章节、全工程活动定义。分页或折叠不会缩小范围。speaker 必须选正式 character；POV、with、文字提及与同名文本不参与推断。旁白与选择文案可独立纳入。

默认纳入静态共享片段闭包。范围预览分别列出根章节出现、根定义、额外片段定义、全部调用点与来源文件，所有目录都可分页查看。关闭闭包会显著标为“直接范围”。同一来源定义只列一次；调用点不是运行次数，排列不是执行顺序。内部控制祖先与外部调用上下文分别显示，不执行参数、条件、once、RNG 或状态。

查询按完整过滤结果分页；每页40行，计数精确。超过 core 完整预算会失败，不返回截断成功。原生生成使用后台单作业；浏览器生成是作者点击后触发的有界同步计算，不宣称浏览器后台线程或持续监视磁盘。所选结果过大可明确缩小章节或角色范围；全工程源码、AST、本地化注册资料与书稿完整性预算仍须先通过，不能靠筛选绕过未选中内容的问题。

每行都可通过 core 核对的真实来源回到原文。当前稿、speaker、direction、人物名称、locale 或范围变化会使旧材料失效。返回台本保留原查询页与选项，旧材料不会冒充新稿。

### 台本里的键盘阅读

角色台本内用 Tab / Shift+Tab 到达范围、角色、语言、分页、来源和交付控件时，当前控件会显露并显示可辨焦点。选择“角色台本阅读区 · ↑↓滚动”后，可用无修饰的上下键阅读外层列表、静态定义和调用说明；它不执行查询或改动选择。

完整交付字节有独立的“交付字节阅读区 · ↑↓←→滚动”。先用 Tab 到达它，焦点边框指明实际字节视口；方向键只滚动该内域，有相应溢出时才移动。长材料仍按原有 UTF-8 连续字节分页，自动换行与原格式不变；没有横向溢出时无需水平移动。切回文字输入框后，方向键、空格和输入法仍由原输入框接收。

阅读、翻页或焦点移动不会勾选交付确认，不会写文件。格式、演出备注、当前稿或查询选项变化后仍须按原规则重新生成、预览和确认；台本不借用语句计划的 Escape 撤回语义。菜单和上层窗口保持原有取消优先级。

## Locale 与私密交付

留空 locale 为源文台本。指定语言时，显示源文、已译、缺译、过期或无效状态。默认交付严格要求最终所选单元完整；不因未选中章节缺译而阻塞选定范围。未知 locale、坏注册/sidecar、全工程重复稳定 ID 等完整性问题仍会阻断。

只有明确勾选“允许回退源文”时，缺译、过期或无效单元才使用源文，并保留状态与回退标记。人物名称和演出备注始终是源语言元数据。

精确 JSON、阅读 Markdown 和表格 CSV 来自同一 immutable core 结果。完整字节预览分页连续显示，复制与文件交付使用同一组字节，不在 UI 重排、翻译或重新拼接。默认不含演出备注，包括隐藏字段、raw Say 或源片段等旁路；只有明确启用“纳入作者私密演出备注”才加入。

CSV 的每格统一包含 ASCII 单引号显示前缀、双引号包裹和 CRLF；精确原值请用 JSON。CSV 不是无损回导格式，也不保证所有表格软件或再次另存后的通用安全。Markdown 对作者字符串执行安全显示处理，不生成可执行 HTML、图片或外链。

原生只写工作区外的新绝对路径文件，不覆盖已有文件；预检、取消、过期或失败不留下冒似完整产物。浏览器只请求下载相同字节，不能确认用户是否已保存到磁盘。这些材料不是完整工程备份，不扩大读者发布白名单，也不自动分享给任何第三方。

## 长章与当前稿角色

- 长章按 core 返回的完整顺序，每次连续显示 80 段；页首与页尾显示完整段落、语句总数，翻页不缩小草稿或交付范围。当前编辑语句即使在另一段，仍显示在当前段前供继续编辑、预览或明确取消。
- 角色台本的下拉候选明确来自已应用稿。尚在正文草稿中新建的人物可在「character 的完整 ID」输入其原始 ID，由 core 在生成时验证；不得填写显示姓名来代替正式身份。

来源暂时无法验证时，当前语句的受保护输入以只读恢复区展示角色、完整 typed parts 和演出备注。该区明确包含作者私密备注，可复制完整原请求；不是制作台本交付，也不会应用、合并或自动重绑。取消仍须原有确认，其他目标和正文草稿不受影响；进行中的输入法提交先由原控件接收。
