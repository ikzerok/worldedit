# 移动单个实体资料声明

这个动作只整理一个已有 `entity` 声明的存放位置，不改实体稳定 ID、显示名、属性或引用。人物、事件、片段、目录、资源和批量移动不在范围内；原来的整文件“安全移动 / 重命名路径…”仍单独使用。

## 从选中实体开始

1. 在资料索引、临时资料阅读页或已有实体资料表单中，选择“移到其他源码…”。键盘也可先用 Ctrl/Cmd+P 按名称或稳定 ID 选中实体，再用 Ctrl/Cmd+Shift+P 搜索“移到其他源码”。命令与按钮使用同一个动作
2. 核对“移动实体资料声明”中的名称、`entity:稳定ID`、当前完整来源。目标清单只显示工作区内已存在、未删除的活动 `.wl`，包含当前来源；不会激活归档源码
3. 如需新文件，先取消，使用文件树“工程文件”旁的“＋”新建，再回来选择。移源本身不会创建源码、添加 include 或启用语言能力
4. 选择目标，点击“预览实体移源”。窗口内用上下键选择目标，Enter 只预览；Tab 离开清单进入底部动作。完整路径可折行阅读与选择复制
5. 核对 core 的源删除和目标插入：每侧显示实际文件、UTF-8 字节半开范围、修改前后原文，并可展开前后上下文与等价证明。独立前置注释、分隔空行和相邻声明不会被猜作该实体的一部分；不能明确证明的范围会拒绝
6. 明确点击“应用实体移源”。键盘预览成功后焦点移到应用按钮，再按 Enter 才应用。取消按钮、窗口关闭或 Escape 都只取消提案；若命令面板在上层，Escape 先关闭命令面板。输入法组合时 Escape 不触发移源取消

## 草稿、过期和零变化

未应用的资料表单、正文 WritingBuffer、源码输入法稿或其他创作输入会阻止预览/应用，输入完整保留；不自动应用、不悄悄丢弃。请先在对应页面明确处理，再重新预览。提案选择本身也参加退出和导出范围保护。

改变目标会清除旧预览。预览后工程内容、磁盘文件、库存、能力或完整计划有变化，core 会在应用时重新检查；失败不会改写一半。窗口保留目标和原因，修正后重新预览。工作区切换不能把旧提案应用到另一个作品。

选回同一规范来源时，core 返回“同一来源、无变化”；应用按钮禁用，不新增撤销、提交或保存动作。

## 应用、撤销与保存

成功只修改源与目标两个源码缓冲，作为一次 Project 撤销/重做；底部明确显示“已应用、尚未保存”。应用后按实体稳定身份重新从 core 目录取得目标真实来源。撤销回到旧声明位置，重做回到新位置；实体资料、阅读与引用仍按当前目录回源，不会把原文件中其他对象的导航历史一起迁走。

保存全部后才写入磁盘。保存复用已有可恢复事务，不承诺跨文件物理原子写入。保存重开后，从实体资料“定位源文件”读取新的真实声明位置。完整工程导出继续保留隐藏目录、未引用文件和附件。

浏览器工作区仍是导入快照；整理快照中的源码不表示正在监视或直接改写原磁盘。自动 egui 测试覆盖键盘事件和窗口布局，但不能替代 Linux 原生实测、Windows/macOS、浏览器、物理中文输入法或屏幕阅读器验收；实际通过范围以本版验收记录为准。
