# 时间线与事件图的同端点连接

## 交互契约

- 按当前视图投影后的有向端点分组；时间线仍过滤 Enter 和投影内自连线，事件图保留原有可呈现边。只合并画法，不修改 core 原始边、标签、条件、顺序或任何运行语义。
- 多边显示单个可键盘聚焦的数量/种类入口；展开列表逐条保留原始完整标签、边类型、条件分支、选择上下文、目标准入和来源。相同标签不同来源仍是独立条目，计数等于原始可呈现边数。
- 单边保留清晰入口。数量和详情控件使用正常字号及最小点击尺寸，不随画布缩放变成不可点的微小目标；长中文标签在有限宽度内换行，详情可滚动。
- Tab/Enter 可进入数量入口及逐条来源按钮，Esc/关闭收起列表。定位来源后作者返回能回到仍有效的展开组；新的 core 快照/来源不再一致时不能使用旧边的行号，明确说明需要重新打开。
- 上层任务命令面板打开时不显示底层图节点/边的 tooltip。分组和详情开闭不改作品、个人布局保存基线或运行状态。

## 验证边界

回归覆盖单边/平行 Choice、Divert、Drift 混合、场景→事件端点投影、标签相同但来源不同、完整长中文/条件、缩放/裁剪、键盘展开关闭、逐条源位置与返回、来源变化和零改稿。原生 supported-width 与真实输入验收由发行验证单独记录。
