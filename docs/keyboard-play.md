# 连续键盘试玩（0.27）

键盘启动、重新开始或确认一条可选路线后，成功推进应保留作者在试玩操作区的工作位置。
界面消费runtime返回的当前选择和结束状态，不从故事源码推断可选项。

## 焦点契约

- 只为键盘发起并真正成功的开始/重新开始/选项确认请求下一焦点；鼠标操作不额外抢焦点
- 有可执行选项时定位本次真实可选项；首项锁定、选项减少或旧按钮消失不能使焦点跌回整个工作台顶栏
- 正常结束时可将焦点交给明确的路线记录动作；只是聚焦，绝不自动保存路径、保存工程、重放或重新开始
- 触发键Enter/Space尚未释放时，不让重复按键误触下一组选择；一次确认不能连续替作者走多条路线
- 用户随后Tab/Shift+Tab、方向键导航、点击、打开命令/其它面板、取消或切换视图时，新的导航意图优先；旧待恢复焦点失效
- 暂停、预算停止、取消、故事错误、未满足条件的拒选或未确认的草稿对话不算成功推进，不伪造可选项、不自动续行
- 锁定选项不成为可执行目标；全锁定/空选项沿既有runtime落穿或结束语义，不在UI另设一条假路线
- 输入法组合时不触发故事操作或焦点转移；未完成组合结束后仍要由作者明确确认

焦点恢复只影响当前会话的界面状态，不写源文件、不改运行语义、随机数、choice身份、
trace/checkpoint或存档格式。它与[真实变量写入](https://github.com/ikzerok/worldedit/blob/main/docs/variable-write-evidence.md)
配合，使作者能连续录制两条路线，再审查差异和实际来源。

## 普通试玩设置的短窗焦点（0.33）

普通试玩的紧凑纵向布局中，Tab 与 Shift+Tab 到达语言、回退策略、种子、普通试玩预算及调试设置时，
当前控件须自动滚入实际可见区域。控件本身及其可读内容须完整可见；不能只有屏外焦点，
也不能要求作者补一次鼠标滚动才能找到焦点。反向 Tab 与正向 Tab 遵守同一规则。

语言切换、状态提示及预算展开造成控件增减时，仍存在的设置控件使用稳定身份；逐键输入不得因
上方内容变化而丢焦点。滚入只跟随作者真实键盘导航，不为鼠标浏览、无导航的重绘或输入法组合抢回焦点。
它不启动、重新开始或推进故事，不改变已建立会话的 locale、RNG、choice 身份、trace 或存档；
下一次运行设置仍只在作者明确开始时生效。原有开始、选择、结束后记录的单次确认与焦点交接规则保持不变。

路线对照与普通试玩切换时，共享的模式和语言设置保留语义身份，但同一帧只在一个宿主绘制，不得注册相撞的 ID。
键盘切换后焦点须能继续 Tab/Shift+Tab 并显示完整控件；触发键不得因宿主变化重复执行故事操作。
明确按 Enter/Space 从路线对照返回普通试玩时，保留的模式焦点须在下一可达布局帧完整滚入。
该显露仅消费一次真实键盘转换；新的指针操作、输入法组合或焦点变化取消它，鼠标返回不重置原滚动位置。
鼠标或键盘切换宿主不重建、推进故事，也不改下一次运行的语言输入；开始前与已有会话、宽窗与短窗均遵守此约束。

验证须使用完整应用外壳、763×542 物理尺寸及应用 200% 缩放（381.5×271 逻辑尺寸），通过真实
Tab/Shift+Tab、逐键输入及 Enter/Space 操作检查控件实际响应矩形与裁剪区域。测试不得用强制
request_focus、直接设置滚动偏移或事后鼠标滚动修补键盘路径；合成输入与原生窗口复验分开记录。

## 验证范围

回归覆盖正常分支、首项锁定、全锁定、空组、结束、错误、取消、重复按键、IME和用户
主动导航。原生键盘、合成事件、物理鼠标/输入法分别记录，不将一次工具按键回执当成
操作成功。发行验证状态见[0.27版本说明](https://github.com/ikzerok/worldedit/blob/main/docs/releases/v0.27.0.md)。
