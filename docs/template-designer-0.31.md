# 可视资料模板设计器（0.31）

模板定义资料表单的字段、提示与分组。它适合让地点、人物或世界观资料采用一致的填写方式；不生成故事事实，不执行规则，也不会替已有对象自动填写、改名或转换属性。

## 打开与建立模板

1. 打开 **工程 → 管理工程模板**，或从工程工具进入 **工程模板**。
2. 选择一个内置模板，点 **复制为新模板 JSON**；也可点 **新建空白模板**。复制后默认进入 **可视字段**，可以直接使用表单控件编辑。
3. 修改模板名称与适用对象，点 **更新模板信息草稿**。适用对象为 `world`、`character` 或 `entity`；只有 `entity` 可以设置实体分类，分类留空表示该类型的全部实体。

内置模板只读，工程模板使用独立的 `project:` 身份。复制不会覆盖原模板。新建或复制即产生未应用草稿，即使尚未手工输入，离开时也会保护它。

宽窗口并列显示目录和编辑区。窄窗口通过 **模板目录 · 选择内置或工程模板** 展开目录；选择后收起，保留编辑空间。次要动作位于 **模板操作…** 中，预览和应用仍在页面顶部。

## 添加与调整字段

可添加六种字段：

- **文本**：字符串，可输入多行内容
- **数字**：有限数值
- **布尔**：明确的 true / false
- **枚举**：选项每行一个，不能空白或重复
- **对象引用**：完整的类型与 ID；按类型和可选实体分类选择已有对象
- **分组**：只组织表单，不对应实例属性；新分组自带一个文本子字段

选择字段大纲中的一行，编辑右侧或下方的 **字段属性**，然后点 **更新字段草稿**。显示名称便于阅读；实例属性 `key` 决定实际读写哪个属性。`key` 在整个模板中唯一，不因分组而重复。

**还原字段输入** 只还原尚未更新的属性输入。**还原模板信息输入** 对应模板名称与适用范围。**撤销草稿编辑** 撤回已经进入当前草稿的可视结构操作；有待更新属性输入时，先更新或还原该输入。

### 分组、顺序和稳定身份

- 大纲的 **↑ / ↓** 调整同级顺序
- 先选中分组再新增，会把新字段放入该组
- 字段属性下选择目标分组，点 **移动到所选分组末尾**；选择“模板根层”可移出分组
- 不能把分组移到自身或后代，也不能让分组变成空组
- 删除分组需要明确确认，并删除其全部子字段定义；实例属性仍保留
- 分组与普通字段不能通过类型菜单隐式互换；需明确删除后新增

可视界面的模板 ID 和字段 ID 都是只读的稳定身份。移动不改变身份，也不丢掉字段或引用限制中的未知可选扩展。自动新增会避让当前草稿已用过的身份，避免把已删字段的扩展带给新字段。高级 JSON 显式改变字段 ID 则按删除旧字段、新增新字段审阅。

### 必填与默认提示

**标为必填提示** 只用于模板完整性提示，不会自动向实例补值。默认提示也不表示实例已经有该属性。

默认数字 0、布尔 false、空字符串与“没有默认提示”互相不同。更换普通字段类型会清除该字段草稿中不再适用的旧选项、引用限制和默认提示；更新前可检查或重新填写，仍不会迁移现有实例。

### 引用能力

对象引用沿用作品当前语言与能力：普通实体/关系引用要求语言 1.10 或以上；人物引用要求显式语言 1.13 及已有的对象引用、人物引用双能力。候选按完整 kind 与 ID 区分，同名不代表同一对象。

新模板导入可沿已有规则显式加入普通对象引用能力。已注册模板的替换不会自动开启缺失能力；需要时先在 **工程 → 语言与资料能力…** 明确启用，再继续草稿。设计器不会自动升级语言，也不会把普通字符串提升为引用。

## 试填真实表单

切到 **试填预览**。它与正常资料编辑窗口共用字段渲染，包括分组、枚举和引用选择。

试填值只留在当前界面：不会创建对象，不会改属性，不会成为模板默认值，也不会单独阻止退出。点击默认提示或添加字段值是显式的试填动作。**清空试填值** 可重新开始；切换模板会重置试填。

若可视属性还有未更新的输入，先更新或还原再切换模式，避免把未完成的输入与已核对的草稿混淆。

## 查看影响、应用与保存

1. 点页面顶部 **预览导入 / 替换**。预览不会写 Project 或磁盘。
2. 核对旧、新模板的名称和适用范围，以及字段的新增、删除、key、类型、提示和位置变化。
3. 查看实例影响。每个对象分别标明“原模板适用 / 不适用”和“新模板适用 / 不适用”；只对真正适用的一侧检查字段，退出范围不被误报为新类型错误。
4. 确认后点 **应用预览中的模板变更**。应用成为一条工程撤销记录，仍未保存到磁盘。
5. 点 **保存全部**，再按普通工作区方式重开。

实例列表每页 50 个对象，显示完整总数、当前范围及页码，提供首页、上一页、下一页、末页。分页只改变显示；不会缩小 core 报告或应用范围。重新生成预览会回到第一页。

字段变更直接显示预览时绑定的旧、新名称、key、类型、必填提示、默认提示、枚举选项和引用限制。较长文字或较多选项会明确标注摘要及总量，可用 **复制完整旧属性 / 复制完整新属性** 核对完整快照；这些是字段属性快照，不是完整模板文档。翻实例页不会改变字段变更快照。

**取消预览** 只撤回这次确认，不清空模板草稿。字段或 JSON 改变后，需要重新预览；工程或磁盘保存基线改变后，过期预览不能覆盖新内容。

### 不完整预览

缺失 include、源码语法错误等会使实例影响不完整。页面显示原因和源码诊断，并将行数标为“已知对象（不完整）”。零行不代表没有影响，应用按钮也不会可用。先修复来源，再重新预览；模板输入保持不变。

## 用模板创建资料与再修订

应用模板后，从正常资料入口新建或编辑适用对象。例如，适用 `entity / place` 的模板会出现在地点资料表单中。填写后明确 **应用资料**，再 **保存全部**。

模板不会自动创建对象。可分别创建两个不同稳定身份的地点，它们可以使用同一模板，但各自保有自己的属性值。

再次修改模板名称、字段、顺序或适用范围，仍走“草稿 → 影响预览 → 应用”。改变 key 不会重命名既有属性；改变类型不会强制转换、删除或迁移实例值。影响预览用于发现这些差异，由作者决定后续资料编辑。

工程 **撤销 / 重做** 操作已应用的模板事务；未应用的可视改动使用 **撤销草稿编辑**。保存后撤销仍会产生相对于当前磁盘的未保存修改，需再次保存。外部刷新和冲突继续遵守[工作区规则](workspace.md)。

停用模板使用 **预览停用模板（保留对象资料） → 确认停用模板**。它解除注册并移除模板文档，不删除实例属性；取消停用预览保持原状。

## 高级 JSON 与原文保留

**高级 JSON** 与可视模式共享同一份草稿。切换模式不会重新排版原文，也不会把坏输入转换成近似的可视字段。当前草稿可通过 **复制当前草稿原文** 保留；**导出 JSON 到剪贴板** 导出所选模板的已应用原文。

未知可选扩展由 core 保留，按稳定字段 ID 跟随跨组移动。未知 schema 或未知必需能力只读；不能通过可视编辑或复制强行降级。无效 UTF-8 不转换成替代文本，原字节继续由完整工程备份保留。

修改已载入模板的 JSON `id` 后，普通预览会拒绝身份不一致。确实要使用 JSON 中的新身份时，选择 **按 JSON 身份导入 / 替换**：新 ID 未注册则导入另一模板；已注册则预览替换该确切身份。原模板不会被暗中删除。

### 坏原文修复

普通替换不会越过旧文的只读保护。**修复坏原文（完整替换）** 是独立入口，只适用于能完整结构化读取、所有保护元数据均确认为受支持的重复键原文。

预览显示 TPL007 警告：将采用完整新文，旧扩展无法安全合并，应先复制原文。只有点击 **确认完整替换坏原文** 才提交；取消、失败和过期都保留旧字节。一次工程撤销可恢复原坏文。

如果原文语法中断、元数据缺失、未来格式或能力无法确认，不能原位修复。可先保存原文副本，再把有效新文显式按新身份导入。修复不会绕过语言、能力或工作区只读限制。

## 中断、冲突与键盘

切模板、新建、复制、重新载入、换作品或退出时，未应用定义和属性输入会受到保护。选择继续编辑或取消，会完整保留输入；只有明确丢弃才清理。原模板发生外部变化时，脏草稿不覆盖较新定义，可先复制草稿再重新载入合并。

输入法组合属于当前实际模板输入框。组合中的 Enter、Tab、Escape 与鼠标导航不会代替应用或丢弃；提交当帧也不会顺带触发按钮。普通输入及单纯的输入法启用通知不要求第二次点击。表单控件保留键盘焦点与标准键盘操作。

自动键盘与离屏 egui 回归不等同于物理输入法或跨平台认证。真实 Windows/macOS GUI、物理 OS IME、屏幕阅读器及实际浏览器宿主未执行的部分不能称为已通过。浏览器作品仍是导入快照，不能宣称持续监视磁盘；保存和冲突边界见[工作区操作](workspace.md)。
