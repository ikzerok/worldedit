# 审阅稳定 ID 重命名（0.13）

稳定 ID 与显示名是两个字段。只想改变读者看到的名称时，打开实体资料编辑“显示名”，保留稳定 ID；这样不会改变 state 的所属身份。关系资料中的显示文字也不等同于关系 ID。

## 先看真实变更，再整批应用

“跨视图更改稳定 ID”使用 core 生成的一份原子计划。预览逐文件列出工作区相对路径、具体行或展示文档字段、真实修改前后语境与身份 token；运行指纹和内容基线也绑定这份计划。预览不会改稿，关闭或取消不会提交。

entity/relation 源码重构只替换正式词法、语法识别出的身份范围。同行注释、引号内的显示名、普通文字、转义和链接显示词保留原字节。展示文档按已注册的引用字段更新；未知字段不被当作引用。

所有明确引用必须整批更新，预览不提供逐处取消勾选。应用前 core 重新核对同一基线和完整计划；输入、工程或磁盘变化后须重新预览，失败时整批不变。应用仅更新工程内存，可整批撤销；“保存全部”才写入磁盘。

## 运行身份的安全边界

实体被 state 用作所属对象时，实体 ID 会参与运行指纹。此类重命名仍安全拒绝，并列出受影响的 state、来源和旧/候选指纹，说明旧存档与检查点为何不匹配。入口轨迹须满足同版 runtime/schema 后按当前稿受控重放，不能保证沿用原结果。不会删除指纹校验、自动修改旧存档或提供隐藏的身份迁移模式；实体可改显示名，关系可改别名，以保留当前运行身份。

成功计划会显示真实前后运行指纹。entity/relation 的计划只有指纹不变时才能提交，不能把所有实体笼统视为静态资料。显式语言 1.11 起的其他既有身份重命名仍遵守原兼容规则；此版本没有新增 DSL，未配置的工程继续使用 1.9，最高支持版本仍为 1.13。
