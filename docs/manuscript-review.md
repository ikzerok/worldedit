# 可信全分支审稿

书稿的“阅读预览”用于作者校对当前稿。页首常驻“静态全分支 · 不代表真实路线”，既不是试玩记录，也不证明某条路线可达。若需要实际发生的台词、选择与状态，请使用试玩或路线重放。

## 阅读方法

- 默认只读当前章节。“整书”按书稿编排顺序分批加载，每批最多 8 章；“上一批章节 / 下一批章节”和当前范围在正文滚动区外。没有加载的批次不能视为已审完
- 条件组与各分支使用文字标签和实线边框标明，条件及其正文位于同一阅读块，边界编号与层级可悬停查看。单分支条件只呈现一次条件头，相邻独立条件不会合并。相邻选择构成选择组；可见条件、可选条件、一次性选择和不可选说明分别呈现，全部未求值
- 正文和台词采用个人正文字号、行距及阅读宽度。链接与前后中文在同一段落内排版，不因链接组件人为添加空格或断句。链接也有“旁查”按钮，键盘可用
- 台词先显示人物显示名，通过旁边的“身份”按钮查看人物类型和稳定 ID，避免同名人物混淆。作者演出说明单独标为说明
- 场景、call、return、流程去向和结构语句保留原文含义。call 明示未展开；组尾只在“控制流继续”的前提下汇合，不暗示所有跳转都会回来
- 动态文字保留 core 提供的动态标记，不用猜测的状态值替换。原文粘接标记有说明，不跨分支拼成一段

## 定位、修改与返回

1. 选择段落或结构头对应的“定位原文”按钮。悬停按钮可查看完整物理路径、行、列、字节范围及原文片段
2. 编辑器先核对工作区库存与保存基线，再重新编译所有当前文件草稿，核对审稿快照、源片段与文件范围。通过后切到同一个文件草稿的“源码”模式，并选中真实范围；实体描述等声明级来源明确定位到声明
3. 手动修改后，仍须自行决定何时应用与保存。审稿、旁查和来源导航均不自动应用、不自动保存，也不创造另一份可写正文
4. 用“返回审稿”或 Alt+Left 回到原章节和模式。来源版本未变化时保留原光标、选区方向及阅读位置；来源已经改变则不会把旧坐标套到新稿，当前输入仍完整保留

窄窗口使用“编辑 / 预览”标签。宽窗口可并排读写；专注模式也有“阅读预览”入口。Ctrl+Shift+R 切换编辑与审稿焦点；Tab 抵达当前章节、整书、旁查和来源按钮，Enter 激活。来源按钮获得焦点时有明显轮廓并滚入可见区。

源码区的 Tab / Shift+Tab 用于缩进和反缩进；先按 Esc，确认输入焦点已离开源码编辑器后，再按 Tab 到“应用源码草稿（可含诊断）”并 Enter，最后 Ctrl+S 保存已应用的工程修改。Ctrl+S 不会代替正文草稿的显式应用。

桌面来源检查会读取工作区磁盘基线；浏览器只核对已导入的工作区快照，无法观察未重新导入的宿主文件变化。

输入法尚在组合时不执行新来源跳转或返回；请先完成组合。遇到磁盘修改、删除、移动、工作区边界或恢复冲突，定位被拒绝，原位置和草稿保留；先刷新并核对冲突，不必为导航强行保存或放弃稿件。

## 错误与规模边界

当前稿不能解析时，页面明确显示“预览过期”，只允许阅读同一目标的上次有效预览；旧来源按钮停用。某章来源缺失或审稿预算不足时，该章显示失败原因，不跳过失败章节来伪装完整整书。

core 每个完整投影最多 10,000 个节点、64 层、1 MiB JSON；一次编译的来源合计最多 16 MiB。编辑器每批进一步限制累计 12,000 个节点和 4 MiB 审稿 DTO。超出当前批次预算时可单独选择该章审阅；单章本身超限则保留明确错误，不显示截断正文。

整书各章共用同次编译的源快照；翻页后释放不在当前批次的缓存。上述限制是本次审稿能力边界，不影响源文件保存或既有写作、结构、源码、试玩等入口。

## 权限与兼容

该界面直接使用 core ReviewProjection 结构及来源验证 API，不在 UI 重新解释 DSL。旧 ReadingProjection 和读者发布的独立授权流程保持兼容；作者看见的全分支审稿不自动成为公开内容，也不会扩大已选发布范围。
