# 大作品章节导航与正文往返（0.31）

书稿导航按真实书稿和编排项身份组织章节，正文仍来自原有 `.wl` 文件。
产品 0.31 不增加 DSL；默认语言仍为 1.9，最高显式语言为 1.13。

## 从书稿找到章节

打开作品后进入“书稿”。普通布局左侧是“章节导航”；专注模式或小窗口从顶部
“选择章节”打开同一套导航。书稿较多时，在“书稿管理”中选择书稿。

“查找标题、ID、摘要、目标”同时检索章名、编排 ID、摘要和目标字段。
输入多个空白分隔的词时，每个词都须命中。匹配忽略大小写，采用文字包含规则。
例如输入完整编排 ID 可定位同名章节中的具体一章。

“状态”和“POV 名称或 ID”与文字查询共同生效：

- 状态匹配作者填写的状态文字，例如 `draft`、`revised`、`final`
- POV 匹配人物的真实 `kind:id`、ID 或可确认的显示名
- 同名人物和同名章节保留各自身份，不合并结果
- “目标”是编排中的目标字段，可以填写字数数字或目标说明

在高度较小的窗口中，状态、POV 和列选项收进“筛选与显示”，有条件生效时标明
“已筛选”。“清除筛选”清除文字、状态、POV 和分节范围。

默认范围是当前整本书稿。选中分节后点“仅此分节”查看该分节的子树；点“整书”
回到全书范围。筛选始终先检查完整范围，再分页。

## 读懂数量、页与路径

结果同时显示两类数量：

- “匹配 X / 可识别 Y 章”：当前范围中匹配条件的章节数量，以及可识别章节数量
- “a–b / N 行”：当前显示页的实际行范围；树中的分节上下文也计入行数

“上一页”和“下一页”切换当前结果。树和列表每页最多 50 行，卡片每页最多 12
项。末页因改稿而缩短时，导航会调整到最后有效页。页数和显示方式不修改真实编排。

树中的“分节上下文”是命中章节的祖先，不计作匹配章节。没有筛选时可以折叠分节；
筛选时会显示命中项的祖先。当前章节被折叠隐藏时有明确提示，可用“全部展开分节”
恢复查看。

标题旁的身份、路径和来源可悬停查看完整文字。当前页中的选中项还显示祖先路径。
路径带有分节标题和稳定 ID，所以同名分节也能区分。

若当前章节在另一页，可点“定位当前章节所在页”。当前章被筛出时，导航会说明，
正文和未应用输入继续保留；筛选不会自动把正文切换到另一章。

## 选择合适的信息密度

书稿管理保留三种显示方式：

- “章节树”：竖向显示分节层级、折叠状态、命中上下文和章节元数据
- “列表”：使用紧凑可选列表格，适合横向对照多章信息
- “卡片”：竖向阅读单章作者元数据，用“查看章节”选择正文

“显示列”可以选择编排 ID、摘要、POV 与身份、状态、静态统计、写作目标、正文
来源。摘要、POV、状态、静态统计和目标默认可见，作者可关闭不需要的字段，个人
关闭设置会保留。只有“列表”使用横向可选列，列较多时可以横向滚动；“章节树”和
“卡片”保持竖向可读的元数据，不会把章名推到横向视口之外。
选择的字段、筛选、布局、折叠和导航位置属于个人会话，不写入作品的书稿 JSON。

同一功能沿用现有 Studio、Manuscript、Technical、Focus、Ledger 结构和配色设置。
专注模式的“书稿工具 / 书稿管理”仍可进入显示方式和编排行为。

## 进入正文，再返回

单击一行选择章节。结果获得焦点后，上下键移动当前页中的真实编排项；Enter 或
双击章节进入正文。在检索框中按向下键或 Enter 可把焦点交给当前页结果。
专注模式的“选择章节”菜单中，单击章节就会关闭菜单并把输入焦点交给该章正文。

正文继续使用原有写作、结构和源码模式，同一文件被多章引用时仍只持有一个文件
草稿。阅读预览和旁查不会复制出第二份正文。

通过既有来源、资料或审稿入口旁查后，使用“返回审稿”或 Alt+Left 返回原作者
位置。会话记录书稿 ID、编排 ID、筛选、显示列、页、导航滚动和编辑模式；原来源
与稿件仍符合校验条件时才恢复光标和正文位置。保存后重新打开也按这些真实身份
恢复。

原章被删除、来源目标已改变或 ID 重复时，不自动打开同名替身。没有可确认的
选择时会要求重新选择；未应用正文仍可从“保留的正文草稿”查看或复制。

## 当前稿、应用与保存

导航优先投影明确的未应用编排草稿和当前文件正文草稿，并标为“当前未应用稿”。
没有这些输入时显示当前工程稿。浏览、检索、折叠、切页和切显示方式都不应用或
保存。

编排与正文各自应用：

1. 在“编排与来源”修改标题、摘要、状态、目标、POV、来源或层级
2. 核对当前未应用稿，点“应用书稿”提交编排
3. 正文输入使用正文区域的应用动作；它与编排草稿分开处理
4. 应用后仍需保存工程；沿用原有撤销与保存流程

“恢复书稿草稿”明确丢弃未应用编排，正文文件草稿继续保留。删除编排项要确认，
它不会删除源码对象或文件。删除后需要重新选择位置。

正文有编译错误时，导航仍保留可识别编排，但来源和统计可能无法确认；阅读预览
会标明过期及原因，若显示同一目标的上次有效预览，也会明确它不是当前稿。
基线冲突时不会用已应用稿冒充当前草稿。保留稿可以继续查看；预览应用和实际应用
仍重新检查内容、原文、只读状态与磁盘保存基线，不能覆盖较新工程。

原书稿本身已有坏节点、重复 ID 或损坏父链时，不能通过仅含可识别项的编排表单
悄悄修复原文。需要先检查原始书稿诊断和原文，保留未理解的内容。

## 来源、静态统计与不完整结果

来源分别显示已解析、缺失、暂不可确认或引用类型无效。缺失来源的章节仍占其
编排位置，无法确认的统计不会显示成零。

词数和汉字数是源码静态正文统计，包含静态分支和选项文字，不代表任何实际试玩
路线看到的文字量。书稿阅读顺序不生成时间顺序或事件执行连接。

“范围未完整确认”说明当前结果只能覆盖可识别项。“快照问题”可以按批次查看
完整诊断列表。零命中不能说明作品没有问题；坏注册或无法确认的书稿也不会显示
成正常空书。

重复 ID 的可识别行会标明“身份重复”并停用选择。即使另一条同 ID 原始记录的
种类无法识别，也仍算身份冲突；它不能成为导航位置或分节查询范围。

## 外部变化和浏览边界

桌面沿用工作区刷新。新增、删除或修改附件及其可读性会让相关浏览缓存失效；
相同的无变化刷新不会使正文撤销失效。刷新失败时，导航明确标为无法完整确认，
原输入继续保留。

浏览器仍是导入快照。磁盘外部修改需要重新导入；宿主更新附件并重新分析时会
重新生成相关只读结果，不能把浏览器快照说成实时目录监视。

已有不可变快照内的筛选和分页不读取文件系统。生成快照复用既有 core 的只读
编译、注册路径身份和附件检查，可能读取相应元数据；源码只来自已载入缓冲，
没有缺失源码回退，也不做提交保存预检。画面说明的是已载入快照，不承诺磁盘在
浏览期间一直未变化。真正来源跳转、应用和保存仍有各自的即时守卫。

新章和来源创建见 [新章作者契约](https://github.com/ikzerok/worldline/blob/main/spec/manuscript-authoring.md)；
目录刷新、冲突与浏览器边界见 [工作区操作](workspace.md)。
