# 发布静态读者包

“发布给读者”用于制作只含明确选择内容的离线阅读站。“导出工程”仍用于完整备份，包含工作区内未引用的附件、隐藏资料和其他文件。发布阅读包不会裁剪或替代工程备份。

## 选择与预览

在工作区顶部打开“发布给读者”，填写站点标题，再逐项选择资料对象、书稿章节和已登记附件。对象、每本书稿的章节和附件都需要单独选择；正文链接、章节来源、地图显隐和附件关系不会自动扩大公开范围。结构有诊断或只读的书稿、当前不可用的附件不能选择。

“生成 / 更新预览”只调用 worldline-core 的同一份公开清单，不写文件，也不改变作品内容、保存基线或撤销历史。预览显示纳入条目数、静态文件数、文件与 ZIP 大小、可见页面，以及未纳入原因。未选内容的引用在阅读站中显示通用“未公开内容”，不显示其 ID 或来源路径。排除明细仅留在作者窗口中，不写入阅读包。

预览对应当前作品内容与所选附件。作品或所选内容变更后需要重新预览；旧预览会失效。发布前勾选确认框，表示你已核对这次离线包的范围。

## 生成与核对

桌面版把 ZIP 写到指定的、位于工作区外且尚不存在的路径，不覆盖已有文件。生成过程中可以取消；预览、取消或发布本身都不会保存或修改作者工程。发布完成后可将 ZIP 解压，在任意浏览器离线打开 `index.html`，再从搜索页检查公开内容。

Web 版使用浏览器下载 `worldedit-reader-site.zip`。界面报告下载已启动；文件最终保存位置和浏览器之后报告的下载错误由浏览器管理。拿到阅读包的人可以查看包内的全部内容，因此这项功能只控制本地生成的离线范围，不提供账号、在线权限或服务器访问控制。

更完整的选择 DTO、预算、静态资源和失败边界见配对 worldline 版本的 [`spec/reader-export.md`](https://github.com/ikzerok/worldline/blob/96b53bd82fe3412952ff82318c3474e2b1547a1f/spec/reader-export.md)。
