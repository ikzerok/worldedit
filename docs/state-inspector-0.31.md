# 真实试玩状态检查（0.31）

状态检查用于回答：**这次实际试玩中，某个值现在是什么，与首次或上一条真实观测相比有没有变化？**
它读取当前试玩会话，不修改变量、不执行额外表达式、不消耗随机数，也不替作者选择路线。
默认语言仍为1.9，最高显式1.13；使用检查器不升级作品语言或存档格式。

## 从一次真实选择开始

1. 打开作品，进入“试玩”，点“开始试玩”。运行范围是当前**已应用工程稿**，包含已应用但尚未保存的内容；尚未应用的正文、表单等输入不自动加入。
2. 做一次真实选择，等待到达下一组选项、正常结束，或明确的预算暂停/错误位置。
3. 点选择侧栏顶部的“⌕ 状态检查：查值与变化…”，打开“状态检查 · 当前真实试玩”窗口。
4. 在“状态与变化”中输入名称、片段名或当前值，选择范围与比较基线，再按需要勾选“只看变化”。
5. 阅读每项的“首次”“上次”“当前”和变化标记。需要追查时切到“实际条件 / 动作证据”，或用可用的声明定位按钮回到作者源码。
6. 从源码按 `Alt+Left` 返回；检查完后点“返回试玩与选择”或关闭窗口，继续自己选择路线。

窗口可调整大小。较宽时三份值并列，较窄时按当前、上次、首次竖排；窗口和结果区可滚动。
检索入口与返回按钮不在长选项列表底部。打开窗口期间，正文自动推进和选择确认暂时被屏蔽；查看不会产生一次新观测。

## 查什么，怎样筛选

- **全部**：包含以下三类当前项目
- **全局**：工程中真实声明的全局变量，包括已声明但该路径尚未执行初始化的变量
- **调用局部**：当前仍活跃的片段调用参数和局部变量；标题显示片段及调用编号
- **状态集**：各个独立状态当前包含的标签集合

同名全局变量与局部变量是不同项目。重复或嵌套调用同一个片段，也以不同调用编号区分。
已经退出的调用不继续显示为“当前局部值”；另一次同名调用不能继承它的比较基线。

检索采用名称、片段名和值的子串匹配，按Unicode小写折叠比较，不是正则表达式。
检索词最多256个字符。**当前字符串和标签按完整真实内容检索**，即使展示因长度限制只保留了前缀，也可能命中后面的内容；首次、上次只检索实际保留下来的显示内容，不能搜索已省略的历史部分。

编辑器每页50项，先对完整当前项目集合筛选，再分页。“匹配”是本次筛选的精确结果数，“共”是当前全部项目数。
“不可比较”统计名称/范围筛选后、被“只看变化”排除前的不可比较项目，因此可能同时看到“匹配0”和“不可比较若干项”。
没有匹配不代表工程没有问题，也不代表其他路径没有变化。

“只看变化”默认比较**上一观测**；选择**首次观测**后改为与首次比较。不可比较项不会被当成已知变化塞入结果，也不会被当成值未变化。
想查看这些项目时，取消“只看变化”。修改检索、范围或基线会回到第一页；运行观察变化后旧分页位置也会重新查询。

## “首次”和“上次”究竟是哪一次

这里的“观测”是运行记录真正写入的一次完整观察，通常发生在到达选择组或正常结束时。
**创建试玩会话、初始化变量、打开检查窗口，都不自动算作首次观测。**

### 当前已记录在选择或结束边界

- **首次**：本条真实路径第一次写入的观测
- **上次**：严格在当前观测之前的上一条已完成观测
- **当前**：此刻实际记录的观测

例如当前就是观测1，“首次”可以与当前相同，但“上次”仍不存在。不能用变量声明中的初值补出一条上次记录。
到达正常结尾也适用同一规则，不把“首次”一概称为首次暂停。

### 当前是部分推进状态

成功选择后尚未继续、步数/时间预算耗尽、推进被取消或运行错误时，当前值可能已经提交，但还没有形成下一条完整观测。
这时：

- **首次**仍是第一次真正记录的观测；若尚未发生，则没有首次基线
- **上次**是最近一条已经完成的真实观测
- **当前**是明确标为部分状态的实时值，不冒称已记录的完整观测

窗口会说明“当前为实时部分状态”或“当前为观测 #…”，并指出“上次”所指的位置。
重复查看同一个暂停组不会把当前值挪成上次；手动暂停、停止也不制造新观测。
预算暂停、运行错误、停止和正常结束分别显示，不能互相代替。

## 值、缺失和比较标记

数值、字符串、布尔、标签身份、标签集合和状态身份保留各自类型。
`0`、`false`、空字符串 `""` 和空集合 `[]` 都是已经存在的真实值。
状态标签集合按成员比较，不能把集合的显示文字当成普通字符串。

以下提示有不同含义：

- **未初始化**：声明存在，但该运行位置尚无该变量的值。它不是0、false或空字符串
- **该调用当时不存在**：有真实基线，但当前这个调用实例在那次基线中尚不存在；不能拿另一次同名调用替代
- **无已记录观测**：所需的首次或上次观测根本不存在；没有值可供比较
- **观测值已省略 / 长值省略**：观测或当前值存在，但超过保留或显示预算，未提供完整值；这不表示为空，也不表示未发生过变化

变化标记也分三种：

- **有变化**：两侧存在足够的真实数据，类型或值不同；已知未初始化变为已初始化也可判定为变化
- **值未变化**：两侧可比较且类型和值相同；不代表没有执行过写入语句
- **不可比较**：缺少观测、调用实例不相同或完整值已省略；不能从相同的截断文字推出相等

## 保留预算与长值

检查器只额外保留首次、上一、最近真实观测所需的数据，不保存一份无限增长的独立调试历史。
每份基线最多4096项、计量后的保留数据最多1MiB；单个值序列化后超过2048字节时明确省略完整值。
这是有界保留，不是随机取样，也不会为满足检查器预算删除原路径记录。

当前长字符串提供有界前缀和省略提示，其他过长值也明确标为省略。
当前完整值仍可检索，但超大值没有完整的比较数据时会显示不可比较。首次/上次被省略的部分无法凭当前值反推恢复。

一页机器投影最多1MiB。超额会明确报错，不会偷偷删字段后宣称完整；可缩小检索词或范围后重试。
CLI/RPC还可把每页条数调低，允许1–100项。机器接口的页偏移超过匹配总数时返回空页及精确总数，不静默回到第一页。

使用CLI/RPC分页时，把返回的`stamp`原样放进`query.expected_stamp`。
这个新检查戳的`run_id`、`compiled_snapshot`、`fingerprint`、`trace_generation`和`revision`
在JSON中全部是十进制字符串；例如`"9007199254740993"`必须保持为字符串，不能转成
JavaScript的Number再回送。只接受`"0"`或没有前导零的ASCII数字字符串，最大为
`"18446744073709551615"`；数字类型、正负号、空白、小数、指数、溢出、缺字段和未知
字段会被拒绝。格式合法但运行已变化时，才按过期检查戳处理。这一新编码不改变现有
存档、路径JSON、state_view或其他接口中的数值字段；图形界面的检索操作不受影响。


## 实际证据不等于因果推断

切到“实际条件 / 动作证据”可以查看：

- 当前选择组已经产生的真实条件缓存；展开不会重新求值，也不额外消耗随机数
- 当前运行状态中最近64条实际状态变更记录，包含前后标签、回合、节点与动作种类；更多记录仍保留，界面会说明本处只显示最近部分
- “打开路线对照：查看已录制路径的动作 / 变量写入证据”入口，进入既有路线对照流程

状态变更记录中的长标签集合也有展示省略提示。这些记录没有可供直接定位的精确写入来源，不能靠节点名或终值猜一个源码行。
从检查点恢复时，其中的状态历史还可能包含本次记录起点之前的动作。

路线对照需要选择已有路径并明确运行；状态检查不会替作者自动重放。
变量的实际写入、同值写入及其可用来源，应到该流程已有的真实证据中看。缺少写入证据时，检查器不会声称知道“最后是谁改了这个值”。

**值有变化，只说明观察之间的结果不同；值未变化，也可能发生过一次或多次写入。**
当前这一条路径到达结尾，不证明所有分支都正确或都已覆盖。

## 声明回源与返回

全局变量提供“定位变量声明”，状态集提供“定位状态声明”。定位的是由当前编译快照验证过的**声明头**，不是最后一次写入，也不是表达式中某个运算符的精确位置。
当前局部值没有可验证的声明来源时会明确不可定位，不猜测相邻行或当前打开的文件。
真实条件证据沿用它自己的“定位选择声明”“定位规则定义”入口。

跳转前会检查：检查项仍属于同一次运行和观察位置、来源身份仍匹配、已应用稿与完整源码集合仍一致，且不存在阻止定位的未应用执行草稿、输入法组合或工作区冲突；实际跳转还核验磁盘基线与工作区边界。

- 改稿后，旧试玩仍可只读查看，但会标明旧运行快照；旧行号不能套到新稿上
- 来源被删除、移动、改名或外部修改时，定位可能被拒绝；按提示先处理稿件与冲突，再重新运行
- 检查器不会为消除拒绝而自动应用草稿、保存工程、恢复旧源码或重新开始

成功跳转复用既有作者导航，优先进入能够准确表示该来源的写作入口，否则回到源码。
`Alt+Left` 沿原有导航守卫返回同一试玩检查位置；会话与检索筛选仍在。若期间编辑改变了导航基线，返回也遵守现有草稿保护。

关闭检查时，最近有效的选择按钮可恢复键盘焦点；恢复焦点本身不触发选择。
确认键须释放后再作下一次确认，避免一次Enter/Space连续走两步。其他键盘行为见[连续键盘试玩](keyboard-play.md)。

## 返回、保存、重放与重新开始

### 返回或关闭

“返回试玩与选择”和窗口关闭按钮都不是一次“继续”或“选择”。
已有的手动暂停、预算暂停、停止、正常结束和错误状态会保留；关闭不会解除暂停，不会复活停止或失败的试玩。

检查窗口只是暂时屏蔽正文原有的自动推进，并不替代“暂停”按钮。
如果在尚未完成首次推进等原本可以自动运行的时刻打开它，关闭后仍会按原运行状态处理后续帧。
需要关闭后也一直停在原处时，先明确暂停试玩；需要从预算暂停继续时，再明确点“继续”。详见[有界试玩](bounded-play.md)。

### 保存与重放

检索词、筛选、检查页、观察缓存和调用编号属于当前会话，不写入作品或普通存档。
检查不代替保存工程，也不代替记录或导出路径；“保存全部”不会把检查页变成持久调试记录。
需要留存实际路径时使用叙事调试器的保存与导出入口，见[有界路径交换](replay-exchange.md)。

“原路径逐步字段变化（只读记录）”继续提供原始记录的顶层JSON字段视图。
可读的导入路径不因此变成当前正在运行的Story，也不获得当前源码导航权限。
重放、路线对照和报告继续使用各自的版本、预算与来源保护；旧版本可读不代表可执行，本功能不迁移旧轨迹。

### 重新开始、载入与换工程

“重新开始（已应用稿）”会建立新的真实运行，清空旧检查窗口与绑定。首次基线需由新运行重新产生，不能沿用上一轮的首次值或局部调用编号。
换工程也清空检查绑定；改稿本身不会把正在运行的旧快照自动替换成新稿。

经runtime/机器接口从存档或检查点恢复时，检查器只拥有恢复后真正产生的观测，不补造恢复点之前的首次和上次。
显式从中途建立新路径记录时，比较基线属于该段记录，不能冒充从故事入口开始的完整历史。

本指南描述已实现的使用规则，不是某个平台或物理输入设备的验收证明；原生界面、浏览器宿主、物理键盘与输入法的验证范围应以对应发行验证记录为准。
