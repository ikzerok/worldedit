# 0.11 有界试玩

普通试玩的每次推进使用 runtime 的显式有界接口，默认最多 100,000 个解释器步骤或 250 ms。步数与时限可在开始前、暂停后调整；它们是本次工作台的运行设置，不写入作品、不改变语言版本或运行指纹。范围为 1–1,000,000,000 步和 1–2,000 ms；更长的合法稿可提高预算或分次继续。

预算耗尽显示「达到步数/时间上限，已暂停」，保留当前输出和已提交状态，不显示正常结尾、不自动在下一帧反复继续。作者可明确继续（给下一次推进新的预算）或重新开始；继续不会重放之前的输出、效果或随机数。手动暂停保留当前位置；停止终止当前工作台演练并显示「试玩已停止」，不冒称故事到达 END。重新开始使用当前编译快照和所选种子，清空本次演练输出。运行错误保留已显示内容，并要求重新开始。

切到其他页面可继续编辑原稿。编辑稿变化后，已有试玩仍明确属于旧快照；不会自动覆盖当前结果或把旧结果说成最新稿。调试重放的预算与普通试玩分开，不能用调试器的限额替代普通试玩保护。

预算在解释器步骤之间检查；单步表达式、事件效果与初始化不是可在中间撤销的事务，不承诺任意代码的硬实时抢占。当前单次推进最多占用所设时间加一个步骤的完成时间；桌面按钮在返回后响应。真实 Linux 原生验证与 egui 离屏回归分别记录，不以后一种宣称前一种通过。

纯时段历史资料的普通检查不因默认首事件而要求结尾。作者明确启动试玩后，由core按当前真实入口追加可定位提示：该入口可显式结尾，作为历史资料无需 END；提示不阻止合法自然结束。已有执行控制的可达时段事件仍使用统一流程分析。
