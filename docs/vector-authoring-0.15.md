# 0.15 矢量地图作者工作流与渲染资源契约

状态：0.15 候选的实现与验收契约。本文不表示功能已完成或测试已通过；须以当前代码执行门禁与原生验收。

地图格式、几何、SVG 安全 profile、事务和诊断的唯一真源在配对 worldline 的 `spec/vector-scene.md`；既有展示与阈值见 `spec/presentation.md`。工作区边界沿用 [workspace.md](workspace.md)。本文规定作者交互和派生渲染，不另立语言/SVG 解析器。

## 1. 作者闭环与兼容

作者应能连续完成：创建空图或选择旧图 → 启用原生矢量编辑 → 拖绘基本图形/开放与闭合曲线/多子路径/文字 → 选中与节点编辑 → 样式和变换 → 组与图层操作 → 对象绑定 → 撤销/重做 → 保存并重开 → SVG 导出和受支持交换再导入。

另一入口是选择本地 SVG 或粘贴源码 → 安全预检 → 核对同一地图坐标中的真实预览与诊断 → 明确确认 → 原子添加图层 → 继续上述编辑。取消、错误、只读状态或过期预览不得留下部分图层、实体或绑定。

- `MapDocument.scene` 的 typed 数据是矢量编辑真源；SVG 原始输入只用于导入诊断/来源，不成为执行内容或第二真源
- path 保留真实段、控制点、多子路径与 Close，不用渲染采样线回写曲线
- 旧 placements、文字标签、raster 底图、校准与尺子、导航历史、资料反查、展示预设和批注继续可用
- 新 scene 能力须显式登记；旧工程打开时不自动迁移标记或升级语言。未知 required feature/格式仍只读保留原字节
- 地图编辑不创建模拟状态、自动关系或地理归属。删除图元不删除绑定资料
- 普通应用修改进入内存与一次工程历史；保存仍走已有 Project 保存/冲突/恢复事务，不把预览当已保存

## 2. 地图工作台

左侧为稳定地图索引，中央为画布，右侧为当前选择检查器或图层/对象树。高频操作位于紧邻画布的上下文工具条，长表单按当前对象渐进展开，不能将所有工具塞入长滚动侧栏。

- 工具条清楚区分浏览、选择/节点、绘制、镜头与测量；始终可找到当前草稿的完成/取消
- 选中对象后，名称、类型、绑定与主动作优先可见；新选另一对象时检查器滚回其详情入口
- 每次节点/控制柄拖动、样式或变换提交后，保留仍有效的选择、镜头与检查器上下文；失效局部句柄退回对象选择，不清空整项选择
- 窄窗口可折叠检查器，但不能隐藏未应用草稿及其取消/应用入口
- 明暗主题使用全局控件/字体/间距和 surface token；画布外围、文档边界、透明区域、选中/禁用/错误/等待状态可区分
- 面板滚动不带动画布；工具快捷键不抢占文本输入/输入法组合中的编辑键

## 3. 创作、选择与结构编辑

绘制工具覆盖点、线、区、矩形、椭圆、Bezier 与文字。矩形/椭圆由按下拖动释放形成原生几何；线/路径有明确结束动作；Enter 完成、Escape 取消，旧双击结束习惯保留。平移可用工具、Space 临时手势或中键，不改变作者数据。

Bezier 创作保留控制柄，支持开放与闭合路径，以及一条 path 内的多个子路径。工具条有明确“闭合并填充”与“添加子路径”入口；Alt 可作为添加子路径快捷方式，不能成为唯一可发现入口。各子路径是否 Close 保留；不能把闭合路径显示成开放描边或将多子路径拆散丢失填充关系。

新建样式跟随当前绘制上下文，分别验证开放描边与闭合填充。可改 fill、stroke、宽度、opacity 与 fill-rule；继承、none 与显式值必须可区分。已有合法字段值不能因为打开检查器或 UI 范围夹紧而被无提示改变。

选择支持点击、Shift 多选和框选；节点模式显示真实端点和适用的 C/Q 控制柄，编辑核心坐标而非派生折线。输入非法/超限/退化数据时显示核心原因并保留输入，不静默修形。多选拖动保留各自父坐标变换，整次拖动释放提交一个事务。

选择上下文提供复制、删除、成组、拆组、置前后和移到目标图层。对象树保留组缩进、显式稳定顺序、显隐、锁定、多选与双击定位检查器。大树采用有界布局/可见行处理或经测量证明满足帧门槛的等效方案，不能每帧无条件复制整场景并生成所有不可见行。

图层显隐在浏览模式是个人临时状态；编辑默认显隐与锁定是明确文档动作。移层必须调用核心专用操作，保持 world affine、继承后的视觉、子孙层归属和锁定边界。图层重排继续由 `map.layer_order` 定义。

## 4. 文字、绑定、导航与迁移

文字使用核心允许的纯文本与 typed spans、字号、颜色/样式和 affine；输入内容经安全 serializer 转义，不解释脚本、HTML 或外部字体。预览和重开使用同一内嵌字体，不能用近似文本 bounds 代替正文绘制。

绑定既有对象使用 core TargetRef；“新建地点并绑定”先由核心生成一个候选，预览后一次原子应用，一个 Undo 同时撤销创建与绑定。UI 不复制世界对象语义或自行合并两个事务。

从资料、搜索、批注或子地图入口定位时，新 scene ID 与旧 placement ID 使用同一路径。隐藏目标先明确询问临时显示；包含隐藏祖先的目标也须可到达。只读定位不写入显隐、关系或撤销历史。图元保留批注与进入子地图入口，访问返回恢复已有镜头规则。

旧标记迁移必须显式预览与确认。默认“预览迁移本层全部旧标记”，另有全图入口，列出准确受影响 ID 和数量；不自动扩大用户选集。核心只接受可保原叠放的整层或后缀子集，拒绝任意中段迁移；UI 展示其原因。稳定 ID、metadata、样式、未知字段与引用保持，旧 placements 原子移除，不能保存两份编辑真源。风格无法无损迁移时整批拒绝。

## 5. SVG 坐标、viewport 与安全交换

安全 profile 由核心单源定义。UI 只传入文本并消费 typed preview、诊断、几何与安全 serializer 输出，不以 regex、XML DOM 或浏览器 SVG 执行补充核心语义。

- 导入预览、应用后的画布、导出再导入使用同一 core viewBox/viewport/affine 变换；非零 viewBox min、宽高非等比、反射、旋转与嵌套组不得各自另算一套比例
- `preserveAspectRatio` 的 meet/none/slice 均按受支持核心 profile 保真；仅算 slice 矩阵而漏掉根 viewport 裁剪不合格
- 根 viewport 裁剪使用核心 typed `clip_rect`，随编辑、复制/组/移层、序列化与交换保留正确坐标。仅允许核心精确定义的安全本地矩形 clipPath 交换形式；这不开放任意 clip/mask/filter、嵌套 svg viewport、外链或脚本
- 画布命中与选择遵守有效裁剪；对象树仍可明确选中裁剪外的节点供编辑，但不能把画布上不可见的裁切外部分当成可点正文
- 曲线与 text affine、nonzero/evenodd 复合填充及组 opacity 必须经同一安全渲染路径显示；不以逐多边形拼接近似孔洞或重复乘组 opacity
- SVG 导入失败保留完整输入和带位置的错误，不能生成半个图层。大文本可默认折叠，仍有完整编辑/复制入口
- “导出矢量 SVG”包含选择范围内 legacy + scene，按真实地图层序输出；raster、世界源码与附件由完整工程备份另行保留，界面明确 SVG 范围
- 源代码、作者未知扩展和不受支持字段不原样拼入输出；导出再导入仅承诺冻结的交换 profile

## 6. 异步任务、取消和一致性

SVG 读取/预检、场景预检、组合绑定预检和像素渲染使用 native 后台任务或同源 Web Worker。共用 typed core 请求/结果，不在主线程运行大 SVG 解析或 resvg 栅格工作。超过 250 ms 的前台等待必须有有用的进度/阶段/原因及取消，不以转圈掩盖同步卡住的 UI。

后台 Project 以精确当前字节、跟踪集合和删除墓碑复原内容基线；私有 saved 参照不等于复制原会话保存历史，具体见配对 worldline `spec/workspace-snapshot.md`。生成快照不能通过 refresh/compile/export 顺便改变工程。Worker 只返回 typed 预检结果/规范化批次或像素，不直接写作者文件。

应用前核对工作区身份、任务代次、修订与完整内容/文档 baseline；Worker 返回类型、任务 identity、像素规格/长度也必须匹配。过期、取消或被替代结果零应用、零下载。无效草稿/冲突时输入保持，重试需重新预检；迁移 retry 仍需确认，不能自动提交。

取消响应目标为 500 ms 以内：关闭预览/切图后界面立即退出或明确显示取消中，后台结果失效。native 计算未结束时仍占实际活动许可；不能将“UI 不再等”冒充线程已停止。WASM 取消终止 Worker 并清理 file picker 事件/DOM；晚到回调不能复活已关闭表单。

## 7. 显示后端与资源上限

屏幕纹理仅是核心 scene 的派生缓存。resvg 0.48.1 使用核心安全 serializer 输出，关闭外部资源/图片解析，只加载工程随包内嵌字体。native 与 Worker 调同一纯像素函数。解析渲染库不能替代 core 的安全 profile。

纹理按实际 viewport、zoom、pan 与设备 DPI 重绘；不得固定低清图放大、不为通过预算降低 DPI。坐标换算只乘一次 DPI。纹理缓存 key 包含能影响像素的 scene/clip/视图参数；暂显旧纹理必须标过期/等待，不能当成完成结果。

数值单源登记在 worldline `spec/presentation.md` §11，本节解释 v0.15 适用语义：

- scene 图层和导入预览共用调度，最多 **2 个实际活动渲染 job**，不能按图层各自开无上限线程/Worker
- 我方显式管理的 scene RGBA 工作缓冲与纹理 cache 合计预算：**native 128 MiB；WASM 64 MiB**。MiB = 1,048,576 bytes；这是 scene 渲染预算，不挪用或悄悄扩大既有 raster 预算
- 开任务与分配完整 viewport 前 checked 计算 `width × height × 4`，按实际同时存活的输出、裁切副本、ColorImage/纹理存储预留，不能在裁透明边后才计费；初始保守预留三份 viewport RGBA，若实现同时存活更多份须提高预留或消除副本
- cache lease 与 in-flight reservation 共享计数；结果收取时验证尺寸，原子转换为实际缓存费用。错误、终止、丢弃、隐藏层和替换 cache 释放其费用
- native 许可必须被实际执行线程持有，切图/Close/丢接收器不能提前放行第三个 job。Worker 许可直到终止或完成才释放
- 预算不声称涵盖 resvg 树、字体、驱动延迟回收或全部进程 RSS。resvg 隔离组可能另分配中间 Pixmap，必须单独预检可证明的尺寸/嵌套工作集上界并在不可容纳时明确拒绝；不得将三份我方 RGBA 预留宣称为任意 SVG 总内存上限
- 资源保护不改变 map 的合法 layer/node 语义，不静默丢层。绘制仍逐层保持 legacy → scene 次序，不能将所有 scene 合并压到所有 legacy 顶上

调度状态必须可解释：

1. **排队等待**：有正在执行的任务可释放临时资源；显示待处理层数/当前阶段，完成或释放后继续
2. **资源不足，需要操作**：当前 viewport 本身或可见缓存工作集无法容纳；显示具体图层、申请量、当前占用、平台预算及临时隐藏图层/缩小窗口等可行操作。不能无限排队、默认该层已显示或缩减内容
3. **渲染失败**：保留核心/渲染错误与原输入，作者可修改后重试；其他合法层/地图继续可浏览

数千层的提示使用汇总加可查看的逐层明细，不能在画布重复绘制数千行错误。缩放/平移中的旧 job 可取消或合并最新请求，不能堆积所有历史视口任务。

## 8. 自动化与真实验收

所有结果以当前候选代码和固定 fixture 生成。每个 Rust 文件（含 tests）最多 600 行；fmt、native/WASM Clippy、完整测试与 release 构建必须针对同一配对候选执行。

自动化至少覆盖：

1. 开放/闭合 Bezier、各子路径 Close、Alt/可见按钮新子路径、继承/nonzero/evenodd、分别新建样式，undo/save/reopen 后真实 path 段仍在
2. 节点/控制柄/多选拖动后有效选中与镜头不丢；检查器先真实滚离详情，再画布选另一对象后详情可见，camera 不变
3. group/ungroup/duplicate/reorder/移层、锁定祖先、对象 ID 避重、绑定/新建地点原子事务、导航/批注/反查与隐藏层确认
4. 旧整层/后缀迁移保顺序与 ID，任意中段和不兼容 style 零变更；一次 Undo 还原
5. 400% 实际像素、affine text、组 opacity、复合孔洞；不同 viewport/viewBox/min、meet/none/slice 根裁剪与导出再导入；任意 clip/外链/脚本仍拒绝
6. native 读取边界竞争、WASM picker 无 worker 时仍可 poll、取消及 late callback 清理、baseline/tombstone 精确快照、伪造/过期 worker 返回拒绝
7. 5000 个分层请求同时到达时实际 job ≤2；取消 UI 后线程未结束仍占许可；缓存加预留不越预算；高 DPI/巨大 viewport/隔离组超限给明确原因，隐藏/释放后可恢复
8. 循环切图/重开预览/重复取消没有缓存、线程或 Worker 许可泄漏；所有取消/失败无部分文档或输出文件

性能目标按固定机器/fixture、release、冷热分开并重复测量：1000 简单 SVG 图元 parse + plan + apply ≤3 s；5000 scene nodes 交互 CPU p95 ≤33 ms；取消反馈 ≤500 ms。dense fixture 必须同时有单层复杂树与多层资源压力，不能以单层通过证明跨层安全。

headless egui update/tessellate 探针可定位树布局和 clone 开销，必须标明不是 native FPS/GPU/present。最终至少 20 分钟真实 Linux 原生作者闭环，包含旧功能回归、400% 曲线、保存重开、异常/取消、密集树与多层。浏览器入口另验同源 Worker 和 SVG 交换；未实际执行的平台、物理输入法或可访问性认证不得称已通过。
