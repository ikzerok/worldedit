# 译文制作与真实体验工作台

本规范定义 0.33 的作者体验与验收边界。语言、目录、token 校验、合并、事务与运行规则来自 worldline-core/runtime；编辑器只保存交互状态并呈现其结果。JSON 是高级交换入口，不是日常翻译的主编辑界面。

## 1. 作者闭环

1. 打开“本地化”，选择源语言和目标语言。语言标识区分大小写，不自动规范化。目录显示当前已应用工程稿中的正文、台词与选项；未应用正文草稿保留原样并明确提示不属于这个目录快照。
2. 从目录发现缺少稳定 ID 的条目，输入明确 ID，预览受影响源码与基线，然后一次应用。重复 ID 要由作者处理，不能静默挑选或以行号、文本哈希当永久身份。启用语言能力沿用明确的能力升级流程。
3. 按状态、来源或文字筛选有界目录。页头显示 core 返回的匹配数、工程总数及当前范围；翻页与筛选不丢失未提交译文。选中项显示源文、译文、来源、身份与真实状态。
4. 直接编辑译文的可编辑文本段和链接标签；占位符及链接身份呈现为不可修改的 token。调整顺序只移动完整 typed part，校验和组装都由 core 执行。空译文须显式保留，不能被当作未翻译。
5. 预览列出本次明确选择的 ID、语言、受影响文件与诊断。取消保持输入且不改工程。应用只更新内存 Project，一次撤销与重做覆盖这组修改；“保存工程”另行落盘。Web 使用同一内存 apply，再沿浏览器工程下载/保存边界交付。
6. 在高级交换区导出明确白名单或导回 UTF-8 JSON。保留既有交换协议与诊断；不把上下文、说话人、表达式或对象目标偷偷放入交换包。
7. 从“试玩”选择源文或目标语言及明确的回退策略，开启经过验证的真实 runtime 会话。源/译对照显示来自同一次源顺序求值的结果。逐条返回精确源文或译文，修正后明确重新开始体验；旧会话不在后台重执行。

## 2. 版面与视觉

- 工作台上沿固定显示语言、未提交数量、当前快照与主要动作；清楚区分“预览”“应用到工程”“保存到磁盘”
- 宽窗中左侧为紧凑目录与过滤器，右侧为源译双栏；目录不展示整段 JSON，长单元只显示摘要与状态文本
- 窄窗或高缩放下，目录与当前项采用可返回的单栏导航，源/译分段切换或上下排列；主要动作可换行，不能依靠横向溢出或不可达的底部按钮
- 紧凑语言配置为有界的源/目标字段行与已有语言选择；首次应用注册目标语言后新增的 Combo（含箭头）仍须完整留在窗口宽度内，不能把后续说明或目录一起撑宽。宽窗保留同排语言配置
- 鼠标移动与按下既可能分帧，也可能在同一原生 UI 帧送达；已有语言 Combo 在两种合法时序下打开后均须保持锚按钮完整可见，不能把按下前的移动当作滚动惯性而让按钮滑出视口。局部显露不能取消全局拖动或触屏能力，也不能持续对抗作者后续主动滚动
- 短视口以全局标题、工具栏和状态栏扣除后的真实可用高度决定布局。窄或短工作台采用覆盖标题、语言、动作、目录/详情及高级交换的单一主纵向滚动；不得让固定头部挤掉唯一可滚区域。宽高充足时保留双栏独立滚动。滚动、切页签或预览/取消不重建或丢弃作者输入
- 短窗的 Tab 与 Shift+Tab 导航须把当前焦点控件滚入实际可用视口，覆盖目录控制、译文详情和高级交换；不能让焦点落在屏幕外后要求鼠标补救。仅响应本次键盘导航及其延后一帧交付，不用陈旧焦点持续拉回作者主动滚动的位置；焦点导航本身不编辑、预览、应用或提交输入。代码输入框中的 Tab 缩进保持原字段焦点，不当作焦点转移；保留编辑器自身的光标显露请求，缩进换行后光标仍须可见
- 预览和导入确认窗按完整屏幕的当前逻辑宽高限界，确认/取消动作可换行，内容过长可滚达；不能把主界面阻断转移到弹窗。工程保存仍使用全局“保存全部”，不与应用混同
- 空白工程的显式能力启用窗口同样属于必要入口。短屏须先从屏幕预算扣除完整窗口边框、标题、内外边距，再用单一主滚动覆盖说明、能力选择、兼容预览、兼容确认、启用与取消；不能仅滚动正文而把 footer 留在屏幕外。宽屏保留既有正文滚动、固定动作和键盘入口
- 源文使用当前主题阅读字号和行距；技术身份、revision、baseline、原始交换信息放在可展开区域
- 状态文字包括缺 ID、重复 ID、缺译、已译、源文已变、无效 token、孤立译文，图标或颜色只作辅助。错误与警告使用当前主题语义色，不能写死颜色
- 保留 Studio 默认，以及既有 5 种布局、10 个配色家族和 17 个成员。新工作台不是替换既有书稿、状态检查、静态发布或来源追踪界面
- 中文、emoji、多行与 200% 缩放应保持可读和可操作；不对字符串按任意字节切片。Unicode 原字节保存、重新打开与运行校验和文字视觉排版分别验证。当前原生/共享 egui 文本界面不完整支持阿拉伯连字塑形及 RTL 双向视觉顺序；可保留、编辑和交换原文，但阿拉伯语、希伯来语的编辑及试玩显示不能宣称视觉正确，必要时须在支持该排版的外部编辑器核对

## 3. 状态与输入保护

- 目录缓存绑定 core 的内容/查询身份；版本变化后查询重算，稳定选中项仅在仍属于当前结果时保留。输入以明确语言和条目身份保存，不借用列表序号
- 来源点击绑定实际展示出处：目录条目身份，或已接受导出、导入、译文、ID 计划及其中的明确条目/完整诊断；同时核对该结果安装时的工作区和已应用工程版本。错误交换包的来源不能借另一条有效目录行证明，过期计划不能跳转。core 返回的真实 SOURCE_MISMATCH 等诊断仍可定位其诊断来源；稳定 ID 诊断还须匹配当前已接受目录中的来源、原 ID 与修订，不能把陈旧 assignment 的来源回显当成当前位置证明。校验失败明确提示并保留所有作者稿，不静默失效或猜测文件
- 目录的源/目标语言、已有语言选择、过滤、翻页、刷新和试玩回源属于查询与导航；自动补全源语言或只读浏览不得凭空产生“本地化草稿”，也不能改变工程或被标成应用完成
- 高级交换的语言配置与目录查询分别保留。仅作者实际编辑高级配置才产生配置草稿；高级 ID 白名单与 JSON 输入独立保留。切到目录、换查询语言或试玩回源不能覆盖这些输入，也不能把它们标成已提交
- 可编辑字段使用绑定工作区、条目/语言及字段角色的稳定身份；出现保留输入、操作提示或异步查询状态不能改变正在输入的字段身份。逐键跨帧输入须保持焦点，不能仅用整串粘贴证明编辑可用；重排 typed part 时仍主动释放旧位置的焦点，避免把输入转交另一段
- 同一目标语言、工作区及已接受工程版本的后台目录刷新不禁用仍显示的稳定译文输入，继续输入仍绑定该页原 revision；切换语言、工作区或版本时旧页继续锁定并保留稿。保焦仅针对后台刷新，不强抢作者已主动移交给其他控件的焦点
- 目录编辑门控始终核对已接受结果的工作区、工程版本与目标语言，不以“后台任务已停止”代表结果已更新。新语言/版本查询取消或失败后旧页保持明确只读且标明原语言，不能从旧译文起草当前新语言；同身份查询取消或失败仍可续写。源语言是作者明确指定的起稿标签，不另造查询规则，已有 sidecar 的语言一致性仍由 core 校验
- JSON 协议上限仍为 8 MiB，完整原文独立保留并作为 core 预览的唯一数据源。超过 16 KiB 的输入默认仅显示有明确字节范围的有限摘要；作者可按 UTF-8 边界分段编辑，每个编辑控件最多排版 16 KiB，摘要绝不回写为数据。分段修改只替换对应原文字节，其他部分逐字保留
- 高级导出和导入结果每页显示 40 项与真实总数，保留前后页、逐项来源和明确详情入口；默认仅排版有限摘要。只为当前明确选择的详情呈现 typed parts，长源文/译文按 UTF-8 安全边界分段查看，每个显示区最多 16 KiB。分页、摘要及分段均是显示预算，完整计划、交换包和原 JSON 不裁剪、不重写，core 预览、应用和导出仍使用完整数据
- 合法但超过当前编辑段预算的大粘贴完整暂存，明确确认“替换全部 JSON”后才替换原文；取消保留原 JSON、当前段和选择，不因控件先删选区而丢字。待确认粘贴受草稿守卫保护。超过 8 MiB 的粘贴或文件准确拒绝并保留原输入，不通过降低协议预算或静默截断绕开大输入
- 原生文件载入在 metadata 早拒之外仍最多读取上限加 1 字节；检查后增长的文件也不能先无界分配再拒绝。超限判断在暂存大粘贴的完整副本之前执行
- 过滤、翻页、返回来源、从试玩回来不能自动应用输入。离开工程、关闭工作台或重置须沿现有未提交草稿保护
- 译文或 ID 的应用只消费对应的已应用输入，不能解除其他未提交译文、ID 或高级交换输入的保护；高级导入成功仅标记本次交换配置与 JSON 已提交。查询变化只废弃旧预览，不把已提交交换内容重新算作新草稿
- 编辑语言、选择范围、译文、ID 或当前工程变化时废弃旧预览；重复点击应用不得重复创建事务
- 预览确认显示源文基线和计划身份；应用时由 core 再校验。磁盘外改、只读、sidecar 版本错误、token 错误均保留输入并显示可定位诊断
- 目录、ID/译文/JSON/导出预览在后台执行，UI 保留先前稳定页及真实页码。更改请求、取消或切换工程后迟到结果不会替换当前页或计划。原生内部编译暂不可抢占，取消后舍弃结果并等待单一任务释放；浏览器 Worker 可终止，不叠加任务
- 目录查询错误与导入、导出、ID、译文等操作提示按请求类型分别归属，不按错误字符串识别。查询失败保留稳定页并显示“上次目录核对失败”；修改查询、后台等待或取消期间保留这条最近查询错误，只有当前请求的有效成功页被接受后才清除。查询失败与成功均不覆盖或清除不相干的操作错误；修正非法来源前缀后，成功页和后续筛选不得继续残留已解决的查询红字
- 原生文件对话框取消不改变输入。高级交换同时提供明确路径的读写路线，避免将“按钮存在”当作文件流程通过。已有导出目标须拒绝且保留输入，作者另选新路径
- 目录状态是真实派生状态；不能通过勾选“已完成”抹掉 revision 过期
- 工程撤销或重做成功后清除本地化工作台的旧操作提示，避免把历史操作误读为当前稿状态；恢复失败不清提示，任何恢复路线均不借此清除未提交输入
- 逐项译文和高级 JSON 导入成功后，正文草稿沿同一本地事务边界传递：原基线须属于真实事务前工程，core 须证明前后源文件均与草稿原文一致；只同步基线，保留完整输入和代次。返回书稿即可继续明确应用，无需先保存、撤销或丢弃。稳定 ID 修改若改动同一源文件，则保留该旧草稿及过期拒绝；其他未改源文件仍按上述证明传递。能力启用仍须先处理未应用正文，不因译文传递放宽入口
- content.localization.v1 从未启用到明确启用成功时清除此前本地化操作提示，避免仍显示已解决的能力前置错误；仅打开、取消或启用失败不清提示。所有 ID、译文、高级配置与 JSON 输入保持，仍须重新预览后明确应用
- 显式启用能力或修改源码会更新目录 source baseline：旧 ID 输入仍保留供核对，作者须定位当前单元后重新明确输入 ID 再预览，不把旧位置输入自动重挂到新身份。typed 译文仍使用既有“对照当前源文，重新绑定此稿”机制；ID 输入没有自动重绑按钮

## 4. Core 接口需求

具体 Rust 名称以 worldline 规范为准，UI 不建立第二份规则。

- 目录查询：当前 Project 快照、source/target locale、文字/状态/来源/kind 过滤、offset/limit；返回稳定 entry key、准确总数/匹配数、分页范围及预算诊断
- 当前条目：稳定 ID 或缺 ID 状态、真实来源文件/行/kind、source revision、源文 typed parts、现有 translation typed parts、派生状态与单元诊断
- 身份计划：将明确 ID 分配给当前源码位置，绑定源码快照；返回改动预览、能力前置条件与一次内存事务 apply
- 译文计划：接收明确 ID、source revision 和 typed translation parts；校验完整 token 多重集、链接身份、空译文、预算及 sidecar 合并；preview 返回 can_apply、digest、受影响文件/ID/诊断
- 内存应用：同一候选 API 服务桌面/WASM，保留未选 ID 与未知字段、一次 undo/redo，不改变原生旧 import 的立即持久化契约
- 交换输入预算：JSON 字节、单元数、单元长度与诊断输出有明确上限。UI 显示 core 错误，不自行容错解析

## 5. Runtime 与 worker 接口需求

- 普通试玩按全局界面扣除后的真实可用宽高选择布局：宽高充足保留正文与调试/选择双栏；窄或短视口改为全宽、单一纵向主滚动，模式和语言、暂停/继续/停止、源译正文及选项均可滚达，不能保留固定宽侧栏挤掉正文。路径、范围/预算与状态检查可用明确折叠组收纳，原有动作与身份守卫保持；布局切换、展开和滚动不执行故事。草稿试演和路线对照的既有能力及状态不由此删除
- 准备 locale：明确 source-only 或目标 locale、严格/允许源文回退策略、当前 Project/compile 快照；预检译文状态且冻结 locale 内容身份
- 执行：先按源顺序求值一次，再按译文 token 顺序组装已物化值；随机流、稳定 choice ID、状态、访问与退出不受翻译影响
- 输出及选项：译文显示、同次源文显示、各自 UTF-8 链接范围、locale/翻译或回退状态、稳定 string ID 和真实 source 位置
- 对照只切换显示，不额外推进；主阅读区域按实际 new_line/glue 合并本次输出，逐项来源与修正放在独立详情中，不用卡片边界改变真实段落连接。未覆盖的名字、禁用理由及动作日志仍标为源文，不宣称全部内容多语言化
- 运行快照身份包含 locale 及译文内容；新译文或源文变化后的旧结果保持旧身份并提示重新开始。重放/检查点不得混用不同 locale 快照
- worker 请求带完整 locale 配置，响应绑定 session/request/内容身份；关闭、取消、切工程或重新开始后旧响应不能覆盖新会话。准备失败必须零推进并保留所有作者稿
- 真实新 Story 会话成功建立后清除此前启动失败的诊断提示；仅修改语言、浏览或再次启动失败时不清除当前错误，运行 trace 与来源身份不受提示清理影响
- 返回源文或译文均要验证该输出属于当前运行快照；切换到本地化时精确选中同一稳定 ID，返回后保留当前会话和阅读位置

## 6. 验收计划

所有结果绑定实际候选版本、二进制 SHA-256、样例来源和时间；现有 0.32 仅可作为新鲜基线观察，不能算作 0.33 通过。Linux 桌面由同一验收者操作，保留失败截图与复现步骤。headless、WASM 编译、真实浏览器和原生桌面分别报告。

### A1 空白工程

- 从空白工程显式启用能力、输入英文/中文/emoji/多行正文/台词/选项，分配 ID；缺 ID 与重复 ID 可发现且准确计数
- 按缺译、过期、来源、关键词筛选并分页，选中后改译文再换页返回，输入保留；测试首尾页及空结果
- 非法来源前缀须真实失败并保留稳定页；清空前缀后接受成功首页，再搜索末项，查询错误消失且页数准确。另测已有导入错误时查询失败、修正成功与取消：操作错误及所有作者输入仍保留，等待或取消不伪称查询已恢复
- 包含占位符和链接的直接译文编辑/重排，合法计划通过；缺/重复 token、未知 ID、重复 JSON 键、非法 JSON、超预算和未知 sidecar 版本阻止应用
