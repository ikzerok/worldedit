# 安全整理源码路径

在工程文件树的非入口 `.wl` 上打开菜单，选择“安全移动 / 重命名路径…”，或打开文件后使用“编辑 → 安全整理当前源码路径…”。填入工作区相对新路径并保留 `.wl`，先预览再应用完整计划。

预览由 worldline core 给出逐文件、逐处路径变化、活动/归档身份、资源解析、默认事件入口、语义加载顺序与运行指纹。它不是普通全文替换。普通文字、注释和未知可选字段不会被猜测改写；不能证明完整等价时拒绝。入口、目录批量和素材移动不在当前范围。

未应用书稿、表单或替换输入应先处理，原输入不会被自动应用或丢弃。改变目标路径会清除旧预览；工程变化后需要重新预览；外部改动、目标碰撞、权限/能力只读和资源改变在应用时再检查。取消只关闭路径提案，不改变作品。

应用后立即打开新路径，全部正式引用作为一次可撤销操作更新内存；保存全部才写磁盘。保存复用既有可恢复事务，不承诺物理跨文件原子。源码移动不迁移旧运行存档；只有 core 能证明运行指纹与默认入口不变的操作才被允许。

新建活动源码在 explicit source_sets 工程中同步加入 active，避免“创建成功后 include 无效”；引用归档/非活动源码会拒绝，不自动启用。浏览器作品仍是导入快照，工作区内路径整理不代表实时操作原磁盘。
