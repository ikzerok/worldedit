# 0.17 人物焦点与时间问题工作区合同

## 语义与来源

人物焦点只消费当前 core 编译快照的 typed focus-context 投影。正式关系、旧式人物关系、属性强引用、事件参与、正文显式链接、可选文字提及分别显示；文字提及默认关闭，不属于正式事实。只读上下文边不提供统一写回或自动升格。人物档案的旧式关系编辑和明确建边入口保持不变。

列表与图共用同一投影、分类筛选及完整 TargetRef 身份。正式关系的作者限定范围保留在记录中，显示可读名称并能定位范围对象来源；不把限定事实显示成无条件全局事实。显示 core 返回的总数、返回数、完整性及预算原因；无效稿、未知对象与截断不能显示成“没有关系”。来源精度按 core 返回值显示；行级来源只导航到真实行，不能编造字符范围。旧结果必须在工程 revision 变化后重新查询，错误态不得继续展示旧事实。缓存失效时通过 core 只读冲突快照核对，存在外改冲突时保留当前缓冲记录但标注 SourceConflict / 不完整，绝不宣称磁盘最新；核对读取失败单独说明无法核对，保留原错误详情，不捏造成无冲突。

时间问题只消费 core 的偏序比较与环见证。真正环成员、被环阻断的下游分开列出，闭环每一条 follows 边均能回到来源。比较明确显示先于、后于、同事件、同根无约束、独立根或未知/无效，绝不以 rank 或屏幕布局推导时间。修稿后重新查询，旧证据不得继续当成当前结果。

## 人物作者流程

1. 人物索引按名称/稳定 ID 查找，结果数量说明索引范围。选择保留完整身份，不按同名替换；未应用人物输入沿用现有防丢保护。
2. 主区保留当前人物标题，默认局部一跳图与分类结果。初次选择/切换人物自动适配，使所选和当前结果在有效画布内；提供定位所选、适配结果、缩放、平移、恢复局部布局。窄画布按实际宽高比展开默认布局，适配计算包含当前200×76最小卡片，当前名称至少14px。默认auto-fit视角随有效画布resize更新；手动平移、缩放或拖点后保留个人视角与节点坐标，明确“适配当前结果”可重新启用自动适配。边标签按实际文字尺寸就近避开卡片，不通过隐藏标签解决重叠。全人物旧关系图可明确切换，以250节点分页说明边界，当前选择保留；平行边分道并各自保留来源。
3. 可编辑档案按需显示；无选择不占空列。空间不足时辅助索引/档案改为抽屉或主区标签，主画布不以固定大宽度溢出。收起辅助区不删除输入。
4. 点击关系端点进入真实对象；点击来源复用既有作者导航历史，可用返回动作或 Alt+Left 恢复原作者位置。图/列表筛选与相机属于个人临时状态，不写工程。
5. 旧式关系按钮与端口拖拽创建明确标为旧式关系，不将属性引用、参与、正文链接或提及写成旧式人物关系。

## 时间问题作者流程

时间线与诊断区均可进入时间问题。问题区先列环及影响，下层显示稳定闭环见证和技术 code；可选择两个事件询问偏序原因。每个来源可导航，关闭或 Escape 返回原焦点。进入问题不应用、不清空、不绕过当前表单保护。

## 键盘与窄窗

新工具打开将焦点送到搜索/比较入口。时间比较使用既有名称优先的对象选择器，展开后聚焦持久搜索输入，Escape返回原选择器；搜索唯一候选可由Enter明确确认。直接ID输入为可选补充，左右输入使用稳定ID，逐字符经过未知前缀也不丢焦点。证据体按实际头部高度后的剩余空间滚动，展开可选输入与闭环仍保留固定关闭动作。证据区来源按钮及展开头随Tab焦点自动滚入可见区域；被小视口上限压缩的时间窗口在视口恢复时恢复可用高度，主动缩小的窗口尺寸保留。F6 / Shift+F6 在人物索引、图/结果、档案间切换；Escape 只关闭本轮新增最上层临时面板并返回其原焦点，不吞输入法组合事件。区域快捷键不穿透设置、搜索、改名或保护确认等上层工具。按钮、列表行、来源与筛选可经键盘进入。当前对象、键盘焦点、悬停、环成员和下游用文字/描边/图例共同区别。

## 安全移动回执

沿用 core 预览和应用计划，不弱化过期检测、工作区边界或等价证明。保存沿用既有可恢复 journal 事务，不承诺跨文件物理原子性。失败回执优先显示可执行建议，区分语义改变、源码已变化、路径非法、无法证明；原始 core 错误在技术详情保留。预览与应用后状态明确说明“未应用”/“已应用、未保存”。

## 验收合同

自动测试覆盖：typed 分类一致/提及默认关闭、选择与一跳可见、100/1000人物范围、长中文名和来源、三宽度布局策略、导航前后保护、进入/返回焦点、环与下游分组和比较状态、证据失效、移动失败分类。全部 Rust 源文件不超过600行。

Native 验收分别记录1400×900、1188×848、1040×660，亮/暗主题；至少24字中文人名、80字关系角色、深路径、多行属性与空/错误/截断态。正文正常文字目标4.5:1、关键非文字焦点3:1，小字力争7:1。自动egui测试、Linux实际键盘/鼠标、物理IME、读屏、高DPI、Windows/macOS、真实Web分别记录已测/未测/受阻，不能互相替代。编译、测试与native验收使用协调者发放的单一执行票，不并行争用。
