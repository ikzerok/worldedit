# 对象状态旁查

人物/地点等资料页、“打开资料”旁的地图标记入口，以及绑定世界对象的矢量图元，都提供“查看真实运行状态”。先明确选择现有普通试玩或现有草稿隔离试演；没有运行时显示空态，不会自动启动、重播或重开故事。

每次结果固定完整对象身份、运行 ID、观测代次和实际稿源。只展示这个对象在该运行冻结目录里拥有的 state，不按名称猜测变量或属性归属。对象没有所属状态与筛选后无匹配项分别说明。

- “静态初始声明”来自该运行自己的源码目录
- “首次记录”是第一次实际观察，可能已经执行过动作，不等于初始化
- “上次记录”和“当前真实值”来自真实运行检查点。缺失、省略、截断与不可比较都保留各自说明
- 运行推进、重开或来源变旧后，旧页可以只读查看；不会自动替换成同名对象的新结果。重新选择已有运行才读取新的观测

对象身份、运行状态、过期/部分提示在内容滚动时仍显示。分页继续绑定同一观测。这里的查看、搜索与回源不会推进故事、改变随机数或写回对象属性。

“定位真实状态声明”定位声明头，不是最后写入位置。已有条件证据来自同次真实求值；状态终值本身不证明写入原因。来源可验证时可跳转，Alt+Left 返回同一对象、运行、选择和滚动位置；旧稿或身份变化时会阻止猜测性跳转。未记录的证据不会补造。

## 操作顺序与返回

1. 从对象资料的“查看真实运行状态…”进入；地图标记和已绑定对象图元的按钮为“查看对象运行状态…”。条件中的 state 可用“旁查所属对象运行状态…”进入同一窗口
2. 点“选择已有运行”，明确选择“普通试玩”或“草稿隔离试演”。只有已存在的真实运行可选，未启动的模式不可选
3. 看固定在窗口上方的对象 kind:id、运行与观测代次、稿号和状态，再在内容区筛选、比较首次/上次记录或翻页。折叠的“完整对象与来源身份”提供全部冻结戳
4. “这次运行的静态初始声明”只展示声明初值；“定位真实状态声明”定位声明头，不表示最后写入点。已有条件证据独立展开
5. “返回对象入口”回到原资料/地图/条件作者位置。来源跳转后 Alt+Left 回到原对象结果，不重新运行故事；Escape 仅关闭最上层旁查，不关闭下面的作者表单

普通试玩使用该运行开始时的已应用工程稿；草稿隔离试演使用已确认的隔离草稿输入。当前作者的新名称、新状态声明与未应用修改，不会拼入旧运行的目录。旧稿页与过期原因保留；来源身份不能验证时，导航被禁止而非按同名或大概行号重定位。

搜索只筛选所属 state，不搜索对象任意字段；未声明的归属不猜测。这里没有“改运行状态”或“把状态写回属性”的按钮。所有“部分历史”提示描述整次运行的观察保留预算，并不承诺它只属于选中的对象。输入法组合期间文字框继续接收输入；打开新窗口、切运行、来源跳转或关闭须等组合完成。

## 协议与范围

- [核心运行状态检查协议](https://github.com/ikzerok/worldline/blob/main/spec/state-inspection.md)：owner 过滤、冻结目录、初值与真实观察、预算和 stamp 保护
- [条件创作](condition-authoring.md)：作者条件的预览、取消、应用事件与保存顺序

页面复用当前运行已经记录的条件证据；不会重新求值条件、执行规则或补造未记录的历史。Worker 自动化验证不能替代浏览器实际 GUI、物理输入法或桌面键盘验收。
