# 生成并核对试玩路径报告（0.28）

“试玩”页的“试玩路径报告…”打开独立作者审阅窗口。它既可捕获生成时的当前路径，也可
显式选择当前会话中已录制或导入的真实路径。选择只用于本次报告，不改变调试器选择，
不会替作者补选分支、修复trace、推进live Story或消耗live随机数。

## 作者流程

1. 选择“当前试玩路径”或一条“已录制”路径，核对当前已应用工程稿版本与预算
2. 如果有未应用创作草稿，先展开清单，明确确认这些输入仍保留且不进入报告
3. 点击“生成并预览已验证报告”；仅显式点击才启动验证，重复绘制窗口不重复运行
4. 核对完整/部分状态、入口或检查点、seed、已验证选择次数，以及完整Markdown预览
5. 阅读私密范围提示，勾选确认后复制Markdown，或保存/下载新Markdown文件

报告中的正文、选择、说话者及源码相对文件名可能包含私人作者内容。默认不加入变量名/值、
任意状态JSON、局部值、作者备注、对象资料、标签元数据、附件或外链。实际全局赋值与状态
动作仅提供次数，不把“前后值相同”当作没有动作。分享报告仍应自行核对具体接收者。

“完整结束并验证通过”要求真实重放通过且记录声明完成并实际结束。其他情况会显示“已验证
部分区段”“分歧”“预算耗尽”“取消”“缺少观察”或“故事运行失败”。正文只包括在当前
源码快照重新执行并与trace匹配的观察；未验证后的内容不补写。检查点之前的覆盖明示继承，
不能当作本次从入口验证；未探索分支也不宣称不可达。

## 陈旧与取消

生成、复制、保存时核对完整已应用版本/内容基线；复制与保存还只读检查外部源码和已登记
文档观察。注释移行、展示文档改动、当前版本变化或未载入的磁盘变化都会要求重新验证，
不会只凭运行fingerprint相同就沿用旧报告。未应用输入仍保留，不自动应用、保存或清空。

生成中可以“取消验证”。关闭窗口取消未完成作业，换工作区清除本次会话中的报告和作业。
生成期间已应用稿变化会取消旧作业，不把迟到结果冒充新稿报告。已经展示的旧报告可留供
核对，但禁止导出，须重新生成。

桌面使用后台线程；Web 每帧至多512解释器步或4ms，总时限限制为2000ms。单语句与检查点
恢复不可抢占。浏览器仍只观察导入快照，不宣称持续监视宿主磁盘。

## 保存位置与权限

桌面先填写工作区外的新 `.md` 文件绝对完整路径，也可使用可选系统选择器。选择器取消
不会写文件；只有“保存新 Markdown 文件”才写入。已有文件、工作区内目标、非 `.md`
目标一律拒绝，不覆盖。写入失败保留当前工程、源稿、live Story及保存基线。

Web使用既有下载流程请求下载 `worldedit-playthrough-report.md`，不推进浏览器本地保存基线。
报告窗口不生成HTML/ZIP，不写入作者工作区，也不扩大读者发布的字段或资料白名单。

原始trace和普通存档可能包含变量及运行状态；分享它们需要独立核对内容与接收者。可读报告默认省略字段不表示原始记录已脱敏。
