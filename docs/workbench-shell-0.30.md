# 0.30 工作台界面契约

本文规定0.30生产工作台的结构与交互验收，适用于同一Rust/egui实现的桌面和Web。实现不得通过修改Web外壳CSS代替canvas内部控件；导出的读者站是另一个发布表面，不自动继承作者的设备外观设置。

## 内容与工具的层级

- 标题区以当前作品和所在工作区为主，应用名称为次。高频保存、查找和试玩均可直接找到；完整工程、导出、编辑、视图操作保留在稳定菜单中
- 左导航负责工作领域和工程文件；章节、人物等领域内的详细索引保留在其工作区，不塞入三层以上的全局导航
- 正文、画布和资料内容是主要工作面。辅助检查器说明当前检查对象；没有选择时给出明确下一步，不伪装已加载对象
- 页面标题、局部工具、内容和来源元信息分层。来源可截断显示但必须可获取完整路径，不遮挡主要按钮
- 工程状态始终区分未应用输入、已应用未保存、已保存、只读、外部冲突和过期结果；不能只用色块表达

## 五种结构风格

配色、结构风格和密度独立。切换风格不改动Project、不变更对象身份、语言版本或指纹，也不自行调整作者明确钉住的参考或读取位置。

1. 编辑台：连续平面分栏，面板内以标题、留白与轻分隔分组，正文不嵌套圆角卡片
2. 稿纸：书稿和阅读内容使用居中、受限宽的连续纸面；局部工具与来源在纸面外，纸面无虚构分页语义。非书写工作区采用同一套章式标题与平面分组
3. 工具台：边到边工作区、明确栏头带、直线边界和连续行。适合源码、资料表与诊断；完整创作功能与其他风格相同

4. 专注：连续居中创作区，不加稿纸边框。全局导航与固定参考采用临时抽屉，常显“导航”按钮与 Ctrl/Cmd+Shift+E 入口，Escape、Alt+Left 或关闭只收起当前最上层抽屉，保留文件、草稿、选中对象、原导航宽度及参考停靠选择。正文工作区保留明确的书稿管理、章节选择和预览切换入口；用户显式打开的编辑表单和问题诊断不能被风格切换丢弃
5. 档案：宽屏以侧题签与对齐资料列组织连续内容；窄屏题签移到正文上方，正文仍至少使用当前可用宽度，不能为装饰题签形成横向溢出。图节点使用短题签带与内容分隔，与整幅表格栏头不同

Studio 编辑台为默认。配色默认雾松，跟随系统，标准密度，用户可独立修改

五者必须在相同内容、相同配色、相同密度的灰度视觉检查中看出结构和形状差异；仅换颜色或行高不算完成。现有旧主题不作为选择项保留。

## 自适应与缩放

- 以当前可用逻辑宽度决定是否收起辅助导航，保留可见的导航菜单和快捷命令入口；暂时收起不覆写设备上保存的面板偏好
- 较窄窗口的主操作换行或进入明确菜单，不画到原生窗口控件后方，不裁掉取消/关闭
- 界面缩放和正文大小分开。200%时允许辅助栏收起、设置滚动；不能缩小正文抵消用户放大
- 章节/资料内容与辅助栏独立滚动；长文件名/来源不会把中心区挤到负宽
- 主窗口允许至少800×600逻辑尺寸的压力测试；更窄有效区域仍须能操作导航、退出和关键决定点

## 交互与输入

- 选中位置、鼠标悬停和键盘焦点分别表达；焦点有可辨轮廓，不能只变色
- 自绘导航/画布控件保留真实egui交互语义、明确标签、稳定ID和键盘可达入口
- 窗口拖动、缩放、最大化/还原、最小化与带草稿保护的关闭继续可用。Web全屏/结束编辑沿用既有浏览器职责
- 临时窗口关闭、取消、Escape及返回按既有层级保护作者输入；输入法组合优先，不把Enter选词当成提交或导航
- 不因后台检查或换配色抢走输入焦点。显示字体或缩放变化后重新排版，仍按真实对象/文本锚恢复位置

## 全功能可达性

书稿、正文概览、源文件、世界观、人物、资料与状态、资料导入、Wiki、地图、世界关联、时间线、事件图、审阅、模板、本地化、检查点历史及试玩均保留稳定入口。完整工程导出、读者发布、Markdown导入、草稿保护、外部冲突与恢复途径不得被简化外观隐藏。

新章起笔由core结构事务和正式WritingBuffer提供；界面不解析或拼接语言。对象筛选及分页由core统一提供；显示名和别名帮助识别，提交仍使用完整kind+ID。

## 验收要求

- 十组十七种有效配色成员×五种结构×三种密度覆盖主要状态；另检查固定模式的请求值保留、跟随系统及切回双模式后的恢复。正文/次文/选中/错误/焦点/控件边界/画布节点都核验实际使用背景
- 真实空白作品、长中文与英文正文、超长路径、空结果、来源失效、只读/冲突、两个参考面板、地图/关系图/时间线均展示
- 1280级桌面与800×600窄窗、80/100/125/200%缩放、键盘打开/关闭/取消/返回、重复操作、保存重启和旧个人状态迁移
- 无变化操作不改变工程dirty、导出字节或运行指纹；语义创建操作必须展示其真实影响
- 自动化绘制/布局测试、真实Linux窗口、WASM编译/执行、其他平台/物理输入法/读屏各自记录。未测不能写成已通过；token计算不等于整产品无障碍认证

## 专注工具的非破坏性显示

专注风格只改变有效显示策略，不覆写个人原有navigation/focus/dock_references/width值。临时抽屉使用统一取消层级和焦点返回；上层表单或IME优先。导航抽屉包含原全部工作区入口与工程文件、新建/引用/安全移动入口。切换工作区或文件后可直接返回正文，重复开关不重建Project或提交草稿。外观预览取消会恢复原结构，而作者主动执行的正常导航仍保留
