# 路线对照：从结果回到真正发生的动作

## 完成一次比较

1. 在「普通试玩」中走出第一条路线，在叙事调试器给路径命名并保存当前路径
2. 重新开始，走出第二条路线并保存；也可使用现有 JSON 路径导入
3. 切到「路线对照」，选择 A、B，明确点击「比较当前已应用稿」
4. 有未应用输入时先核对运行范围；比较不会替你应用或保存它们
5. 先看两侧是否完整结束、是否来自可比起点，再看首个不同选择和实际停止状态差异
6. 选择 state，展开真正执行过的动作，查看前后标签、所属世界对象和作者来源；「打开动作来源」定位原稿后，用 Alt+Left 返回对照

路线只保存在当前工作台会话；本轮未增加重启恢复或永久路径库。原有普通试玩、录制、单路径重放和条件证据仍保留。

## 屏幕上的几种不同事实

- A/B选择器表示准备比较的路径；结果标题表示上次实际比较的路径。选择器变化不会偷偷重跑或把旧结果改名
- 「完整结束并验证通过」与「已记录区段通过」「分歧」「失败」「取消」「预算耗尽」分别显示。后几种的值是实际停止状态，不冒称结局
- 相同结果值不表示路线等价。相同访问节点也可能经历不同选择并得到不同状态
- 不同种子/起点、未验证初始观察或不同检查点会说明不可对齐。首个不同选择不是后续全部结果的唯一因果证明
- 检查点继承的覆盖与本段新增执行分开。未访问仅代表未测试，不等于不可达
- state 动作按真正发生顺序记录，同值写入不会被当作没有发生；超出证据边界会显示省略
- state 与世界对象的关系来自现有语言定义；变量仅比较值，无可确认的动作证据就不提供猜测来源

## 来源、草稿和返回

比较结果使用冻结的已应用稿。源文件、编译选项或作者草稿变化后，旧结果仍可看，但不可靠的回源会被阻止。即使只加注释、runtime fingerprint没变，也要显式重新比较才能定位新行。

新鲜结果优先显示状态和世界对象名称，稳定ID作为辅助；过期结果不借用新名称冒充旧资料。作者来源显示工作区相对路径与行，完整路径留在提示中。

回源只定位，不执行选择、不改变live Story/RNG，不应用/保存草稿，也不替换固定参考。返回恢复同一A/B、结果、选中项、阅读位置和焦点。遇到冲突、输入法组合或未应用执行草稿时，先处理明确提示，不会绕过保护去找同名字样。

## 预算与支持范围

主区显示路径身份、有效性、首差异；fingerprint/schema等技术详情可折叠，过期或不同起点等风险不会因此隐藏。沿用现有明暗主题、阅读和工作区设置。

对照默认硬上限每trace4096 steps，与既有普通路径导入上限不同；不会暗中裁掉输入。总执行预算两侧共享；浏览器额外使用既有的较低时间边界及合作式按帧推进。取消是真实停止，不伪装验证成功。

0.19 trace/checkpoint不能直接交给0.20比较，应重新录制；普通Story Save继续原有独立兼容规则。不要手改版本字段。新功能没有增加独立CLI遥控编辑器窗口的能力：CLI/RPC使用各自工程与会话。

正式语义见配对[core规范](https://github.com/ikzerok/worldline/blob/011e6bca42779cb93ad6cf3424a5a4d8b6bada04/spec/route-comparison.md)，开发与验收合同见[编辑器设计](route-comparison-0.20.md)。真实平台操作、offscreen测试与构建检查分开记录，不能用其中一种代替其他平台GUI、IME、读屏或高DPI验证。
