# 0.16 内容优先工作台契约

本轮仅调整地图布局、通用实体长表单和对象候选的呈现；所有内容命令仍由 core 校验，不改变语言、正式身份、检索范围或工作区边界。

## 地图

- 紧凑布局依据主导航之后的真实可用宽度，并扣除地图目录、检查器的实际宽度及面板边距，保证画布优先；不得单用总窗口宽度决定。
- 浏览地图且没有选择、未完成表单或定位请求时，不默认占用空检查器。目录与检查器有独立、始终可达的展开/收起入口；紧凑时可在检查器访问目录、查找与全部既有命令。
- 未提交表单、矢量检查器草稿和定位请求保持检查器可达；折叠、切换宽度及展开不应用、保存或清空输入，不改变镜头。
- 普通浏览将渲染状态与导出命令渐进展开；错误、待处理任务及未提交预览仍及时可见。

## 通用实体长表单

- 仅正文、模板、自定义属性和技术字段滚动。固定操作区保留应用、取消、未应用/过期/能力只读状态；内容长度和滚动位置不影响可达性。
- 应用必须继续检查打开基线、语言能力和有效名称；快捷键与按钮采用同一资格条件。过期或能力不足时保留输入，可取消或查看所需能力。
- 删除入口、稳定 ID 只读规则、草稿导航护栏、一次应用一次撤销以及保存语义保持不变。

## 快速切换与共用对象选择器

- 候选以名称及类型/稳定 ID 为主行、工作区相对来源和行号为次级 caption；路径保留目录，不仅显示 basename。
- 全路径仍参与检索，并通过 hover/复制可查；候选不按显示名合并，点击与键盘导航仍使用完整 TargetRef。
- 未提供工作区上下文的可复用控件必须明确回退完整来源，不猜测公共路径。普通查找/替换保持既有相对来源规则。

## 验收

自动回归覆盖 1040×660、1188×848 与宽窗，主导航和地图面板开/关、长中文标题与放大界面字号；检查真实画布宽度、草稿保留及完整命令入口。长表单在顶部和滚动后均能看到操作及过期状态。候选覆盖深层 Unicode 路径、同名跨类型、同 basename、全路径/别名检索和键盘选中。

自动 egui 事件/绘制测试不能替代原生窗口、真浏览器、高 DPI、物理输入法或读屏验收；实际执行与未执行项分别记录。
