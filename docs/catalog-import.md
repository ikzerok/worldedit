# 世界资料批量导入与修订

在「工程 → 世界资料导入…」、左侧「世界资料 → 世界资料导入」或任务命令中打开工作台。它把表格中的人物、地点、组织和其他实体资料接入当前作品，先完整预览，再一次应用。

## 一次完整操作

1. 选择一个 UTF-8、逗号分隔的 CSV。这里只读取选择时的快照；改动原 CSV 后需要重新选择。取消文件选择保留当前输入。已有快照时，选另一份文件会要求明确确认替换。
2. 为每一列选择 kind、id、display、entity_type、description、某种明确类型的属性，或「明确忽略此列」。不猜表头或属性类型。属性要填写稳定的属性键。
3. 选择新对象写入的既有活动源码文件。更新对象留在原声明文件，不移动。未选位置、未映射列、重复映射、重复身份等都会阻断整批。
4. 选择「刷新预览」。后台检查期间可以取消；原生不可抢占的检查阶段可能先运行到结束，过期或取消结果不会采用，也不会并行启动另一批检查。
5. 在「逐行审阅」查看新增、更新、无变化、阻断行。选择行能看完整身份、CSV 物理行、原声明来源与每个变化字段的真实原值、新值。展开「批次详情」可查全部忽略列、修改文件、换行规范化数和运行指纹。
6. 检查整批错误与存档影响，勾选「已审阅整批字段差异与存档影响」，再点「确认整批应用」。应用会在当前工程同步复核，可能短暂停顿；任何失败都不应用部分行。
7. 成功后可「看资料」「回到来源」，通过返回作者位置回工作台。整批是一条撤销记录，可一次撤销/重做。选择「保存全部」才写入工作区；浏览器依其既有下载与本地快照流程保存。
8. 用相同快照和映射再次刷新，应显示「无变化」，不新增历史、不置脏、不重排原文。

## 数据含义与边界

- 身份只由 kind + 稳定 id 匹配。kind 只支持 character、entity；同名不合并，同 ID 的人物与实体仍是两个身份
- 新对象必须有明确 display；新 entity 还需要 entity_type。entity_type 与 description 只适用于实体
- 文本值保留原字符串。number 使用有限 JSON 十进制数值；bool 只接受 true、false。引用列明确选择 entity、character 或 relation，单元格只填目标 ID；同批前向引用由最终候选统一校验
- 空单元格默认报错。列级「保留现值 / 跳过」表示不改旧值，也不给新对象添加该可选字段。「设置为空文本」只适用于允许空文本的文本字段。空格不等于空值，0、false、null 字样均不自动当作空值
- 所有 CSV 列必须明确映射或忽略。未映射的工程属性、人物关系、注释、其他声明不变；不做删除、ID 改名、声明移动、schema 定义/绑定写入或附件、别名、标签批量修改
- CSV 允许 BOM、LF/CRLF、带引号字段、双写引号、引号内逗号与换行。引号内 CRLF 规范化为 LF，并在预览说明。拒绝重复/空表头、不规则列数、无效引号和非 UTF-8；不猜编码或分隔符，不执行公式
- 输入上限为 2 MiB、500 数据行、64 列、单格 64 KiB；完整字段预览上限 4 MiB。错误详情最多显示 100 项，摘要仍给出全量错误数，未显示错误一样阻断整批

## 草稿、旧预览与能力

切换页面、Esc 返回、看资料和回源都保留导入快照与映射。关闭或切换工程时，未应用导入输入参加既有草稿保护，只有明确丢弃才清除；输入不会通过保存工程自动保存成下一次的导入任务。

存在其他未应用作者输入时，预览与应用暂停，并提供返回草稿入口。源码、映射、目标或工程基线变化使旧确认失效；刷新预览不会自动应用。磁盘冲突、只读工程、未知能力或失效基线都保持零变化。

缺少实体或引用能力时，从错误旁进入既有「显式启用语言与资料能力」。导入快照保持，启用后须重新预览；不会自行修改语言版本或能力清单。默认语言 1.9、最高 1.13 不变。

运行指纹提示来自 core 对本批前后候选的真实计算。人物显示名与某些非引用属性会参与指纹，可能使已有 Story save/checkpoint 不兼容；不要把实体静态资料的结论推广到人物。导入不改动原有存档和严格重放守卫，也不自动迁移旧存档。

## 键盘与验证范围

Tab / Shift+Tab 在控件间移动，Enter 激活按钮，Space 勾选确认，Esc 返回资料库并保留输入。输入法组合期间或包含输入法事件的一帧不会确认应用。

自动化覆盖：读取快照与显式映射、文件取消对应的无事件状态、替换取消、草稿保护、过期结果、整批错误零变更、幂等、单次撤销/重做、保存重开、资料与回源返回、退出保护、窄/宽视口、长中文来源、亮/暗主题及合成键盘/IME事件。它不是实际操作系统文件对话框、Windows/macOS、物理输入法、读屏、高 DPI 或真实浏览器验收的证明。
