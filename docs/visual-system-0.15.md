# 0.15 作者工作台视觉系统契约

状态：0.15候选契约，需以当前代码完成验收。既有能力与安全边界以 [工作区操作](workspace.md) 为基础；读者发布的交互与长任务约束见 [0.15 发布流程](reader-publishing-0.15.md)。

## 一、范围与稳定角色

本轮覆盖主导航、书稿、源码、人物、资料目录、Wiki、网络、地图、参考及诊断面板的共同视觉语言。各页面可以采用适合内容的视图，但不能让相同位置和样式在不同页面承担互相冲突的角色。

| 角色 | 默认职责 | 不应混入 |
| --- | --- | --- |
| 主导航 | 切换作者任务与工作区；当前任务清楚 | 资料条目列表、选中对象字段 |
| 集合索引 | 左侧搜索、筛选、选择同类条目 | 大段正文、全工程诊断 |
| 内容区 | 中央文稿、源码、关系图或地图画布 | 重复的永久主导航 |
| 选中检查器 | 右侧呈现当前选择的可读资料与编辑入口 | 与当前选择无关的整库列表 |
| 参考区 | 明确标为参考，支持已有双参考能力 | 伪装成当前编辑内容 |
| 诊断与状态 | 原因、位置、严重程度、未应用/未保存状态 | 仅靠颜色传达成功或失败 |

Wiki 与资料目录使用左索引、中央内容；人物使用左侧可搜索集合、中央关系图与右侧人物检查器；网络提供真实“搜索中心对象”入口，空状态必须指向实际存在的控件。地图沿用相同索引/画布/检查器角色，具体工具仍由地图模块提供。

## 二、主题、字号与空间

暗色、亮色、跟随系统继续保留。正文与元信息采用同一语义层级，不能在单页自行降低到不可读字号来塞入操作。

共享 token 的本轮确定值：

- 间距 `SPACE_XS/SM/MD/LG/XL`：4 / 8 / 12 / 16 / 24 逻辑像素
- `CONTROL_HEIGHT`：32
- `INDEX_WIDTH`：232；`INSPECTOR_WIDTH`：288，作为初始宽度而非阻止收缩的最小值
- `BODY_SIZE`：14；`META_SIZE`：12；`HEADING_SIZE`：22
- 作者个人设置的文稿字号/行距继续生效，不被上述界面字号覆盖

共享 surface helper 为 `index_panel()`、`canvas_background()`、`document_background()`；颜色从 theme 语义色取得。界面表面有层次，选中、焦点、hover、只读、错误分别有可辨识状态。只读应给出原因，错误同时显示文字；选中不只依赖字体颜色。图节点选中边框明显，长标签限制在节点范围内，完整值可查。

## 三、操作层级与导航

- “保存全部”与“试玩”保持直接可发现；试玩属于叙事高频主循环，不能藏入含糊菜单
- 发布、完整目录导出、桌面完整 ZIP 与 Web 恢复副本统一有明确“导出与发布”入口；保留各自原有严格边界和平台差异
- 工程菜单保留新建、打开、另存、能力、模板、本地化、检查点、重新载入与冲突检查等能力
- 快速切换保留 Ctrl/Cmd+P 和命令模式 Ctrl/Cmd+Shift+P，视图菜单提供可发现入口
- 菜单、命令面板和快捷键指向同一动作，不产生新的隐式保存/应用路径
- 聚焦输入框时保留其局部撤销、输入法组合、Enter/Escape 与上层临时窗口规则
- 未应用、已应用未保存、只读、冲突和过期预览仍显式呈现，不能为减按钮而移除

## 四、来源与渐进展开

人类可读标题优先，技术 ID 和来源次级显示。项目内文件优先显示可消歧的项目相对路径，完整路径通过 hover 与明确复制入口可达；同名文件不能只剩 basename。无法取得项目 root 的共享对象选择器使用完整 wrapped 来源回退。

`technical_value`、`relative_source`、`source_path`、`source_caption` 提供共同能力。书稿首屏来源使用单行次级 caption，完整路径保留 hover/context-copy，不因新增第二行操作挤走正文。长目录 sidebar 可以在自身有界区域内部横向滚动，不能随路径长度扩大整栏。

正文的结构信息渐进展开，写作/结构/源码模式仍存在。折叠不丢语义、编辑入口、未应用稿或章节编排；人物身份与来源可放技术详情展开区，仍可查询和复制。

## 五、尺寸与可达性

主要验收视口为 1188 × 848、1×，覆盖暗/亮主题与含长中文名称、长 ID、长路径的工程。

- 主流程不横向截断；固定尺寸按可用空间收缩，不让子内容撑大父面板
- 工具栏必要时换行，正文与列表各有清楚滚动范围
- Inspector 超长内容可滚动；列表显示完整候选能力，分页不能成为隐藏上限
- 确认、取消、返回、应用和保存区别清楚，窗口底部动作可达
- 索引、检查器和文稿保留原有个人布局恢复、双参考与专注模式能力
- 浏览器/桌面工作区边界不混淆，Web 仍是导入快照

## 七、实施与证据

Reader 核心解析、公开投影及生成由 worldline-core 提供，UI 不另写语义。每个 Rust 源文件不超过600行，必要时按职责拆分。所有变更由当前代码与测试证明；验收记录注明实际平台、尺寸、主题及未执行项。
