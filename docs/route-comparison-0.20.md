# 路线对照与真实状态动作回源

## 目标与边界

0.20 在现有「演练 · 试玩」内提供路线对照主内容模式。作者选择当前会话中两条真实录制或导入路径，显式使用**同一份当前已应用工程稿**验证 A、B，然后从差异查看当次实际动作并返回原稿。

此文约束编辑器实现与验收；运行含义、投影 DTO 和来源身份以配对 worldline 正式规范为准。编辑器不得另写解释器、按标签猜动作、按同名匹配对象或重新推导路线等价。设计和自动化测试不替代最终原生操作验收。

不新增 DSL、持久路径库、导出格式、协作、通用历史状态调试器或全局可达性求解。普通试玩、录制、导入、单路径重放和原有条件证据继续保留。

## 主内容信息层级

试玩工作区顶部提供「普通试玩 / 路线对照」。切到对照不开始或推进 live story，不改变 RNG，不应用或保存作者草稿。

对照使用主内容区，不借用普通试玩的 300 px 调试栏承载主要结果：

1. 标题、当前已应用稿版本，以及「比较当前已应用稿 / 重新比较」「取消」
2. 两个等权重路线身份区：A/B、会话路径选择、结果实际所属路径名、入口或检查点、各自完整/部分/分歧/失败/超限/取消状态
3. 显著的风险说明：过期、未纳入草稿、不同 seed、不同起点、不能对齐、任一侧仅部分结果
4. 首个真实不同选择，或明确说明尚无可比较前缀/当前范围没有不同选择；存在来源时区分「选择声明」和「实际状态动作」
5. 一个主阅读滚动区：结果 state/vars 两侧值 → 选中 state 的实际动作 → 所属世界对象与验证来源 → 访问/选择覆盖

首屏始终能看出双方是谁、两侧验证状态以及首差异/无差异/不可对齐原因。完整结局才称结局，其余值称停止时状态。状态相同只说当前结果值相同，不称路线等价。技术信息的折叠区可以收纳 fingerprint、schema、详细预算和来源文件列表，风险信息不能仅放入该区。

1280×800、1188×848、1040×660，明暗主题均需验收。沿用现有字体、颜色和间距；状态使用文字与图形含义，不仅靠颜色。长中文标题、ID、值和路径换行或提供完整内容提示。主体不嵌套窄栏滚动；详情可以折叠。固定参考保持原身份、内容、选中项和历史，不能被来源导航替换。

## 数据、运行与新鲜度

- A/B 复用现有 saved_paths。仅当前工作台会话，不暗示重启恢复
- 复用现有 JSON 导入校验与边界；不得以对照入口绕过单路径导入限制
- 保存结果时保留冻结的两侧路径身份，改变选择器不能把旧结果冒充新路径结果
- 比较只由显式按钮触发；绘制、交换已显示两侧、展开详情与导航不重跑
- 使用现有 AppliedPlayScope 的版本、完整源码集合、编译选项、工程内容基线与排除草稿清单
- 比较输入确认签名包含 A/B 身份、两条 trace 与预算；确认期间任一项变化都要求重新核对
- 两侧临时运行共享一个冻结编译快照；不借用 live story 的 save、RNG、状态或录制缓存
- native 后台执行；WASM 使用同一 runtime 对照 DTO 和合作式 session，按帧限额推进。取消、超限、错误均保留真实停止含义
- 新任务取代旧任务或工程切换时取消旧任务；旧任务返回不得覆盖新任务或另一工程
- 改稿后保留旧结果，显著显示过期并禁用不可靠回源。必须显式重新比较，不以 fingerprint 相同代替内容基线相同

## 真实动作与来源

结果 state 行可查看两側按真实发生顺序列出的动作。每项保留运行归属、动作顺序、before/after、操作类型及 core 验证的动作身份。同值写入与循环重复动作不能按相同结果值折叠成一个。没有证据或存在截断时明确标注，没有观察到不表示未发生或不可达。

state 所属目标来自 catalog.states[id].target；世界对象只通过已有稳定 TargetRef 与阅读入口打开。变量仅并列实际值，没有动作证据时不提供猜测因果来源。

来源必须依次通过：

1. 该动作/选择属于当前显示的冻结比较结果
2. 结果 AppliedPlayScope 与当前工程、编译来源及完整内容基线匹配
3. 输入法、未应用执行草稿和恢复冲突保护
4. core resolver 验证对应快照和明确动作/选择身份
5. 工作区边界、来源文件身份、原文内容与磁盘导航验证
6. 既有 go_author_source_position 作者导航桥

「打开来源」只定位，不执行、应用或保存。选择声明与实际状态动作定位精度分别按 core 契约描述，不将声明头冒称子表达式或动作精确范围。

## 作者返回

Alt+Left 复用作者历史。对照返回位置仅属于本次会话，不写入项目或持久路径数据库，包括：结果身份、A/B 选择、选中差异和动作、主滚动位置、键盘焦点。

回源成功才写入历史。回源拒绝不得切换页、产生成功提示或增长历史。返回时恢复同一结果；若结果身份已变化，不恢复到错误动作，也不覆盖当前草稿。固定参考、未应用正文、工程 dirty 状态、live story save/trace 和 RNG 在整个只读闭环中保持不变。

## 自动化验收矩阵

### 语义消费与输入边界

- 同 seed、同入口，两路线访问节点集合相同但选择/state/vars 不同，首差异和两侧值均来自 runtime DTO
- 完整、partial、diverged、story_failed、预算和取消独立显示，不能把任一 `replayed` 一律写成完整结局
- 不同 seed/entry/checkpoint 显示风险；不可对齐时不按步骤序号硬配
- checkpoint 继承访问与本段实际执行分开，未访问始终称未测试
- 相同结果值不显示等价；动作遗漏有文字说明，未证实动作没有跳转按钮
- 既有 JSON 字节数、字符串长度、步数、路径数量边界保留

### 运行与只读闭环

- 比较前后 project baseline/dirty、磁盘字节、WritingBuffer、live save/replay_trace、固定参考一致
- 确认过程中更换 A/B、预算、草稿或工程使旧确认失效；取消和返回处理保留草稿
- UI 连续多帧不会创建重复任务，切页仍可取消/完成，旧任务不能覆盖新任务
- native 后台与 WASM 合作式任务具有相同结果含义；WASM 每帧限额和总预算确实生效
- source → Alt+Left 恢复同 A/B、结果、选中项、滚动和焦点；失败请求无历史副作用
- 未应用稿、输入法、恢复冲突、源码外改/移动/删除、同 fingerprint 注释移行均拒绝旧来源；重新比较使用当前准确来源

### 布局与原有行为

- 两主题 × 三尺寸首屏含 A/B、各自状态及首差异/明确无差异，技术折叠前也可见风险
- 长文本、空路径、相同路径、无结果、无差异、失败、过期、动作截断均可读
- 离屏 egui 测试核实文本与可点击控件边界；不能冒充原生鼠标、IME或跨平台验收
- 原生键盘与实际鼠标各完成：切换模式 → 选 A/B → 比较/取消 → 选差异 → 动作来源 → Alt+Left
- 普通试玩开始、暂停/继续、停止、重新开始、选项、保存路径、单路径重放、条件证据和固定参考回归

## 验证记录要求

只有实际运行过的命令和 GUI 流程才能记为通过。未运行、环境阻塞、失败与通过分列。保存构建来源、命令、结果、截图尺寸与主题，不把研究布局图或生产等效旧缓存当作最终新版本验收。
