# 作者反馈与键盘选择契约（0.11）

## 命令与完整对象快速切换

Ctrl+Shift+P的22个作者命令，以及Ctrl+P最多1000个对象候选，使用同一个键盘选择契约。
对象始终显示名称、类型、稳定ID、真实来源文件与行号；同名不合并，不按显示名猜目标。

- 上下键改变当前选择时，只对该次变化请求滚入视野。打开面板和更改过滤词时重新定位首项；
  结果减少导致选择归一也重新定位。不会在每一帧把手动滚轮滚动拉回旧选中行。
- 当前选择有高亮和边框。Enter只执行当前帧完整可见的选中项；若滚动尚未完成或作者已用
  鼠标把该项滚出视野，Enter不执行隐藏动作。上下键可重新定位，或直接点击可见候选。
- 空结果Enter无动作，不关闭面板，不自动跳到同名对象；清空筛选后重新显示合法结果。
- 输入法组合和提交所在帧不处理命令导航/Enter/Esc。Esc只退出最上层临时面板，并恢复
  先前编辑焦点和选区；未应用正文、表单与工程内容不因打开、筛选、移动选择而改变。
- 选择列表有明确最大高度和滚动区；无需改变全工作台布局或扩大1000项边界。

## 控件的状态可辨性

沿用现有暗亮配色、卡片及导航。未勾选复选框在同色卡片上仍有可见轮廓；hover加粗轮廓，
键盘focus/active保留更强轮廓。禁用控件保留边界且弱化，不能只靠填充颜色区分状态。
已勾选有勾形标记；审阅的解决/锚定文字由审阅视图独立提供，不能以checkbox颜色代替状态。
此样式适用于既有原生egui控件，未引入自定义checkbox或作品格式。

## 正文关键字教学

以choice、if或->等关键字开头的正文，在正常缩进后用反斜杠转义，例如 `\choice 只是正文`。
额外空格属于缩进，不是逃逸机制。语言规范与手册最小示例由正式执行回归覆盖；不修改lexer、
旧缩进含义、语言版本或运行指纹策略。详见worldline的syntax与handbook正文段。
