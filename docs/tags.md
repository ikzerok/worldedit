# 标签操作

## 查看与添加

进入“资料与状态”，点击“全部标签”。列表显示名称、ID 与直接关联对象数，右侧搜索支持名称、ID 和别名。点击标签打开资料，修改名称和说明不会改变已有引用的 ID。

在事件、人物或其他对象的“标签与引用文件”中，打开“搜索 / 多选标签”，按名称或 ID 搜索后连续勾选。直接标签可取消，正文内联标签需在源码中修改。点击已加标签可查看其资料和关联对象。

展开“＋ 创建并添加标签”，输入名称后点击“创建并添加”。已有同名或同 ID 标签直接复用；新标签自动分配未占用的 tag_N ID。创建与绑定作为同一次工程编辑，编译失败不提交。更完整的资料可到标签详情补充。

## 给标签加标签

打开标签详情，在“给此标签添加标签与引用文件”中使用同一搜索、多选与创建操作。例如打开“港口”，添加“地点”，表示港口被地点标记。打开“地点”可以查看直接使用它的对象；勾选“包含下级标签标记的对象”，也会找到被“港口”标记的事件。递归查询去重，不会把循环关系无限展开。

## 用标签设置条件

事件前置要求、分支显示条件和事件效果条件均有“＋ 用标签设置条件”：

1. 选择要判断的状态，例如“林舟心情”。
2. 搜索并勾选标签，例如“冷静”和“警惕”。
3. 默认要求全部包含；勾选“不含”改为否定，勾选“任意一项”改为或关系。
4. 默认与已有条件同时满足，也可选择满足其一。
5. 核对生成的表达式预览，点击“添加到条件”。原有表达式会加括号，保留其优先级；仍可直接编辑表达式。

条件读取运行中的状态集合。给人物、事件或标签添加分类标记，不会自动改变该对象的状态；状态内容中的 has 也不递归展开分类标签。

## 改变状态

在事件效果中，或展开分支的“＋ 选后改变状态”，选择状态及标签，然后选择操作并点击“＋ 添加状态变更”：

- 替换全部标签：用所选集合替换状态；不选标签表示清空。
- 增加标签：保留其他内容，加入所选标签。
- 移除标签：保留其他内容，移除所选标签。

动作加入效果代码末尾，或分支正文末尾、该分支直接出口之前。已有正文中的提前跳转可能使后加动作不执行，复杂分支请检查完整正文并试玩。增加、移除操作必须选择至少一个标签。

条件和动作首先修改事件草稿，点击“应用更改”进行全工程验证，再“保存全部”写入磁盘。状态初始内容在状态资料中修改并应用。对象分类标签操作直接更新工程缓冲，也要保存；可以使用撤销恢复。
