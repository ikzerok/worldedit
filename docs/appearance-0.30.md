# v0.30 设备外观契约

## 目的与边界

外观只属于当前设备。切换、预览、恢复默认和保存外观不得修改作品内容、工程 dirty、内容指纹、作者位置、参考对象或工作区历史。默认采用 Studio 编辑台、雾松、跟随系统、标准密度；系统没有提供明暗信息时使用浅色。没有旧版主题入口，也不支持任意 CSS、任意颜色或外部字体下载。

## 五个独立维度

- 明暗：System / Light / Dark，保留用户明确的覆盖意图
- 配色：十组、十七个实际明暗成员。雾松 Mist、梅墨 Plum、纸铜 Copper、海盐 SeaSalt、石墨 Graphite、樱花 Sakura、印刷黑白 Monochrome 支持明暗；终端绿 Terminal 与霓虹夜景 Neon 仅深色，羊皮墨 Vellum 仅浅色（模式意图保留规则见后文）
- 结构：Studio 为贴边平面分栏与留白分组；Manuscript 为居中连续纸面、独立页边和纸外工具，不伪造分页；Technical 为贴边网格、栏头带和直角分组；Focus 为可召回工具的无框居中正文；Ledger 为宽窗侧题签、窄窗题签上移的对齐内容列
- 密度：Compact / Standard / Spacious 控件与列表行分别为 26 / 30 / 36 逻辑点，不通过减小字体提高密度
- 排版：界面、正文、源码分离。正文可选实际 Sans 或 Mono 字族，字号 12–36（默认 17）；源码字号 12–28（默认 15）独立；行距 1–2.1（默认 1.65）；阅读宽度 480–1400（默认 760）；界面缩放 80–200%

受控强调色可用本色、松绿、梅紫、铜橙、靛蓝、冰青；每种都有配套按钮文字、hover 和 focus token，选中底色保持基础配色的语法与阅读关系，所有配色组合都计算实际背景对比。高对比把次要文字与必要边界提升为主文字并加粗焦点；减少动态将界面过渡时间设为零。禁用状态保留独立可读文字角色、稳定表面与必要轮廓，不依靠透明度表示状态；增强对比也保留该文字角色。不可用动作应附具体原因。

## 组件与数据流

AppearancePreferences + 系统明暗 → normalize → ResolvedTheme → egui Style、语法色、表面与字体角色。

ResolvedTheme 存在各自的 egui Context 内。只在完整解析结果变化时重新安装样式。零参数兼容 helper 读取有作用域的 FrameThemeGuard 快照；guard 结束（含提前返回）后撤销绑定，嵌套 Context 恢复外层快照。线程变量不保存用户偏好或持久主题真值。

稳定组件入口：

- resolved(ctx)、configure_appearance(ctx, preferences) → FrameThemeGuard
- metrics()：control_height、row_height、section_gap、panel_margin、button_padding
- shapes()：control、row、document、popup、window
- style_preset()；body_font(size)、source_font(size)
- document_surface(ui, max_width, contents) → InnerResponse；panel_header(ui, title, subtitle)
- panel / chrome / index_panel / card：兼容名称重新定义为新表面，card 不再是全界面描边圆角卡片
- BG / CHROME / NAVIGATION / PANEL / DOCUMENT / CARD / TEXT / MUTED / CONTROL_BORDER / HOVER / SELECTION / FOCUS 等明确角色

Studio 的正文连续平面、Manuscript 的有限宽纸面与页边、Technical 的贴边正文与网格栏头是结构差异；不能仅靠颜色或圆角声称三种结构完成。输入和键盘焦点的必要边界独立于装饰分隔。错误、警告、选中、禁用及只读同时提供文字、图标或交互语义。

## 设置事务

个人 Settings 保存 committed 外观，窗口另存 draft。窗口打开时复制 committed；控件只更改 draft，实际画面读取 draft（无 draft 时读 committed）。自动持久化永远只保存 committed。

- 应用：提交规范化 draft，窗口继续开启
- 确定：提交后关闭
- 取消 / Esc / 标题栏 X：同一路径丢弃 draft，并恢复最近一次已应用值
- 应用后继续修改再取消：保留已应用结果
- 恢复默认：只重置外观 draft，不改变布局、源码折行、作者位置、参考或历史；仍可取消
- 重开：从最新 committed 开始，不遗留旧 draft

设置窗口内容可滚动，按实际窗口可用高度先预留操作栏，配色说明增减或手动缩小时操作栏仍可达；键盘焦点滚动即时更新，不因零时长动画的延后布局而短暂裁切目标；200% 与窄窗不得把取消操作放到不可达的位置。预览提示和存储保护提示在窗口可见。源码折行属于立即生效的视图菜单设置，不混入外观事务。

## 设备数据迁移与保护

继续使用 worldedit.personal.v1 存储键，载荷 schema_version 升到 2，避免多个键争夺优先级。v1 主题意图和合法的正文字号、行距、阅读宽度迁入 appearance；未写明主题的旧载荷按原有 Dark 默认解释。新用户使用 System。原导航、问题栏、专注、折行、宽度、最近工程、工作区、参考及定位字段保留。

已知版本的坏外观字段逐字段恢复，不连带丢弃其他合法外观或作者状态；数值范围修正时使用明确默认和边界。未知未来 schema、无法解析的 JSON 与超过安全读取限额的数据原字节保留，禁止自动保存覆盖；会提示当前会话可以预览但设置无法写回。未支持的未来版本不降级重写。

## 字体与 Web 外壳

正文 Sans / Mono 是实际 egui 字族：Latin 主字体保留相应的比例或等宽字体，中文按字形回退。系统中文字体不可用或无法解析时使用仓库内 NotoSansSC；Web 离线使用同一已捆绑字节。CJK 回退不是等宽中文保证，不把字体菜单名称当作任意第三方字体已加载。

Web CSS 仅控制画布外背景和加载状态，使用当前持久化外观的已知 token；双模式配色的系统模式跟随 prefers-color-scheme，无信息回落浅色；单模式配色按已声明的固定支持解析。CSS 不修改 Rust 画布组件，也不改变作品导出。

## 验证范围

自动测试的覆盖合同为全部十七个基础颜色成员、所有受控强调色、普通/增强对比、真实控件状态与图形边界，分别按文字 4.5:1、必要轮廓/焦点 3:1 计算。十组 × 两种明确模式请求 × 五结构 × 三密度 × 四缩放共 1200 个请求组合（包含单模式重复的有效成员）验证解析与有限尺寸；多 Context、缓存、系统变化、设置撤回、重复开关、迁移幂等、作者状态保留、字体回退均有测试。

这些测试只证明被测 token 配对和 headless 行为。完整视觉、物理 IME、读屏以及未实际运行的平台必须分别报告，不以编译、颜色比值或模拟按键替代。

## 扩展结构与冷色（同一 v0.30）

保留已审阅的 Studio、Manuscript、Technical 和雾松、梅墨、纸铜；默认仍为 Studio × 雾松 × System × Standard。新增海盐 Sea Salt & Indigo、石墨 Graphite & Ice Cyan，各有独立明暗；受控强调色另增靛蓝、冰青。强调色改变按钮/链接/焦点，选中底色与语法仍随基础配色。

新增 Focus 专注：无纸框的居中连续内容与轻量标题，导航/文件/固定参考通过明确入口暂时召回。隐藏只是当前风格的呈现策略，不能覆盖用户已有导航、停靠、专注模式、宽度或固定对象偏好；退出、关闭抽屉和取消外观均能返回原内容。

新增 Ledger 档案：宽区域以 112pt 题签、16pt 间距和至少 480pt 正文组成对齐的资料区域；不能容纳时把题签移到正文上方，不挤压正文。它不将作者文本改写成表格，也不新增业务字段。控件/选中行/正文/浮层圆角分别为 2/2/0/4；Focus 对应为 6/6/0/10。

原 document_surface 接口维持原三结构行为；document_surface_titled 支持题签名称；纯 document_geometry 可直接验证可用宽度和窄屏回落。所有结构均受已有密度与字体设置影响，切换结构不替用户改写这些值。

当前颜色成员为七组双模式加三组单模式，共十七个有效成员。有效颜色 × 五结构 × 三密度 × 四缩放共有 1020 个不重复显示组合。显式请求矩阵则为十组 × Light/Dark 两种请求 × 五结构 × 三密度 × 四缩放，共 1200 个请求组合；单模式中部分请求解析到同一成员，不能计为额外配色。System 的有/无系统信息、系统变化、固定模式暂时主导显示、切回双模式恢复偏好另作请求语义回归，不混入 1020 的有效组合数。新增配色必须通过与旧配色相同的文字、按钮、语法、选中、错误、禁用、焦点、控件轨道和必要图形边界检查；受控强调色须跨全部基础配色验证。

## 风格化配色扩展（同一 v0.30）

在原五组十成员之上添加 Terminal 终端绿（仅深色）、Neon 霓虹夜景（仅深色）、Vellum 羊皮墨（仅浅色）、Sakura 樱花（明暗）、Monochrome 印刷黑白（明暗），共十组、十七个实际颜色成员。保留原五种结构与 Studio 默认，不为配色切换字体或布局。

终端绿使用绿黑底与磷绿文字；霓虹夜景以蓝紫暗底、粉色强调和冰青焦点构成夜景感；羊皮墨为灰橄榄纸面与历史墨色，区别于纸铜的橙铜；樱花偏暖粉红；印刷黑白主体与语法为灰阶，必要的错误、警告和状态色仍保留可见文字/符号提示。不添加发光、闪烁、扫描线或背景纹理。

PaletteId::ALL、label、description、mode_support 是系列登记入口。模式支持分为 Both / LightOnly / DarkOnly。明暗偏好始终保存在 AppearancePreferences.theme；normalize、切换配色、预览与提交都不能为了固定模式改写它。ResolvedTheme.effective_mode 是实际的 Light 或 Dark，light 为其兼容判定。双模式配色按用户明暗偏好和系统解析；单模式配色使用固定模式，System 在此期间不跟随系统变化。

固定模式的设置说明必须持续可见：“本配色固定深色（或浅色）；已保留原模式偏好，切回双模式配色后恢复。” 明暗按钮表示保留的偏好，不能声称它正在控制单模式配色的实际明暗。切回双模式后恢复先前请求的 Light / Dark / System，不另存隐含模式。Apply → 再改 → Cancel、Esc、X 仍恢复最近已提交的完整外观。

受控强调色仍为本色及既有五种，不增加无独立用途的菜单项。其按钮文字、hover、focus 按实际有效明暗选择，须与全部十七个基础成员配对检查。选中背景和语法留在基础配色。Web loader 使用相同固定支持规则，只读取存储；Rust 启动后同步有效配色。

新增自动化须覆盖注册完整性、固定模式与系统变化、保留/恢复明暗意图、序列化/迁移/局部恢复、真实预览和撤回、窄窗说明/选择入口可达性、文字/语法/禁用/错误/选中/焦点/节点实际背景以及强调色混配。既有十个成员的精确 token 不得因扩展而改变。

持久化外观的 mode（含旧 theme 别名）、palette、style、density、accent、body_family 只接受已登记的字符串枚举；数组、对象（包括类似 `{ "Terminal": null }` 的外部标记形态）属于坏字段，逐项回退，保留相邻合法数值、布局与作者数据。正常 v1/v2 序列化一直使用字符串。Web 加载壳执行相同的字符串白名单规则。

## 不可用控件的可辨识性

不可用状态不能只有 1% 的透明度差。普通 Button、Checkbox 和禁用组统一经过轻量 theme 适配：在原 Ui 临时安装可读的 disabled 文字与稳定控件表面，再调用原 egui add_enabled / add_enabled_ui；不新增 Ui 层级，不改变 Widget、条件、ID、布局尺寸或返回行为，结束后恢复原 Style。父级禁用不能被内层 true 重新启用；嵌套不叠加文字透明度。

disabled 文字采用基础次要色且完全不透明，在实际背景保持至少 4.5:1；高对比仍保留这一独立角色，普通 secondary 与必要边界的增强规则不变。按钮/勾选框采用稳定禁用表面，既保留必要边界，也能与可用静止态区分。显式 RichText 错误/警告等语义颜色保持，不通过改字体、字号、删除线或全局降低对比表现不可用。

选中状态、自定义 Widget 的显式 fill / 颜色仍服从各控件语义，不把该适配宣称为任意自定义控件的完整无障碍认证。重要不可用动作仍应提供已有的前提/原因说明。设置状态示例使用当帧局部解析的 Colors，不能被帧初 Context 旧配色覆盖。

显式 EDS-11 隔离原型工厂拥有独立 Context，draw 同样持有默认 AppearancePreferences 的 FrameThemeGuard；不能假设普通 App 已替原型安装配色。原型不读写个人设置或用户作品。
