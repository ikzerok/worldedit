# 时间约束与可信重放

事件表单沿用 worldline 的世界偏序语义，重放不会仅因片段源码位置变化而报告分歧。
默认语言仍为 1.9，最高支持 1.13，不自动升级旧作品。本流程使用作者自己的工作区；
发行包不附带故事示例。先确认工程声明的语言版本与已有对象关系，再操作表单。

## 改时段前先看已选关系

打开已有事件，查看“明确晚于以下事件”的前驱关系。显式语言 1.13 允许同一时间根内
跨直接时段的关系；1.9–1.12 仍按同一直接时段限定。

- 已选关系与可选候选同时显示名称、ID、直接时段及时间根，不凭同名或图上位置判断
- 改时段后仍合法的前驱保持选中；只改标题不应移除已有关系
- 去掉时段或改到独立根时，现有非法前驱不会自动消失。先读原因，再决定是否明确取消
  具体关系；非法状态下不能直接应用
- 即使取消当前事件的前驱，其他事件也可能仍把它当作前驱。应用会校验整个工程中的
  前驱、后继和环，失败保留输入且不部分改写
- 无根、错误或不完整快照不能当作可安全改写的完整结果

点“应用更改”后查看时间线，确认计划保留的关系仍在；随后 Ctrl/Cmd+S 才保存磁盘。
取消、撤销与恢复草稿沿用已有保护。`at`、书稿顺序和运行入口不因改时段而变动；
时间线不提供日历计算或自动事实裁判。

## 用两条实际路径检查改稿

1. 试玩一条路径，在叙事调试器用“保存当前路径”记录；重新开始后走另一条路径并保存。
   每条路径的实际选择、起点和是否完整记录都应在调试器中确认。
2. 路径先保留在本次工作台会话。长期留存时点“导出所选路径 JSON”，复制并另存显示的
   只读正文；“保存全部”不是路径文件导出。交换统一采用 4 MiB UTF-8 / 20,000 步上限，
   详见[有界路径交换](replay-exchange.md)。
3. 给两条路径共同调用的片段增加空行或注释，应用源码草稿。选已记录路径，点“重放所选
   路径”，检查结果属于当前编译稿；旧试玩快照不会被自动当成新稿结果。
4. 运行语义不变时，不应仅因片段当前文件或行号改变而分歧。当前源码定位仍可用；调用
   对象、参数/local、栈与执行位置、输出和状态没有被忽略。
5. 再修改实际影响路径的变量初值或条件，版本兼容的入口轨迹会在观察到真实差异时停止。
   检查点起始轨迹还须匹配程序指纹，不能绕过校验。

请用同版 runtime 生成和重放。旧 runtime 的合法路径可只读导入和查看，这不表示它能
执行；开始重放仍严格校验 runtime/schema，工具不会自动迁移旧轨迹。普通 Story 演练
存档另按读取格式、必需能力和指纹规则处理，不能概括成与轨迹相同的版本绑定。

结果跳转只使用本次 ReplayResult 在当前程序里的实际位置；旧轨迹的行号只用于预期
对比。结果过期时先重新重放；执行结束或对象缺失且没有实际位置时，界面明确不可跳转，
不会猜测活动文件或相邻行。

重放可以取消，也有自己的步数/时间预算；“已取消”“达到上限”“发生分歧”都不是
完整通过。普通试玩的暂停续行另见[有界试玩](bounded-play.md)。路径只证明实际覆盖的
选择，不能据此声称所有分支已测。

## 中断时先保稿

正文、事件表单和其他工作台的输入，应用后才进入工程缓冲；保存再写磁盘。未应用稿、
已应用未保存稿与旧基线草稿是不同状态。切页或关闭的提示中选“取消”会保留当前工作；
需要丢弃时必须明确决定。

遇到基线过期或磁盘冲突，保留输入并查看差异，在最新原文上合并后重试。不要为消除
提示自动应用、清空或重置基线。完整导出会列出未应用输入；选择仅导出已应用版时，
这些输入不会进入副本。详见[工作区说明](workspace.md)。

稳定 ID、显示名、别名与正文文字分开。当前统一身份重命名支持 entity/relation，以及
显式 1.11 起的 rule/fragment/character/tag/state；event/scene/file 尚不在同一安全改名
范围。手动改引用或移动文件不是一键原子重构，人物等运行身份改名仍可能使旧存档不兼容。
