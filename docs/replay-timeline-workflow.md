# 时间约束与可信重放

产品 0.12 让事件表单与已有世界偏序语义一致，并避免片段源码位置变化制造重放分歧。默认语言仍为 1.9，最高支持 1.13，不自动升级旧作品。配对 worldline 的[栖雪山站示例（在线，需联网）](https://github.com/ikzerok/worldline/blob/d41034dff247f590070a4aaf18c14f943ef7620b/examples/snowline-seeds/README.md)可用于下面的操作；离线 Windows 发行包内的说明位于 `windows/worldline/examples/snowline-seeds/README.md`；配对源码中位于 `worldline/examples/snowline-seeds/README.md`。

## 改时段前先看已选关系

打开示例中的 handover。collection 是它的已选前驱：两者分别属于 afternoon 与 night，却同在 journey 时间根内，显式语言 1.13 允许这条关系。

- “明确晚于以下事件”同时呈现已选关系与可选候选，用名称、ID、直接时段及时间根确认对象；不要凭同名或图上位置判断
- 把所属时段从 night 改到 afternoon，collection 仍合法，继续保持选中；只改标题也不应移除任何已选关系
- 去掉时段或改到独立根时，现有非法前驱不会自动消失。先读原因，再决定是否明确取消具体关系；非法状态下不能直接应用
- 即使取消了当前事件的前驱，其他事件也可能仍把它当作前驱。应用会校验整个工程中的前驱、后继和环，失败保留输入且不部分改写
- 1.9–1.12 的候选仍按同直接时段限定；1.13 才允许同根跨时段。无根、错误或不完整快照不能被当成可安全改写的完整结果

点“应用更改”后查看时间线，确认 collection → handover → delivery 仍在；随后 Ctrl/Cmd+S 才保存磁盘。取消、撤销与恢复草稿各自沿用已有保护。`at`、书稿顺序和运行入口不因改时段而变动；时间线不提供日历计算或自动事实裁判。

## 用两条真实路径检查改稿

1. 试玩路线 A，在叙事调试器用“保存当前路径”记录；重新开始后走路线 B，再保存一条路径。示例每路两次选择，完整结果见其 README。
2. 这些路径先保留在本次工作台会话。长期留存时点“导出所选路径 JSON”，将显示的 JSON 另存文件；“保存全部”不是路径文件导出。
3. 给共享 inspection 片段加空行或注释，应用这份源码草稿。选已记录路径，点“重放所选路径”，检查结果属于当前编译稿；旧试玩快照不会被自动说成新稿结果。
4. 在运行语义未变时，不应仅因片段当前文件或行号改变而分歧。当前源码定位仍可用；调用对象、参数/local、栈与执行位置、输出和状态没有被忽略。
5. 若把 label_count 初值从 1 改成 2，版本兼容的入口轨迹会在观察到真实差异时停止。检查点起始轨迹还须匹配程序指纹，不能绕过校验。

请用同版工具生成和重放。ReplayTrace 与调试检查点严格匹配 runtime 版本，并校验 schema；0.11 轨迹不能直接在 0.12 重放，定位修正不会迁移旧版本轨迹。旧可选 DTO 形状仅在 runtime/schema 已兼容时可读。普通 Story 演练存档另按读取格式、必需能力和指纹规则处理，不能概括成与轨迹相同的 runtime/schema 绑定。

结果跳转只使用本次 ReplayResult 在当前程序里的真实位置；旧轨迹的行号只用于预期对比。结果过期时先重新重放；执行结束或对象缺失且没有实际位置时，界面明确不可跳转，不会猜测活动文件或相邻行。

重放可以取消，也有自己的步数/时间预算；“已取消”“达到上限”“发生分歧”都不是完整通过。普通试玩的暂停续行另见[有界试玩](bounded-play.md)。路径只证明实际覆盖的选择，不能据此声称所有分支已测。

## 中断时先保稿

正文、事件表单和其他工作台的输入，应用后才进入工程缓冲；保存再写磁盘。未应用稿、已应用未保存稿与旧基线草稿是不同状态。切页或关闭的提示中选“取消”会保留当前工作；需要丢弃时必须明确决定。

遇到基线过期或磁盘冲突，保留输入并查看差异，在最新原文上合并后重试。不要为消除提示自动应用、清空或重置基线。完整导出会列出未应用输入；若选择仅导出已应用版，那些输入不会进入副本。详见[工作区说明](workspace.md)。

稳定 ID、显示名、别名与正文文字分开。当前统一身份重命名支持 entity/relation，以及显式 1.11 起的 rule/fragment/character/tag/state；event/scene/file 尚不在同一安全改名范围。手动改引用或移动文件不是一键原子重构，人物等运行身份改名仍可能使旧存档不兼容。离线 Windows 包内的完整路线位于 `windows/worldline/docs/author-route.md`；也可在线阅读[从资料到可信重放（在线，需联网）](https://github.com/ikzerok/worldline/blob/d41034dff247f590070a4aaf18c14f943ef7620b/docs/author-route.md)。
