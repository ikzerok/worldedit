# 从资料查询巡检地图与正式关系

## 一条可返回的工作路径

1. 打开资料库的「组合查询与待办」，设置已有筛选，或载入一份受支持的共享查询，然后点「运行查询」
2. 先看完整命中数、来源诊断和命中原因。结果表的一页不等于全部范围；查询只构建一次冻结快照，之后翻页不会重新编译
3. 点「在地图巡检全部命中」或「在关系巡检全部命中」。宽窗显示「临时查询范围」；小窗显示命中数，并从「范围操作」返回同一查询、返回巡检位置、刷新、取消刷新或清除
4. 在范围列表选择一个对象的具体位置。一个对象在多张地图、多个标记或矢量图元上出现时，逐处保留；位置列表本身可以翻批
5. 点「正式关系」查看该对象的一至两层明确关系。节点写明「命中」「仅关系上下文」或「未解析端点」；上下文不增加原查询的命中数
6. 点「编辑真实资料」或「打开来源」进行正常编辑。当前输入、输入法组合和地图草稿沿现有保护处理；巡检不会自动应用或保存
7. 改稿后范围会过期。显式刷新得到新快照，并看到原/当前数量；返回保留查询与个人浏览位置
8. 点「清除范围并恢复」恢复进入前的个人视图。原地图或来源已变化时沿已有安全恢复规则说明无法沿用的位置，不按同名对象猜测替换

小窗口的地图工具位于可滚动的「地图操作」菜单；Escape关闭菜单时保留校准、绘制等未提交输入。关系巡检可切换「关系图／范围列表／关系上下文」；点击「关系操作」进入独立的可滚动操作页，调整层数、方向、分页和筛选。「完整网络检查器」另开一页，两页顶部都保留「返回关系图」。

## 数量如何理解

- 「命中」是 core 对完整候选集筛选后的结果，不是当前表格页或画布上的数量
- 「地图绑定」逐处计算，旧标记和 scene 图元都算，一个对象可以有多处
- 「无已知位置」表示此快照没有找到绑定。存在未知格式、缺失文件或解析错误时，它不等于确定未放置
- 「未解析地图绑定」是缺失目标的引用，单列巡检，不计入查询命中
- 零命中只说明当前条件没找到对象，不能说明作品没有资料
- 正式关系只使用独立 typed 关系与方向；普通文字提及、地图包围和装饰线段不生成关系

## 临时展示与作品内容

巡检不写入新的集合文件，也不将范围写入共享展示预设、世界事实或公开选择。地图轮廓使用当前主题的语义颜色；默认显隐、坐标、图层和锁定不因范围改变。装饰图元仍按正常地图显示。画布最多标注当前地图的前 500 处匹配绑定，并明确显示绘制上限；全部命中和逐处绑定仍可在范围列表分页检查。

隐藏/锁定位置仍列在列表。定位走已有地图导航；不会绕过草稿保护或因为查询命中就给予编辑权限。未知必需能力和只读文档保持保护。关系网络的查询期间不提供保存共享布局，清除范围后恢复原有布局操作。

保存筛选仍使用既有共享查询；临时 scope 与返回位置只在当前会话存在，关闭/切换工程不生成新持久文档，也不恢复过期的范围。

## 后台、取消与预算

原生后台线程构建完整查询、地图绑定和正式关系；同一进程同时只允许一项查询计算，快速取消/重开会等待旧计算真实退出，不无限复制大型工程。取消按核心检查点结束；一次编译和已有整份地图解析阶段不能在中间抢占。浏览器使用同源 Worker，取消终止该 Worker。任务取消、筛选变化和切换工程后，晚到结果不能覆盖当前输入。

候选默认 10,000、最多 100,000；scope 对象（含未解析端点）、绑定及正式边各最多 100,000，诊断最多 10,000，完整 JSON 最多 32 MiB。超过预算明确失败，不能把部分集合包装成完整范围。局部关系一页最多 250 节点/500 边；「下一页」继续真正剩余的关系。

冷构建需要一次编译与地图解析；完整快照建立后，列表翻页、局部关系查询和空闲帧不进行工程重编译或地图重解析。外部刷新与新导入使旧范围失效。浏览器导入工程仍是快照，不代表持续监视磁盘。

机器接口与完整 typed 合同见 worldline 的 `spec/catalog-scope.md`；CLI 为 `wl catalog-scope`，RPC 为 `catalog.scope`。两者只读使用同一 core 投影。

后台构建不会为未跟踪的 include 临时读取新磁盘正文。附件单独增删或保护观测失败也会在下一次真实外部刷新后使范围过期，即使作者源码基线未变。空闲帧只比较上次刷新留下的内存观测标记，不自行探测磁盘；没有刷新时不会声称已经得知外部变化。

机器RPC的 `catalog.scope(project_id)` 只消费已打开会话的已应用缓冲，不隐式刷新或恢复保存事务。自动外部刷新属于编辑器既有生命周期；机器调用方若需要读入外改，必须另行明确调用已有 `project.analyze` 后再查询。
