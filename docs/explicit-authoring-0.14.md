# 0.14：明确稿件、证据来源和语言能力

## 试玩和严格重放

开始、重新开始、严格重放都运行“已应用工程稿”。应用但尚未保存的修改会参与；正文缓冲、隐藏表单和输入法中的未应用输入不参与。入口列出相关来源，同一源码的多个书稿章节去重。作者可返回处理、取消，或明确运行已应用稿；任何选择都不自动应用、清空或保存输入。纯地图布局、书稿排序等展示草稿不因此阻断试玩。

确认窗口期间稿件或输入变化会要求重新确认。结果标明实际运行的快照和被排除的草稿；旧故事中的人物/Wiki资料也使用它自己的快照。严格重放仍在首处差异停止，不改录制轨迹或期望，不提供“按新文案忽略差异”模式。

## 从条件证据返回作者来源

调试区的条件、可选条件、once 和纯规则定义可返回经 core 验证的作者来源。这里显示的是该次真实求值缓存，不为导航再次求值，不消耗随机数。定位范围明确为声明头；并非表达式每个 token 的精确选区。错误、未求值和省略各有独立文字。

来源必须与实际运行快照、身份及内容基线吻合。未应用改稿、文件移动/改名/缺失或旧快照不能确认时会解释原因并拒绝导航，不用旧行号覆盖新稿。可表示的书稿结构/写作模式优先保留，必要时回到源码。Alt+Left 沿已有作者历史返回；若返回位置本身已过期，同样安全拒绝。

## 语言与资料能力

“工程 → 语言与资料能力…”和任务命令可查看已支持版本及具体 required_features。新建工程会给同一显式选择；取消仍保持默认 1.9。想创建地点、组织、物品，可先选择 1.10 或更高版本，再检查全文兼容预览。无需外部编辑 JSON。

预览包含新增关键字解释、全文诊断、能力依赖、实际前后运行指纹和存档边界。有未应用输入先返回处理；已应用但未保存的稿件可参与。候选错误保留原稿并禁止应用；确认成功只完成可撤销内存事务，仍由作者保存。未知版本/能力原字节只读保留，扩展字段不被改写。

短窗或高缩放下，说明、能力选择、预览、兼容确认、启用和取消共享完整窗口内的纵向滚动。首次打开和重新打开须把语言选择焦点滚入可见范围；Tab 前进、Shift+Tab 后退也须显示完整焦点控件，不能要求先用鼠标找回焦点。滚入只响应本次键盘导航或打开窗口，随后手动滚动不得被旧焦点拉回；宽窗保留正文滚动与固定动作。Enter 可打开版本列表、选择版本或执行当前按钮；Escape 先关闭已展开的版本列表，能力表单本身仍使用“取消 / 保留当前设置”明确退出，不用 Escape 丢弃当前选择或确认状态。预览、滚动与取消不改工程或其他作者输入。

完整作者组合示例见 worldline 的 docs/explicit-capabilities.md，展示同一命题的作者事实、相信、所知和携带分别建模；没有新增知识、库存或日历 DSL。

## 主题与范围

试玩正文、调试结果和条件证据统一使用现有主题语义色。暗色、亮色和跟随系统均保留错误/警告/禁用原因的文字，不仅依赖颜色。普通可见语义文本在实际使用背景上以 4.5:1 为内部对比目标；禁用控件按非活跃例外单独检查。此目标不是可访问性认证。

本版不重做皮肤，不改默认语言，不自动迁移旧工程，不保证升级后所有运行指纹不变。产品 0.14.0、最高语言 1.13 与 runtime/trace 版本是不同概念。
