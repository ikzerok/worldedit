# 本地后台计算与取消

地图 SVG 预检、场景批次预览、创建地点并绑定、派生场景栅格和读者站构建使用 typed 后台任务。桌面使用受控后台线程；浏览器使用与编辑器同源、随静态包分发的 Web Worker。两端共享 worldline core 与 renderer 计算，不另建语言解释器。

浏览器包必须同时含入口 JavaScript、WASM 和本地 worker 模块，不依赖 CDN、外部字体、SharedArrayBuffer 或放宽安全策略。worker 加载页面声明且经同源检查的构建产物；没有 Window 的执行环境不启动编辑器 UI。

## 请求与快照

请求字段包含 schema 1、任务 ID、会话代次、完整内容基线、入口、可选快照状态和任务枚举。任务枚举为 SVG 预检、场景批次预览、地点绑定预览、场景渲染、读者包。源码与资源通过二进制侧通道传输；元数据和负载有独立上限，活动文件与墓碑合计受 worldline 的[后台快照契约](../../worldline/spec/workspace-snapshot.md)约束。

有 Project 的请求必须捕获精确状态，不使用会刷新/迁移/编译工程的导出捷径。独立 SVG 预检与派生渲染不伪造 Project。计算端拒绝不支持的 schema、数量或字节超额、身份不匹配、错误路径、重复负载和无效墓碑描述。

## 进度与取消

长任务在 ≤250 ms 的前台响应边界内显示明确阶段、进度或可取消忙状态。取消目标为 ≤500 ms；浏览器终止 worker 并移除所有处理器和排队结果。桌面取消标志不能伪装实际线程已经退出；资源许可持续保留到真实计算结束。

关闭、Escape、切换工程、丢弃本地输入和新的同类任务都能使旧任务失效。窗口 X 或取消意图在同帧先于完成结果副作用处理；按下关闭按钮期间不能提前消费成功结果并打开页面或下载。

取消不自动应用半份场景、不输出半站、不清空作者输入，也不推进保存状态。已排队完成消息仍须经过当前状态验证，不能因为“计算完成”跳过取消。

## typed 结果检查

- 请求和结果枚举必须匹配，任务 ID、代次和完整基线必须当前有效
- 场景批次的头部、操作顺序与非导入操作保持不变；只允许原 ImportSvg 替换为其经 core 验证的 ImportScene，图层与标题不能被结果改写
- 地点绑定结果保留原 typed 请求，主线程交由 core 再次预检和原子应用
- 栅格结果的尺寸、DPI、缩放、平移和字节长度等于请求，不接受不同 RasterSpec 的像素
- 读者包文件路径唯一、安全，实际文件数/字节数符合预算；交付前重新验证显式选择、profile 和基线

worker 不能写原工作区、保存稿件、请求下载或打开系统浏览器。主线程不把返回的任意文件字节当作场景提交授权；core 仍是唯一结构语义真源。

## 渲染资源与许可

栅格器只消费 core 安全 serializer 生成的受支持 scene，禁外部资源解析。图像是可丢弃派生缓存；持久真源保留矢量路径、文字、组和变换。实际缩放×DPI 变化需要重绘，不以低清图放大冒充矢量。

跨地图图层和导入预览共享最多两个实际活动渲染任务。RGBA 工作缓冲与纹理预算为桌面 128 MiB、浏览器 64 MiB，分配前预留并覆盖峰值存活期；关闭后仍在运行的桌面线程不能提前释放许可。此额度不宣称是 resvg 内部隔离组、树、字体或整个进程 RSS 的上限，内部合成另有有界检查。

预算不足的可见层集必须明确报错；暂时排队和无法容纳整个视口不能混同。不能静默跳过层、降低 DPI 或改变 legacy/scene 的逐层叠放语义。

## 自动化与实际验证

测试覆盖快照墓碑、畸形/不同类型结果、身份或 RasterSpec 替换、ImportScene 正规化篡改、取消与排队完成竞态、窗口 X、断开后台通道、重复请求、导入文件选择器取消和清理，以及很多图层时并发/缓存配额。

发布门禁含 native 与 wasm 静态检查、完整静态包资源闭包、真实浏览器请求路径与最终 Linux 原生作者流程。编译通过、headless CPU 测量或无外部 URL 扫描不能替代实际 browser/native 验收；受工具拒绝的 file:// 路径单独列为未验，不能绕过拒绝。
