# 0.8 作者工作区与个人设置

## 内容与个人状态

工程源码与展示文档仍由 core 管理，界面不复制解析器或另存正文。导航、专注模式、旁查、字体、主题、列显隐和最近位置属于当前设备/浏览器的个人设置，不写工程、不进入完整工程包、不改变运行指纹或撤销栈。个人存储版本为 1；格式未知或损坏时保留安全默认，不把内容草稿写入个人设置。原生工程以规范根路径区分，浏览器以导入快照的会话身份区分；恢复时只打开仍存在的文件/完整对象身份，失效项明确提示，不能按同名猜测。启动时优先打开显式指定路径；未指定时可恢复仍有效的最近工程。没有有效最近工程时选择目录；显式路径无效或取消选择时干净结束，不回退打开其他工程、不自动新建。

界面提供导航显示、无错误诊断折叠、正文专注、停靠/浮动参考与重置布局。窄窗口只显示一份参考标签，宽窗可并排两份，停靠时分配真实空间而不覆盖正文。最小窗口同时打开参考时，导航临时收入顶栏“导航”菜单；资料索引空间不足时改由“资料索引（窄窗）”抽屉打开，关闭或选择对象即可收起。收起参考或扩大窗口后自动恢复侧栏，不修改个人导航偏好。当前章节/对象、源光标与滚动位置、侧栏尺寸及两份参考可随个人会话恢复。任何恢复都不能应用表单或执行故事。

## 草稿生命周期

“表单打开”不是“已编辑”。现有对象的干净表单不阻断切换/关闭；新建表单仅打开自动默认值也不算修改；其初始签名只在内存中记录。实际文本/字段变更、IME组合输入、地图未提交动作、书稿未应用正文仍受保护。离开工程时列出未提交的种类，提供回到草稿、明确丢弃后继续和取消。应用应回到对应表单，使用其现有 core 事务；不提供绕过检查的盲目批量应用。已应用但未落盘的修改仍走原保存/丢弃/取消确认；丢弃表单不等于丢弃已修改工程。

世界观只读浏览不产生未提交草稿。应用成功后更新表单基线；恢复/取消只放弃该表单输入，不改源码。外部刷新后不能用新的源码作为旧草稿的无条件覆盖依据，陈旧表单继续给出定位提示。保存状态同时说明未提交输入，避免“文件已保存”被理解为所有输入已保全。

## 快速命令与对象选择

Ctrl/Cmd+P 打开对象快速切换，Ctrl/Cmd+Shift+P 打开任务命令；↑/↓选择，Enter执行，Escape取消当前面板。Ctrl/Cmd+Shift+F继续全文搜索，Ctrl/Cmd+S保存。输入法组合期间不触发改稿/切换快捷键。对象选择按名称、类型、稳定ID、来源检索，完整身份不因同名合并；POV、正文来源、关系端点、目标跳转和模板ref使用同一选择原则，不能自动填第一个候选。

Alt+Left 返回上一个作者位置。历史只存位置与完整身份，不保存编辑副本或运行历史；已删除的来源提示失效，不跳到同名对象。命令面板仅包含固定作者动作，不执行任意代码。

## 资料结果列

组合查询可显示实体分类、标签和最多六个指定property列。列显隐及次序为个人布局，查询本身和共享定义不变。缺值显示“未设置”，布尔false、数值0和空字符串与缺值不同；对象引用显示完整身份，不转换成普通标量。现有名称/对象类型排序与分页语义保持。新增列不支持属性排序、多字段分组、公式或批量改稿。

## 可读性和键盘

支持暗色、亮色及跟随系统，正文大小12–28点、行距1.0–2.0倍、阅读宽度480–1400逻辑像素。设置作用于作者显示，不改作品。所有关键动作保留可聚焦按钮及文字，不只靠颜色表示选择/错误；低宽度工具换行，保存/退出/恢复布局始终可达。输入法组合事件由回归测试覆盖；原生验收涵盖中文粘贴、键盘、缩放、长标签及取消/导航打断。物理输入法候选窗的平台实测边界见发行说明；Web工作区继续是导入快照。
