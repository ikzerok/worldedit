# Wiki 词条与注释索引

侧栏点击 **Wiki 词条**，使用右侧搜索框按关键词、别名或 ID 查找。现有人物、世界、事件与设定资料会直接进入目录；选择词条即可阅读资料和它在各源码文件中的出现位置。

点击 **＋ 新建词条**，填写关键词、释义和别名（每行一个），点击 **应用词条**，再用 Ctrl+S 保存全部。选中词条后点击 **编辑此对象** 可以修改释义；别名也可在阅读页直接添加或移除。词条与作品一起保存、撤销、刷新和导出，在桌面版与浏览器版共用。表单打开后若工程发生变化，会保留输入并阻止覆盖，请复制需要保留的文字、关闭后重新打开合并。

正文概览、资料阅读、词条释义和试玩文字会自动识别显示名称及别名，无需逐次插入链接。中文相邻词可以连续识别，同一位置优先匹配最长词；ASCII 英文忽略大小写并按完整词匹配。每次重复出现都可点击，同名候选会分别列出。点击打开 **Wiki · 注释索引**，释义中的其他词也可继续点击，用 **← 返回上一词条** 返回。

试玩选项中的词语同样可查阅；点击 **选择** 按钮才会推进故事。显式正文链接优先于自动识别，即使显示文字与另一个对象同名，也会打开作者指定的目标。插值与粘接后的运行文字保留正确的链接位置。

**关键词出现位置** 列出当前全部源码缓冲中的名称、别名和显式链接，点击文件、行、列即可回到原文。索引包括声明、说明、属性、正文和选择，排除源码注释；同一行重复出现分别计数。运行时插值才生成的词可以点击，但不会虚构静态源码出处。源文件和表单输入区继续用于编辑，阅读时使用正文概览或资料阅读页。

独立词条复用作品里的标签说明，已有对象复用原有资料，没有额外数据库：

```wl
tag harbor as "雾港"
  description "终年多雾的港城，林舟的故乡。"
alias tag harbor as "旧港"

character lin as "林舟"
  property background = "出生于雾港。"

event start
  林舟回到雾港，再次望向旧港的灯塔。
  -> END
```

文件名、变量和未声明的正文标签仍可搜索，但不会自动成为关键词。修改独立词条释义或别名不改写正文、不推进故事，也不改变存档指纹。完整匹配与保存契约见同级 worldline 仓库的 `spec/catalog.md` 第 6 节。
