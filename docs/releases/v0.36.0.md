# 0.36.0 条件往返与对象真实状态

本版配套 worldline/core/runtime 0.36.0，在现有事件与选择表单中修改安全条件子集，并从对象旁查一份明确选择的真实运行。默认仍是 Studio；五种布局、十个主题家族与十七套有效明暗配色保留。产品版本不代表 DSL 升级。

## 修改已有条件

事件的前置 `after`、事件及其场景/嵌套选择的显示条件和可选条件，使用同一 core 的有类型投影。支持布尔常量、全局布尔变量、状态包含标签、全局变量与同类型字面量比较，以及有序的 NOT、AND、OR 分组。数值支持大小比较；字符串与布尔只支持等于/不等于。状态和标签选择真实声明，状态同时显示完整所属对象身份。

先改一个叶子或分组，再“预览条件改动”；确认后“应用到事件草稿”，最后应用事件并保存工程。预览不改稿；应用条件只改事件草稿，应用事件才进入工程缓冲，保存才写入磁盘。保存全部不能替代前面的确认。取消条件输入不改工程。高级源码入口仍保留，表单与源码不会在同一字段上默默合并未确认输入。

数值可以连续键入多位数字，再用 Tab 继续填写。首次修改出现的“条件输入待确认”复用顶部固定单行状态区，保持当前输入的焦点与可见位置；主动滚轮离开后，旧焦点不会把视图拉回。“取消全部”取消本事件所有待确认条件输入，保留已应用到事件草稿和工程的内容，完整作用范围可查看按钮提示。输入法会话的普通启停不阻断 Tab；文字组合期间保留输入框，预览、应用与结构操作暂不可用。

表达式由正式 lexer/parser 定位和验证。无变化时保留原字节；只修改现存条件时，不重建无关的正文、去向、once、disabled 说明、本地化标记、头注释或 CRLF。保存后可以重开同一条件继续填写。只读、未知版本、来源过期、外改冲突或不可信身份会阻止结构化写入，作者输入保留供重新核验。

复杂 rule、local、参数、算术、rnd、when 和其它调用保留整段高级源码，不显示可编辑的残缺子树。表达式内部含注释时也进入高级源码，保留中文等非 ASCII 注释及完整原式；需要修改时，在高级源码中明确编辑，再应用事件并保存。片段 fragment 内的选择不在本版条件表单范围。条件树上限为 128 节点、24 层、16 KiB 原文；超限与错误原因明确显示。预览不运行条件，不消耗随机数；AND/OR 保持语言既有急切、从左到右的求值语义。可选条件仍要求显式语言 1.12+，不会自动升级默认 1.9 工程。

详见[条件作者使用说明](https://github.com/ikzerok/worldedit/blob/main/docs/condition-authoring.md)与[core 契约](https://github.com/ikzerok/worldline/blob/main/spec/condition-authoring.md)。

## 从对象查看真实运行状态

从已有对象入口、地图对象链接或条件的所属对象入口打开旁查后，明确选择现有“普通试玩”或“草稿隔离试演”。没有运行时显示空态，不暗中开始故事。对象使用完整 kind/id，状态、显示名和静态声明初值来自该次运行冻结的目录，不与当前已改稿的目录拼接。

只显示该对象拥有的 state，不猜测全局变量或任意属性的归属。同名对象不会混合，一个对象的多个状态分别呈现；合法的无状态对象显示真实空页。当前值、上次记录、首次记录与静态初始声明分开：首次记录可能已经发生动作，并不等于初始化。已有的真实条件证据和声明来源可以返回，缺少、过期、省略或部分运行的情况明确标出。

查询只读，不推进故事、不重置 RNG、不回写属性。运行 stamp 绑定每页结果；推进、重开、换稿或迟到响应不能替换另一次运行的身份。旧页可保留查看，旧来源不能猜测新稿行号。搜索和分页沿用现有 1–100 项、1 MiB 页预算及省略语义，不把第一页当作完整历史。

这不是持久路线库、全历史数据库或任意属性的时间模型。详见[对象状态旁查](https://github.com/ikzerok/worldedit/blob/main/docs/object-state-inspection.md)与[runtime 状态检查契约](https://github.com/ikzerok/worldline/blob/main/spec/state-inspection.md)。

## 作者工作台层级

全局与书稿动作区按真实字体度量收拢：保存与作者状态优先，低频动作进入有名字的菜单。书稿标题与管理动作减少重复占位；窄窗与应用缩放下仍保留可达入口，不靠缩小字体隐藏拥挤。

“输入待应用”和“工程待保存”是独立状态，可以同时出现。状态菜单说明哪些输入未应用、工程是否已保存，以及持续可见的操作失败原因。保存全部只处理已应用工程，不暗中确认条件、书稿或其它作者缓冲。来源往返保留对象/运行/选中状态与原有作者上下文；状态文字不只依赖颜色。

## CLI 与机器接口

`wl condition-authoring query/preview/apply` 与 RPC `condition.authoring.query/preview/apply` 共用 core DTO、投影和事务，协商能力为 `authoring.condition_authoring.v1`。机器事务仅精确修改已经存在的一个表达式槽；新增或移除槽仍走既有表单，避免留下孤立 disabled 说明。CLI apply 默认只改本进程内存，明确 `--save` 才落盘；RPC 保存继续另用 `project.save`。

对象查询扩展现有 `StateInspectionQuery.owner`，能力为 `runtime.object_state_inspection.v1`。协议拒绝不完整身份、重复 JSON 键、未知字段/版本和过大请求；过期、只读或冲突属于领域失败。不能把 `ok:true` 单独当作完整、未省略或可执行的证明。接口细节见[机器协议](https://github.com/ikzerok/worldline/blob/main/spec/agent-protocol.md)。

## 兼容与验证边界

本版不增加 DSL，默认语言 1.9、最高显式语言 1.13 保持。ReplayTrace 与 ReplayCheckpoint 按既有严格 runtime 版本守卫：0.35 及更早记录需要重新录制。普通 Story Save 仍按自身格式、能力和实际语义指纹验证，不因工具版本号一概失效。

桌面外改/未保存冲突保护、现有 replay、受限 SVG 与静态 reader 发布契约保持。浏览器工作区仍是授权导入快照，不宣称持续监视磁盘。发行不附带样例工程或独立演示页面；必要回归测试输入仍可存在于源码包中。

### 0.36.0 开发期本地验证（2026-10-15）

2026-10-15 的 0.36.0 开发期候选默认配置全量回归为 1,560 项通过、0 失败、9 忽略；`eds11_prototype` 配置为 1,576 项通过、0 失败、10 忽略。配套 worldline 工作区为 2,002 项通过、0 失败、13 忽略。原生目标 Clippy、WASM 目标 Clippy 与格式检查均已通过；忽略项不计为通过。

实际桌面操作已覆盖 `after` 数值多位输入、预览、应用、保存与磁盘重载读回，以及带非 ASCII 内部注释的完整高级源码编辑保存。首次输入与后续数字保持完整可见、Tab 正常继续，“取消全部”恢复干净条件输入。对象旁查已验证普通试玩和独立草稿试演的 54 状态分页、无状态对象、完整 kind/id、运行 stamp、冻结目录、静态初值与首次观测的区别，以及只读和旧稿保护。

该次验证未安装物理中文输入法；组合输入保护使用合成 Preedit/Commit 事件验证，普通输入会话启停和键盘路径另有实际桌面操作。真实系统 DPI 切换、浏览器 GUI 与 Windows GUI 尚未验证，不能由应用缩放、WASM 检查或离屏 App 回归推定通过。
