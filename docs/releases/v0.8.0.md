## 完整创作语言与工作区

本版统一交付本轮语言、世界资料与编辑器改进，没有拆成分功能版本：

- 显式语言1.11：参数化纯规则、可暂停并返回的共享片段、state类型化集合、强角色台词
- 正文中心与书稿：同一源缓冲的正文/结构/源码模式、章节直达、分节重组、卡片信息与筛选
- 个人工作区：布局和最近位置恢复、停靠双参考、快速命令与完整对象选择器、可选资料列、字号/行距/宽度与明暗主题
- 安全公开：逐字段白名单、实际页面预览和空内容提示；未选字段、未公开引用目标、演出备注不自动外发
- 修复块内全局声明、跨事件完整scene目标、有符号rnd、关系端点尾项与只读浏览误报未提交草稿

## 兼容注意

默认语言仍为1.9，显式1.10旧作品不自动升级。新增语言只在1.11解释，新存档严格绑定指纹、返回链、类型值及必需能力；未采用新增能力的合法旧作品不无故改变指纹。

负数rnd旧错误行为例外：旧版曾错误钳成0并接受部分非法范围。本版按有限安全整数闭区间计算。已有存档保留实际值与RNG状态，不重算过去；旧错误负数/反向范围轨迹（含动态范围）不保证跨版本重放相同。有效非负固定seed结果与消费序列保持兼容。


块内const纠偏：首次实际初始化后，重入不再计算初始化表达式；若旧稿在此放入rnd，后续重入的随机调用次数因此减少。已保存的值和RNG状态仍原样载入。非负rnd算法本身的固定seed序列保持，不等于旧错误控制流的跨版本轨迹完全等价。


场景目标纠偏：本版使用精确场景路径，不再从无序哈希表随机挑选同名前缀后代。旧短名偶发跳过父场景的行为不保留；既有存档按已保存位置与实际状态继续，不追补过去被跳过的正文或效果。
