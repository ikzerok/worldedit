# Worldedit 0.16.0

本版围绕源码整理、地图虚线和长内容阅读完成同一轮改进。Worldline 提供源码生命周期计划与等价性检查，Worldedit 提供预览、应用和撤销入口；SVG 虚线从导入、编辑到交换与读者地图使用同一份场景数据。

产品版本为 0.16.0。默认语言仍为 1.9，最高既有显式语言仍为 1.13，本版不新增 DSL，也不自动升级作品语言、激活归档源码或迁移旧地图。

## 安全新建和整理源码

修复显式 `source_sets` 工程中新建文件返回成功、入口已添加 include，但新文件未加入 active，随后出现 A105 的问题。现在新建活动 `.wl`、更新 active 与入口 include 在同一内存事务中完成；失败不会留下半条 include、孤立缓冲或清单修改。引用已有归档或非活动源码会明确拒绝，要求作者另行处理其活动身份。

在工程文件树中对非入口 `.wl` 打开菜单，选择“安全移动 / 重命名路径…”，或使用“编辑 → 安全整理当前源码路径…”。输入工作区相对新路径，先“预览完整移动”，审核逐文件、逐处前后内容与资源解析，再“应用完整计划”。应用后打开新路径，全部修改成为一次可撤销操作；编辑器仍须“保存全部”才写入磁盘。

移动仅支持单个已跟踪、非入口的工作区 `.wl`，包括中文、空格和多级目录。活动、归档和其他非活动文件保持原成员身份。core 统一处理正式入站 include/file 引用、被移文件出站 include/asset/file 路径重基、manifest 及已理解的登记展示文档字段。普通正文、注释、description、链接标签和未知可选字段保持原字节；不会用全文替换猜测路径。

移动前与候选均须通过活动编译，并证明语义加载顺序、默认事件入口、对象身份与声明顺序、正式引用、附件解析与原始内容、运行指纹保持等价。只有编译成功还不够。无显式 include 的路径排序变化、file 所属 state 的运行身份变化、批注附着状态无法保持或提案基线无法迁移等情况会整体拒绝。该操作不迁移 Story 存档、检查点或 trace；本轮在保持指纹的正向夹具上实际复用了这些运行资料。

计划绑定当前缓冲、保存基线、目标缺失与资源摘要。改变目标或工程内容后需要重新预览；未应用书稿、表单及替换输入应先处理，不会被自动提交或丢弃。陈旧、外改、篡改、取消、目标碰撞、链接或越界、未知必需能力、无效登记文档、缺失资源和无法证明的迁移均拒绝。入口、目录批量、素材移动与自动合并不在本版范围。

保存复用已有可恢复 journal，不承诺跨文件物理原子写入。若机器接口返回 `applied:true,saved:false` 且错误阶段为 save，内存已应用，磁盘可能已有部分替换；应保留缓冲和恢复日志，通过重新打开或刷新继续恢复，不删除日志或盲目重发旧计划。

## 同一 core 的 CLI 与机器接口

CLI 提供 `wl source-lifecycle preview|apply <workspace> --request-json JSON`，apply 还需使用预览返回的 `--plan-digest`。request 为 create、include 或 move；例如 `{"operation":"move","from":"旧章.wl","to":"章节/新章.wl"}`。机器请求统一使用 `/` 相对路径。

JSON-RPC 提供 `project.source_lifecycle_preview` 与 `project.source_lifecycle_apply`，使用 path 或 project_id 之一、request，应用时带 plan_digest。预览不修改工程；机器 apply 成功后保存。参数形状错误走 JSON-RPC error，合法请求的业务拒绝为 `ok:false` / `SOURCE_LIFECYCLE_REJECTED`。CLI 成功退出 0，业务或保存失败退出 1，用法失败退出 2。

源码整理最多检查 4096 个工作区文件/目录条目和 4096 个已跟踪缓冲，最多 16384 处正式路径。源码缓冲与登记 JSON 缓冲各限 64 MiB；单份资源/磁盘基线各限 64 MiB，去重资源和保存基线总量分别限 256 MiB。超限在继续复制或展开前拒绝，不截断证明。完整字段清单、事务与恢复说明见 `docs/source-lifecycle.md` 和配对 core 的 `spec/source-lifecycle.md`。

## SVG 虚线描边

场景描边支持继承、实线、虚线预设、自定义数组和独立偏移。导入 `stroke-dasharray` / `stroke-dashoffset`、画布、整图与选择 SVG 导出、重新导入以及读者地图使用相同 core 校验和 serializer；不会把虚线拆成持久节点或把曲线改成采样折线。

- 数组最多 64 项，单场景派生虚线工作量最多 100000；隐藏、透明和无 stroke 的节点也计入保守预算，避免重新显示后失去约束
- 每项允许无单位或 px 的有限非负数；偏移可为正负有限数。奇数列表按 SVG 规则逻辑重复；none 覆盖继承为实线；全零数组绘制实线但仍保留作者原数列，混合零项不被过滤
- 数组与偏移独立继承，inline style 优先于 presentation attribute；Affine、viewBox、缩放与 DPI 作用于完整描边，各子路径重新开始相位
- 百分比、其他单位、pathLength、表达式、坏分隔符、负数组项、数值下溢或超预算均明确拒绝。首版不接受 text/tspan 最终有效的非零虚线数组；文字可显式 none 或全零覆盖为实线
- 任意显式 dash 字段，包括 none、全零和偏移 0，都要求地图与 scene 同时声明 `presentation.vector_stroke_dash.v1`。显式编辑会登记能力，普通打开和非虚线编辑不添加；移除最后一项也不自动降级能力

缺少声明或旧客户端不识别必需能力时，只读保留原数据，不能吞掉字段再保存。本轮检查了该兼容契约与旧解析机制，未实际启动 0.15 GUI 打开新虚线地图。错误按可得位置给出节点、字段和 XML 行列；失败保留输入，取消或陈旧计划不提交部分图形。既有脚本、外链、任意 CSS、滤镜、遮罩与嵌套 SVG 等拒绝边界继续生效，不承诺完整 SVG 标准。

## 内容优先的编辑器与读者站

- 地图按照扣除导航、目录和检查器后的实际可用宽度选择紧凑布局。空选择浏览不持续占用空检查器；目录和详情可独立展开，草稿、选择和定位请求保持可达，折叠不改变镜头或清空输入
- 通用实体长表单仅滚动正文、模板和字段，应用、取消及未应用/过期/能力只读状态留在固定操作区，继续使用原有资格检查与草稿保护
- Ctrl+P 与共用对象选择器以名称、类型/稳定 ID 为主，工作区相对来源和行号为次级信息。完整路径仍可搜索、提示和复制，同名对象不合并；普通查找/替换原有相对来源保持不变
- 离线关系图按每条关系独立排列，用 Unicode grapheme 两行摘要与裁切边界约束长标签，完整文字和可点击身份保留在 HTML 等价内容中，继续遵守显式公开白名单
- 修复读者地图中没有 href 的 SVG 定位锚点误拦拖动；真正的导航链接仍抑制拖动。静态世界站继续提供静态分支阅读，不执行 runtime 条件、效果或状态；世界 description 仍是纯字符串

## 实际验证及限制

Linux 完整配对记录为 core 996 通过、3 ignored，普通编辑器 570 通过、4 ignored，原型 585 通过、5 ignored。配置间包含重叠测试，不合计为唯一测试数。格式、600 行限制、普通/原型 native 与 WASM 严格 Clippy 和构建、release 构建、Python 配对 8 项及发行脚本 67 项通过。SVG、2000 对象站点、发布配置前台和源码移动 UI 探针另以 release 显式通过；D5 查询、5000 场景夹具注册/密集场景及原型手动绘制 profile 本轮未执行，不能沿用上一版结果。Windows 最终配对以对应提交的 CI 记录为准。

Windows 已实际执行六项受控文件保护回归：正常读取、持锁时独立兄弟目录 MoveFileW 发布、祖先改名/删除与叶写删保护、既有 junction 拒绝、父检查后真实 junction 重定向拒绝、最终句柄外部路径拒绝。修复目录句柄共享限制引发的 os32，祖先允许 READ/WRITE 共享但继续禁止 DELETE；叶句柄仍仅共享 READ，并在读取内容前核对最终路径。该结果仅覆盖所列测试，不宣称消除了全部文件系统竞态或安全问题。

五个新夹具的 Linux release 记录：1000 SVG 图元预览加应用 45.2–60.1 ms；2000 对象/2000 别名站点预览加生成 366–397 ms。501 源码的实际 egui UI 探针预览 149–165 ms，完整 apply/history/recompile 为 188–198 ms；2000 对象发布配置完整前台提交 191–218 ms，原 250 ms 门未放宽。早期 252/258 ms 超限经同次重验 candidate 复用修正，晚到外改、目标与硬链接身份检查仍保留。以上为特定 Linux release 与温热缓存的 CPU/业务时间，不是 FPS、GPU 呈现或跨机器保证。

本轮 Linux 原生以键盘到达地图、快速切换与实体表单，截图确认虚线曲线、约 708 px 地图内容区、相对来源及固定操作区。绑定坐标点击未产生可确认状态变化，因此未宣称原生鼠标源码移动流程已通过。1040×660 等尺寸与放大字号主要为 egui 帧回归，不等于物理高 DPI 实测。

实际导出包的 40 文件、35 HTML、630 引用闭合及真实 reader.js 的 Node 最小 DOM 检查共 88 项通过；关系 SVG 经 native resvg 渲染检查。这些不能替代真实浏览器排版、file:// 离线阅读、Browser Worker 或下载验收。Windows/macOS GUI、物理 IME、读屏、高 DPI 和真实浏览器未验证。

## 升级与使用建议

先保留完整工程备份，再对需要整理的文件预览移动；不需要整理或虚线的旧作品可继续原有流程。核对全部路径变化、资源证明与拒绝原因，不通过外部强制移动绕过语义检查。引入虚线后使用支持该必需能力的客户端编辑；读者包仍只是显式选择内容的副本，不能替代完整工程备份。

两仓工具必须按 compatibility.json 与发行配对清单使用。开发和测试记录、系统交互与代码模拟分别列示；未执行范围不会因编译或打包成功而变成已验证。
