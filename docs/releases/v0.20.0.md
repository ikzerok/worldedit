# 0.20：真实路线对照与状态动作回源

本版本把「录制路线 → 同稿比较 → 实际 state 动作 → 作者来源 → 返回对照」连成一条工作流。语言 core/runtime、编辑器流程与界面阅读是同一个 0.20 范围；没有新增 DSL，也没有把已有世界资料、关系、地图、时间线或单路径重放重新列为新增功能。

本文记录范围、使用口径、正负验收与性能边界。最终精确配对、主分支 CI 和发行资产以发行包中的 `release-pair.json`、`SHA256SUMS.txt` 为准；本轮逐项执行结果、实际原生交互及环境限制见 [配对验收记录 PR #62](https://github.com/ikzerok/worldedit/pull/62)。文档在工作分支存在不表示版本已发行。

## 三条线共同交付什么

### 语言 core 与 runtime

- 两条真实 trace 在同一份当前冻结 `CompileResult` 上分别重放；临时 Story、随机流和结果互相独立
- 每侧保留入口/checkpoint、seed、完整/部分/分歧/失败/预算/取消状态、实际停止值，以及本段执行和继承覆盖
- 起点及初始观察确实可比时，只比较已验证选择前缀中的首个不同实际选择；按发生顺序识别重复节点和循环
- 瞬态 state 动作证据覆盖替换、加标签、移标签，记录真实顺序、前后标签、既有 state.target 与可核实作者来源；同值写入也是一次动作
- core 核对 AST owner、provenance、动作种类与正式语句头，不通过同名 state、标签值或注释猜来源
- 同一次来源验证按文件复用正式 lexer，批量与单条保持同一权威校验；缓存不跨调用或编译快照
- CLI `wl route-compare` 与 RPC `project.compare_routes` 消费同一 DTO，能力为 `authoring.route_comparison.v1`

不包含全路径求解、通用变量因果解释、任意历史改写后执行或存档跨版本迁移。默认语言仍为 1.9，最高既有显式语言仍为 1.13。

### 编辑器作者流程

「普通试玩 / 路线对照」位于试玩主区。对照复用当前会话的录制路径及 JSON 导入；选择 A/B 后明确比较当前已应用稿。有未应用输入时先核对运行范围，不替作者应用或保存。

结果身份与准备比较的选择器分开。换选择、交换显示、查看或展开不会偷偷重跑，也不会把旧结果改名。选择 state 后查看实际动作、所属世界对象和来源；回源后 Alt+Left 返回同一 A/B、结果、选中项、阅读位置和焦点。

来源导航遵守完整源码/编译选项基线、草稿、冲突、输入组合与工作区边界。即使只是注释移行、runtime fingerprint 不变，也不能把旧行号套在新稿上；需要显式重新比较。比较和回源不改变 live Story、RNG、作者草稿或固定参考。

路径仅属于当前会话。本轮没有新增永久路径库、重启恢复、在线协作、新发布格式、可执行读者站或 CLI 遥控已有编辑器窗口。

### 界面阅读与交互

A/B 身份、逐侧有效性与首差异/不可对齐原因放在主内容区。名称优先、稳定 ID 辅助；作者来源显示工作区相对路径与行。过期结果不借用新稿名称冒充旧资料。

技术信息可以渐进展开，风险、部分结果和证据省略保持可见。状态不只靠颜色。沿用明暗主题与现有阅读设置；长中文名称、ID、路径和值纳入三尺寸两主题布局检查。普通试玩窄屏的既有重放入口保留，切入比较的指针按下/释放帧也不推进排队中的 live 动作。书稿元数据也采用相对来源与行号单行显示，完整路径保留提示；深层中文路径下插入分节、移动章节、应用与源码不变的断言保留。长路径完整回归曾暴露旧测试在折叠展开过程中提前点击的时序假设，验证需等待真实可见且几何稳定的控件，不把动画裁剪误报为持久可访问性故障。

## 怎样理解屏幕上的结果

- 只有 `replayed`、`complete=true` 且 `ended=true` 才称完整结束并验证通过。其他值是实际停止状态，不冒称结局
- 同样访问节点不表示做过同样选择；相同终值也不证明路线等价
- 不同 seed、不同起点、不同 checkpoint 或未验证初始观察会说明不可对齐。首个不同选择不是全部后续结果的唯一因果证明
- checkpoint 继承覆盖不是本段新执行；未访问只表示未测试，不表示不可达
- 超出动作证据边界会明确省略，不能把 omitted 当作没有发生
- state 的所属目标复用语言已有定义；一般变量只比较值，不提供猜测来源

操作细节见 [作者指南](../route-comparison.md)，正式 UI 契约见 [工作台设计](../route-comparison-0.20.md)，运行与机器契约见 [core 规范](https://github.com/ikzerok/worldline/blob/011e6bca42779cb93ad6cf3424a5a4d8b6bada04/spec/route-comparison.md)。

## 兼容与只读边界

新的来源证据只属于瞬态比较结果，不写入 `SaveState`、`ReplayTrace`、checkpoint 或语义观察；choice ID 与 fingerprint 的既有含义不变。

0.19 trace/checkpoint 保留严格 runtime_version 守卫，不能直接用于 0.20 重放/比较，应重新录制，不能手改版本字段。普通 Story Save 继续独立的格式、语言能力与 fingerprint 规则：同源码旧 Save 能恢复的实测样本，不等于所有旧存档或 checkpoint 都获得跨版本兼容。

CLI 从磁盘建立自己的只读工程快照，不恢复未完成保存事务、不迁移权限、不刷新或保存作者文件；遇到未解决事务拒绝且保留文件字节。RPC 使用当前已打开 Project 缓冲，不隐式刷新。它们都不读取另一个编辑器进程内的未应用草稿。

CLI 两侧 `replayed` 时 exit 0，其中可以是明确标注的已录制部分区段；结构化分歧、故事失败、预算或取消为 exit 1；参数、结构、版本错误为 exit 2。RPC 区分协议错误与 `ok:false` 故事结果。

## 正负验收范围

冻结作者样本《盐钟灯船》中，A/B 访问相同四个节点，实际选择却不同：盐钟状态分别鸣响/封存，receipt 分别 0/7。第三条路线与 A 同值但多一次真实同值动作；循环路线保留重复发生顺序。

回归覆盖：逐侧完整/partial/diverged/story_failed、缺初始观察、seed 与 checkpoint 差异、继承覆盖、重复/动态动作、fragment 与 enter/done/exit 顺序、注释移行和合法移源、错误 owner/路径/种类/索引、源稿变化、预算/取消、超大输入/响应、只读事务保护，以及比较前后 Save/trace/RNG 不变。批量来源校验另检查与单项逐项等价、重复次序、截断源稿、调用间变稿不复用缓存及额度拒绝。

编辑器回归包括模式切换、A/B 身份、旧结果提示、来源守卫、草稿与固定参考、真实 egui 指针/键盘事件、Alt+Left、选中项/滚动/焦点恢复和布局。离屏事件与几何测试使用实际产品代码，但不是操作系统鼠标、输入法、读屏或高 DPI 验收。

## 预算与性能

默认值同时是硬上限，可降低，0 不是关闭保护：

- 两侧合计 100000 解释器步、30000ms；WASM 编辑器另保留较低总时间边界和合作式推进
- 每 trace 4MiB、4096 选择输入；比较 DTO 1MiB，CLI/RPC 完整响应最多 1MiB+4096 bytes，包含 envelope、RPC ID 和换行
- 每侧最多 256 动作记录、64KiB；单段证据字符串最多 2048 UTF-8 bytes，超限省略整条记录，不截断可导航身份
- 实际输出两侧合计最多 32768 条、1MiB，在完整语句边界检查
- 源快照最多 4096 文件/64MiB，报告记录最多 16384；批量来源一次最多 514 项/1MiB 请求字符串

零总预算不推进正文，但入口初始化已有的 enter 效果仍可能发生；预先取消不创建 Story。单语句、起点创建、checkpoint 恢复及单文件词法过程不可抢占；不能把合作式时间片说成硬实时保证。CLI/RPC 同步调用没有新增远程任务取消数据库。

### 同样本优化前后实测

Linux x86_64、Rust 1.98.0、真实 debug WASM、Node 24.19.0。使用相同 wrapper、作者 fixture 与原始 trace，50/200 和输出压力分别运行三个独立 Node 进程；同步/合作式/取消结果及语义 DTO 字节逐一相等。

| 负载 | 终次 advance 中位，优化前 | 优化后 | 完整 DTO bytes |
|---|---:|---:|---:|
| 50 state，双侧 100 动作 | 179.24ms | 18.95ms | 42437 |
| 200 state，双侧 400 动作 | 2233.70ms | 34.63ms | 164445 |

200-state 合作式总时间中位从 3206.19ms 降至 984.08ms。终次计时包含 finalization，并非纯词法剖析；主要修复是把同文件约 402 次完整词法扫描收敛为本次批量中的一次。

这不是浏览器帧率承诺：200-state 非终次最大约 28.07ms，600KB 大输出压力的终次约 129ms；Node 进程 peak RSS 最高 89004KiB。保留总预算、取消与明确停止状态，不把 10/16ms 时间片当硬上限，也不把这些单机少量样本外推到任意作品或平台。

## 构建、平台与发行核对

最终门禁按固定 pair 执行两仓源码行数/fmt/test/严格 Clippy/build；editor 普通与 prototype 的 native 和 WASM 配置分别检查。Rust 单文件不超过 600 物理行，研究材料不进入仓库或源码发行包。

真实 Linux 原生键鼠、离屏 egui 事件、真实 WASM/Node、浏览器与 Windows 构建是不同层级的证据。原生会话曾受环境 I/O 和连接替换影响，历史候选与原始证据丢失后以精确远端代码重建并重测；不能把重建记录说成原始文件恢复。实际验证到哪一步、哪些被工具阻断，在配对验收记录中逐项列出。未实测 Windows/macOS GUI、浏览器交互、系统 IME、读屏与高 DPI 的部分，不以 CI 或模拟输入代验。

正式发行应恰有六件资产：Windows ZIP、Web ZIP、editor 源码 ZIP、core 源码 ZIP、`release-pair.json`、`SHA256SUMS.txt`。两个源码包必须与 manifest 的精确 main 配对一致，哈希清单恰好覆盖其余五件；上传后回读、公开前复核及公开后状态确认完成，才称正式发布。
