# worldedit / worldline 0.28.0

本版统一补齐作者依赖上下文、可信试玩审阅、地图往返、汇聚连线可读性与共享片段分析性能。世界设定、语言语义和来源仍由worldline core/runtime统一解释，编辑器消费同一结果。

## 看清规则和变量用在何处

[静态可执行依赖](https://github.com/ikzerok/worldline/blob/main/spec/executable-context.md)区分规则调用、片段调用、全局读取与写入，保留使用语境、重复出现处和真实来源。局部变量、参数及身份引用不冒充全局读取；无效来源、缺源、歧义或预算耗尽明确不完整。静态依赖不表示运行时真的执行过，旧world-context默认投影不变。

## 把真实试玩变成可核对的作者报告

[试玩路径报告](https://github.com/ikzerok/worldedit/blob/main/docs/playthrough-report.md)从当前或已录制路径出发，在当前已应用稿上有界重放，再生成匹配的实际正文、选择、说话者与来源。明确入口或检查点、继承范围、seed、已验证选择次数和完整/部分/分歧/预算状态；未执行分支不写成经历。

复制或保存前必须核对预览并确认私密范围。报告不额外列出变量名/值、任意状态JSON、作者备注、对象资料和附件，不扩大静态读者站的公开授权。正文、选择和相对源码文件名仍可能含私人内容；正文中已经写出的值仍作为正文保留，原始trace与存档需要独立审阅。桌面只保存工作区外的新Markdown文件，拒绝覆盖；Web使用明确下载。陈旧工程基线、迟到任务和外部源码变化不能继续导出旧结果。

窗口打开后交接路线焦点；长预览中的确认、路径、复制、保存和关闭控件随键盘导航滚入可见区域，不代替作者确认或生成。复制、保存与导航不推进当前试玩、随机流或作者稿。

## 地图往返不丢作者位置

[资料、源码与地图返回](https://github.com/ikzerok/worldedit/blob/main/docs/map-author-context.md)保存有效地图身份、选择、镜头和入口。返回前核对当前对象及来源；失效地图明确回退，失效选择不写回旧对象。未提交草稿继续受保护。地图和标记优先显示可读名称，稳定ID用于消歧。

## 汇聚连线保留每一条语义

[时间线执行画布与事件图](https://github.com/ikzerok/worldedit/blob/main/docs/parallel-edges.md)将同端点连接作视觉分组，准确显示原始边数量，并逐条提供完整标签、条件、类型和源码位置。三条选择及各自的显式跃迁仍是六条core记录。长中文换行，详情不被底层节点提示覆盖；支持键盘展开、逐条回源、返回和关闭。时间偏序仍与执行连接分开。

## 共享片段保持有界分析

保守反向摘要跳过确定无Node跃迁的重复片段展开；真实跃迁继续保留每条路径的上下文、来源、顺序和重复数。达到32768次展开或8192条片段来源边时报告A231错误，不能把截断图当作通过。

合成无跃迁DAG反例中，旧版20层一次约1706ms，新版20/24/32层各三次约3–6ms，包含CLI启动、IO、编译和JSON输出。该数据只说明此反例修复，不是通用性能承诺；未触限真实图与旧版oracle逐字段一致。详见[语义与预算](https://github.com/ikzerok/worldline/blob/main/spec/semantics.md)。

## 直接开始原创演练

[蓝时水库](https://github.com/ikzerok/worldline/tree/main/examples/blue-hour-reservoir)提供两条真实路线、规则链接、两张地图和逐步操作说明，按仓库MIT许可证提供，无外部素材。

## 兼容与验证边界

本版工具版本0.28.0，不新增DSL，默认语言1.9、最高显式1.13保持。实际0.27普通暂停Story Save在同源码0.28继续成功；0.27 ReplayTrace/ReplayCheckpoint仍按既有runtime_version守卫拒绝重放、对照或报告，应重新录制。该样本不代表所有历史存档兼容。

Linux完整测试：core 1455通过、0失败、8忽略；editor默认877通过、0失败、7忽略；prototype 892通过、0失败、8忽略。fmt、严格clippy、默认/prototype原生与WASM release构建均通过；两套WASM在Node24完成模块校验、编译、初始化和非法worker请求拒绝。CLI/RPC另有89项明确断言通过；配置与专项覆盖有重叠，不相加宣称独立用例总数。

Linux原生实际验证了规则使用处回源、两地图与资料/源码往返、缺失地图回退、全部分组边回源/返回、长中文与条件可读、过期来源禁用、完整/部分报告、显式私密确认、新Markdown保存和陈旧导出拒绝。复制操作有实际成功反馈，系统剪贴板字节未独立读取。作者源码字节及当前试玩保持不变，外部变更后的旧快照有明确提示。

Node/WASM模块验证不等于浏览器GUI或Web Worker宿主；Linux合成键盘/指针验收不等于物理IME、读屏、Windows/macOS原生交互或高DPI测试。Windows官方CI覆盖精确提交的构建、测试和lint；打包工作流另运行已打包CLI烟测，不据此宣称Windows GUI已验证。
