# 0.36.1 桌面启动与应用身份修复

本版修复没有现成作品时的桌面入口、Windows 可执行文件图标和启动终端闪窗，并校正两仓现行文档。worldedit 版本为 0.36.1，配对 worldline/core/runtime 保持 0.36.0；精确配对提交由 compatibility.json 与发行清单记录。

版本与附件以[项目版本页面](https://github.com/ikzerok/worldedit/releases)中对应版本及实际附件为准。

## 无需现成作品即可启动

无参数启动时恢复有效最近工程；首次使用、没有最近工程或最近路径失效时进入“欢迎使用 worldedit”。欢迎页可新建、打开、调整外观或退出，不先要求作者提供作品，也不自动写入演示工程。

“新建作品”使用应用内路径确认，可填尚不存在的新文件夹完整路径，也可选择已有空目录；只有点“创建作品”才调用 core 空白工程及保存流程。新作品仅含空白 world.wl，不预填人物、正文、地图或书稿。非空或不可写目标明确报错，保留输入，可改路径重试。

“打开工程”只读取已有作品。空目录、无效路径或访问失败保留错误与入口，不隐式新建。取消应用内窗口返回欢迎页或原工程；取消系统选择器不确认打开或创建。已有工程的未保存修改与未应用输入继续受保护。

显式命令行路径仍优先于最近工程，支持作品目录和根入口 .wl 文件；路径失败进入可恢复欢迎页。完整操作见[桌面启动与新建作品](https://github.com/ikzerok/worldedit/blob/main/docs/desktop-startup.md)和[工作区说明](https://github.com/ikzerok/worldedit/blob/main/docs/workspace.md)。

## Windows 应用图标与无终端启动

worldedit.exe 嵌入仓库既有 ICO 的七种尺寸资源，窗口继续使用同源 PNG。Windows 应用使用 GUI 子系统，正常启动不创建终端；wl.exe 与 wl-agent.exe 仍保留控制台行为。

工程错误在应用内可见；窗口启动失败与不可恢复异常通过系统错误提示和本机诊断日志报告，不依赖隐藏的终端。日志位置和分享前的隐私检查见[启动故障说明](https://github.com/ikzerok/worldedit/blob/main/docs/desktop-startup.md)。本版没有重画图标或新增图标生成素材；资产来源见[图标说明](https://github.com/ikzerok/worldedit/blob/main/assets/README.md)。

- Windows 包内文档按实际目录重映射链接，补齐变更记录和图标说明；未分发的源码及历史材料明确转为需要联网的固定提交链接，源码归档字节保持
- 0.36.0 的仓库版本说明校正为已发行状态；原测试数字与日期作为历史记录保留，不计作 0.36.1 的通过结果。GitHub 既有 Release 正文是独立副本，不会随仓库文档修订自动变化
- Studio 默认、五种布局、十个主题家族和十七套有效明暗配色保持；默认 DSL 1.9、最高显式 DSL 1.13 保持，不自动升级作品
- core/runtime 仍为 0.36.0；0.36.0 的 ReplayTrace 与 ReplayCheckpoint 不因编辑器补丁号失效，但仍须通过原有版本、指纹及身份校验。0.35 及更早记录继续受既有 runtime_version 守卫约束，应重新录制；普通 Story Save 按自身格式、能力及实际指纹验证
- Windows、Web 和双仓源码发行归档继续排除独立样例工程、规范演示和视觉演示页面；必要源码测试输入与产品字段模板保留

## 验证与平台边界

2026-10-15 本地验证记录：

- core 全量测试 2002 通过、13 ignored；editor 默认测试 1579 通过、9 ignored
- Linux 真实桌面已核对无参数欢迎页、新建与打开的取消、无效路径、真实不可写目录的 PermissionDenied、创建空白作品、保存和重新打开

CI 配对门禁覆盖 core 与 editor 默认测试、可选 eds11_prototype 测试、native/WASM 构建与严格 Clippy，并检查 Windows PE 子系统及七尺寸图标。通过结论以对应完整提交的实际 CI 记录为准，不从本地默认测试推定其他配置通过。

Windows 真实桌面尚未实测，须单独验收；Linux 桌面、离屏 egui、PE 静态检查和 WASM 编译均不能替代 Windows GUI 结果。历史测试数字也不计入本版通过记录。

发行验收按[配对检查](https://github.com/ikzerok/worldedit/blob/main/docs/paired-ci.md)和[发行流程](https://github.com/ikzerok/worldedit/blob/main/docs/release.md)核对精确提交、实际附件、release-pair.json 与 SHA256SUMS.txt。当前修复不承诺物理 IME、读屏、高 DPI、多平台安装器或签名认证。
