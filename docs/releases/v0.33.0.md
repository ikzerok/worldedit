# 0.33.0：译文制作、真实体验与正文资料关联

本说明对应 worldedit 0.33.0 及配对的 worldline/core/runtime 0.33.0。默认语言 1.9、最高既有版本 1.13 保持；不新增 DSL，不自动升级作品。发行身份、配对提交与附件以本版本 Release 和 release-pair.json 的实际记录为准。

## 译文制作与状态巡检

本地化从手写 ID 列表与整段 JSON，扩展为稳定目录、真实状态和源译内容编辑。作者可以发现缺 ID、重复 ID、缺译、过期、无效 token 及孤立译文，按来源、类型、文字和状态筛选有界页；总数和状态均来自 core。

显式设置稳定 ID 后，可编辑文字片段和链接标签、移动完整受保护 token。预览列出明确选择和受影响文件，应用只进入工程内存，一次撤销/重做，保存另行完成。桌面与 Web 采用同一候选规则；旧原生 CLI import apply 保持立即持久化。目录与交换预览在后台运行，可取消且迟到结果不能覆盖新查询或新工程。

[译文工作台操作与保护](https://github.com/ikzerok/worldedit/blob/v0.33.0/docs/localization-workbench.md)

## 同一运行时的真实译文

普通试玩和隔离草稿试演可选择经过校验的目标语言。正文、say 与选项标签显示真实译文；源译对照使用同一次源顺序求值的结果，重排占位不重排随机求值，也不改选择身份和状态规则。

严格策略在缺译或过期时拒绝开始；作者明确允许源文回退后，每项保留其真实原因。当前语言、旧快照和未覆盖字段清楚可见，输出可返回准确源文或译文条目修正，再明确重新开始。

保存、检查点、回放、路线比较与试玩报告绑定独立的 locale 内容身份。改变译文不能悄悄继续旧观察；源文默认入口保持旧行为。人物名、演出备注、禁用理由及动作日志仍使用源文，不宣称全部玩家可见字段都已翻译。

[core/runtime 接入与兼容](https://github.com/ikzerok/worldline/blob/8ed767c53687e0cd603a31c40062e3d5b6201aed/docs/localization-workbench.md)

## 正文中关联和创建资料

书稿正文选词后可以检索已有世界对象、明确插入稳定引用，旁查后返回原章和光标。新建正式人物或已有通用实体类型时，core 的复合计划列出资料声明、正文链接及纳入的完整草稿，确认后一次应用和撤销；其他未应用稿不会被偷偷提交。

正式人物与通用实体身份保持不同。旧 1.9 作品新建 entity 时必须显式预览启用 1.10，核对迁移影响，清单与正文在同一个复合候选中应用；取消不会先升级作品。

[书稿正文资料关联与事务](https://github.com/ikzerok/worldedit/blob/v0.33.0/docs/manuscript-workspace.md)

## 外观与兼容

- 保留 Studio 默认、五种布局、十个配色家族与十七个明暗成员；新列表、源译内容和局部关联面板使用现有主题语义
- 未提交输入在取消、切换查询、回源和再次打开时保留；来源、语言和应用范围分别可辨认
- Unicode 数据保存与视觉排版分别验证。当前 egui 文本界面不完整支持阿拉伯连字塑形及 RTL 双向视觉顺序；阿拉伯语、希伯来语可保留原字节并交换，但不能把编辑框和试玩显示当作正确排版。本轮 Linux 原生已观察到该视觉限制；未替换文本排版引擎，也不宣称全语言视觉完善
- 新工程仍为空白，Windows/Web/双仓源码发行包继续不含样例工程或 demo HTML
- 静态世界站的显式选择与公开权限不变；本版不提供独立可玩作品包，不自动公开未选资料、作者笔记或叙事分支
- 0.32 及更早 ReplayTrace/ReplayCheckpoint 按原 runtime_version 守卫处理，应重新录制；普通源文 Story Save 继续按格式、能力和指纹独立校验。locale 持久物还须匹配展示身份
- 修正 include 展开后的真实来源：正文、say、choice 及相对文件链接按 parser 记录的实际文件定位。旧版本导出的交换包中，若单元实际来源不同于其 event/fragment 声明文件，旧包可能记录错误文件或修订；0.33 会拒绝不匹配导入并提示“重新导出交换包”，保留原工程和原包，不自动改写到另一文件。请保留旧包，重新导出后按稳定 ID 核对迁移译文，再预览导入；未受此来源问题影响的旧包继续按原校验与保存方式使用

## 实际界面验证边界

- 本次 Linux 验收环境缺少可用的 xdg-desktop-portal 与 zenity 文件对话框后端，未完成「新建」中的文件夹选择器入口验收；本版保持既有选择器语义。空白启动与 core/CLI 空工程验证分别记录，不作为该 GUI 入口通过的证据
- 本次浏览器宿主在 WebGL 初始化阶段失败，未完成真实浏览器 GUI 验收。Node/WASM 协议与运行测试不替代浏览器宿主、输入和界面验证
- 物理操作系统 IME、Windows/macOS GUI 与未实际执行的平台不记为通过；合成输入、headless 和 Windows CI 不能代替真实设备交互。阿拉伯连字塑形及 RTL 双向视觉顺序的限制见上节
