# worldedit 0.15.0

本版扩展可编辑矢量地图、完整静态世界站和统一作者工作台。Worldline 拥有几何、出版选择和事务语义，worldedit、CLI 与机器接口使用同一核心；产品版本与语言版本独立，默认语言仍为 1.9，最高显式支持 1.13，本版没有新增 DSL。

## 地图与 SVG

- 原生 scene 保存直线、二次/三次贝塞尔、圆弧、多子路径、文字、组、顺序与仿射变换。曲线渲染采样不会回写替换控制点
- 画布直接绘制、节点/控制柄编辑、点击/Shift 多选/框选、复制、成组/拆组、移层、排序、显隐和锁定；提交后保留有效选中与镜头。可绑定既有资料，或预览后一次创建地点并绑定
- SVG 先预检再确认，支持常用基本图形、组、路径命令、纯文本/basic tspan、受控样式、viewBox 与 meet/none/slice。根 viewport 的 typed 矩形裁剪可持久化并安全往返
- 脚本、事件、DTD/实体声明、外链/href、foreignObject、任意 CSS、filter、mask、动画、未知元素/属性及 nested svg 整批拒绝；仅开放严格定义的根 viewport 矩形交换，不支持任意 clipPath 或完整 SVG/CSS 标准
- 全图与当前选择可导出安全矢量 SVG。作者选择组会明确展开隐藏后代，须先核对范围；底图、源码和完整附件仍由完整工程备份保存

入口及完整边界见 `docs/vector-authoring-0.15.md`。SVG 源码输入已验证；系统文件选择器的实测边界见下文。

## 静态世界站

- “导出与发布 → 发布给读者”采用选择内容、核对资源、预览页面、确认生成四步。长列表可搜索、分页、选择全部匹配结果，操作底栏保持可达
- v3 生成首页、类型目录、资料详情、时间结构、关系目录/局部图、书稿/章节、地图和静态故事；搜索覆盖公开名称、别名、正文和授权字段，包含类型过滤与摘录，地图保留公开锚点和包内导航
- 选中对象授权其 display、全部别名及允许的类型结构；property 逐键、地图节点/底图、章节和附件分别授权。选组不自动公开后代，正文、关系和反链不扩大公开范围
- 静态条件/效果说明需额外明确选择。站点不执行条件、效果、状态或存档，不是可玩的网页故事 runtime；私有端点和不能安全投影的说明会隐藏
- 发布 profile 保存选择、章节顺序和稳定路由，可预览、撤销和显式迁移；失效选择不静默裁掉，未知能力不降级。应用配置进入内存，保存全部才写盘
- 取消/关闭保留同一工作区的输入，清除旧审核与确认；内容或选择变化须重新审核。桌面写工作区外的新 ZIP，已有目标永不覆盖；原子提交点后等待真实结果，不把已成功交付误报为取消。Web 实现同源 Worker 复核和下载请求，其真实浏览器执行仍未验

阅读包是所选内容的静态副本，持有人可读取包内全部内容，没有在线账号权限，也不能替代完整工程备份。使用与授权细节见 `docs/reader-publishing.md`、`docs/reader-publishing-0.15.md`。

## 共同界面与后台任务

主导航、集合索引、正文/画布、当前选择检查器、参考和诊断采用一致角色；人物、资料、Wiki、网络、地图和书稿保留各自内容形式。明暗/系统主题共用字体、间距与表面层级；保存全部和试玩可直接访问，技术身份与来源逐步展开，完整值仍可查看/复制。长检查器、窄书稿及发布底栏分区滚动，不隐藏未应用稿或取消入口。

SVG、预检、绑定、渲染、配置规划和导出在后台执行，结果按任务代次、内容基线、修订和类型重验。场景渲染最多两个实际活动任务，容量不足明确提示，不静默丢层或降 DPI。窗口关闭、取消、完成排队和输出提交竞态均有自动回归。

## 语言核心与兼容

- 地图 `schema_version` 仍为 1，scene 由 `presentation.vector_scene.v1` 显式启用。旧 placements、底图、文字、测距/校准、导航、预设和批注继续保留，打开旧工程不自动迁移
- 旧标记迁移保留 ID、引用、批注、样式与未知可选字段，仅接受可保原叠放的整层或连续后缀。不能保持顺序/样式，或拆组/移层会破坏合成边界时明确拒绝
- 场景批次按核心预览和应用形成一次内存事务；陈旧、冲突、锁定、非法或取消不提交半个候选。新增 `wl scene svg-preview/preview/apply/export` 与对应 RPC，能力发现为 `authoring.vector_scene.v1`
- 读者 v1/v2 保持原语义；v3 使用 `reader.world_site.v1`，旧配置升级先确认新增别名和类型结构授权。`reader.story_details.v1`、字段与附件不被自动加入
- 未知必需能力/格式只读保留原字节。几何和出版配置不代替语言版本升级或运行身份迁移；故事存档与调试重放继续执行原有能力、指纹及 runtime/schema 校验

建议升级前保留完整工程备份，在副本中先预览迁移与公开选择。编辑器普通应用不自动保存；CLI/RPC 的持久化规则见配对 worldline `spec/scene-protocol.md`。

## 资源与实际验证

单次 SVG 最多 2 MiB、1000 图元；每图 scene 最多 5000 节点、32 层级。v3 公开对象最多 2000，旧 v1/v2 仍为 500；静态站最多 10000 文件、128 MiB 原始内容，编辑器 ZIP 另有 128 MiB 预算。scene 缓冲/纹理预算为桌面 128 MiB、Web 64 MiB，内部合成另受限，这不是整个进程 RSS 上限。准确数值单源见配对 worldline `spec/presentation.md`。

本轮重建源码的 Linux 普通测试 core 925、editor 552、可选 prototype 567 通过；对应 Windows 源码配对 core 925、editor 553、prototype 568 通过。core/default 各 3 ignored、prototype 4 ignored 均不计入普通通过数，相关手动 fixture/profile 已另行显式执行。平台和配置用例重复，不能相加成唯一总数。fmt、源码行数、native/WASM 严格 Clippy、native 与 Web 构建分别核对，最终配对及 CI 以 `release-pair.json` 为准。

Linux 1188×848、1× 的实际功能会话为 21 分 03 秒，之后的 tooltip、跨平台 binding 微修及不同二进制局部验证分开记录。真实单层 5000 节点平移三组 CPU P95 为 12.395/12.188/12.625 ms；它不含 GPU/present/vsync，不能换算 FPS。固定 release 负载中，1000 SVG 为 44.884–60.715 ms、2000 对象无地图/媒体站点为 344–394 ms。profile 曾出现 269 ms 超限，等价优化后十次完整前台提交为 192–239 ms。共享机器、新 fixture 不等于 OS 冷启动，无跨硬件性能保证。

### 允许环境内的模拟验证

- 实际生成的完整读者 ZIP 经静态核对：29 个 HTML 页面从首页全部可达，480 个本地引用（含 22 个片段）存在，35 项 manifest 资源长度与 FNV 校验一致，没有外部引用。真实 `reader.js` / `search-data.js` 在 Node VM 与最小 DOM 模型中完成 45 个场景、191 个搜索断言；34 条记录均可查，覆盖正文、别名、13 类筛选、中英文大小写、空白/空结果和重复输入。另有 651 项静态检查，合计 842 项模拟/静态断言，不混入 Rust 测试数
- Worker 补充验证共 15 项分层检查：11 项执行未改写的 `worker.mjs` 与生成 JS/WASM，2 项执行 Node 线程 terminate，1 项为下述 54 变体源码投影，1 项核对既有 10 个 Rust 回归。真实脚本/WASM 检查覆盖预览/渲染、17 条进度、320000 字节 RGBA、transferable 分离，以及不安全 SVG、坏 JSON、跨源资源、schema/generation、越界/重复文件和错误工程基线拒绝。两项 terminate 分别位于初始化暂停点及真实 `svg_parse` 进度点，退出且无 done；不等于 Rust host 取消清队列或浏览器 terminate
- 主端身份检查只做按 Rust 源码锚定的投影模拟，54 个 job_id/generation/baseline 变体被拒绝；没有将它记成执行了 Rust receive。本次只核对既有 10 个相关 Rust 回归，没有额外执行 Cargo；其原运行证据单独保留
- SVG 文件输入直接编译使用实际 `svg_import_job.rs`，仅把系统选择器返回替换为指定路径或 None，后续真实后台线程、文件 IO、UTF-8/大小校验和 core 预检均执行。有效文件、空选择、不存在路径、目录读取错误、无效 UTF-8、超过 2 MiB、恰好上限、安全拒绝及畸形输入共 9 个分支通过；不安全/畸形 SVG 的原始源码保留已检查，None/IO 错误验证错误返回；该模拟没有执行完整 UI，也不证明每种读取错误下的 UI 旧输入均已保留。这不是系统对话框或 portal 成功证据

上述是纯代码、静态内容和抽象 IO 分支验证；未使用另一通道绕过已拒绝的浏览器访问。

### 未验范围

实际 `file://` 被工具安全策略拒绝，正常 HTTP 返回 `ERR_BLOCKED_BY_CLIENT`；没有绕过限制。真实网页布局、离线搜索/链接/地图/音频/断网，以及 Browser Worker 执行、取消和下载未验。静态资源审计、Node WASM、DOM 或 worker 模拟不能替代这些真实浏览器结论。

Linux 系统 SVG 文件选择器点击后未出现对话框并返回空选择，成功路径未验；源码输入、直接指定 ZIP 路径或 picker 抽象测试不替代它。Windows/macOS GUI、物理 IME、读屏与物理高 DPI 未验。准确测试命令、机器、固定 fixture、产物身份和适用范围见两仓 `docs/verification-0.15.md` 及本版独立完整更新日志。

## 下载与配对

Windows、Web 和两仓源码快照的精确提交及 CI 见发行附件 `release-pair.json`，下载后核对 `SHA256SUMS.txt`。Windows 为未签名 x64 便携 ZIP；Web 编辑器包需静态 HTTP 服务，与作者导出的静态读者站是不同输出。发行未提供 macOS/Linux 安装器，不把构建检查表述为这些平台的原生交互验收。
