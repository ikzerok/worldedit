# Worldline 与 Worldedit 0.17.0

本轮完善大型作品的安全源码整理、世界对象上下文与时间偏序解释，并提供对应的人物焦点工作台。语言与分析只在 core 实现，编辑器、CLI 和机器接口消费同一合同。产品版本为 0.17.0，默认语言仍为 1.9，最高既有显式语言为 1.13；没有新增 DSL。

本说明记录 0.17.0 的交付范围与验证边界。最终固定配对、合并后 CI 与公开发行状态分别由对应提交、CI 与发行记录确认；工作分支保存不代表已发布。

## 升级前先看重放边界

- 原 0.16 trace 直接交给 0.17 会被既有 runtime_version 守卫拒绝；实际 CLI 退出 2。不支持直接跨版本 trace 重放，请保留原工具用于原记录，或在 0.17 重新录制，不要修改版本字段绕过保护
- 原 0.16 普通 Story save 在本轮同源码 fixture 中成功加载，state 逐字段一致；该结果不保证所有旧作品，也不等于跨版本 checkpoint 验收
- 跨版本 checkpoint 本轮未独立实测。同一 0.17 中，合法源码移动、保存和重开后的入口 trace、checkpoint-origin trace 与普通 save 均已独立验证
- 升级前保留完整工程和原运行记录。旧作品不因打开而自动启用新语法或改变已保存的语言版本

## 确定性安全源码整理

修复同一稿件安全移动时，引用目录的无序枚举导致预览或应用随机误拒绝的问题。现在仅规范语义无序引用的比较次序，仍保留重复出现、真实来源、引用目标和属性；语句、选项、效果、加载顺序及默认入口等有序语义不会被排序抹平。

沿用“安全整理当前源码路径”：选择单个已跟踪、非入口 .wl，输入新路径，预览完整计划，再整体应用。修改路径或稿件后重新预览；应用为一次内存事务，可撤销/重做，保存沿既有可恢复 journal，不保证跨文件物理原子。

失败回执按 SourceChanged、IllegalPath、SemanticChange、UnableToProve 区分源码变化、路径非法、语义变化和无法证明，并显示可执行建议及原技术详情。不以重试按钮掩盖不稳定结果，不弱化入口、越界、外改、目标碰撞或语义等价守卫。应用和保存状态明确区分。

## 世界对象焦点上下文

新增只读 schema 1 投影与精确对象查找。按完整 TargetRef 识别对象，分别列出正式关系、旧式人物关系、属性强引用、事件参与、正文显式链接及可选文字提及；提及默认关闭，不能作为正式事实或自动升格为关系。

记录保留原始端点、方向、类型、角色、typed provenance、正式关系 scope_refs 及真实来源；平行边与多次出现不合并。反向浏览不会复制新关系；缺失端点标 exists:false，不按显示名猜替代身份。行级来源只保证真实行，不伪造精确字节范围。非正式关系的 occurrence ID 只在当前快照内稳定，不能用作持久关系 ID。

投影支持入向、出向或双向，一至两跳。max_nodes 默认/最大 250，max_records 默认/最大 500；max_candidates 默认 10000、最大 100000。精确 ID 查找独立于广域目录候选上限，广域保护保持。结果提供 total、returned、complete、truncated、reasons；候选预算耗尽时 total=null，不能把有界部分显示为完整审计。

snapshot 绑定源码、编译上下文及加载序列；content_baseline 绑定作者内容，两者不是保存授权或磁盘永久最新证明。编译错误标 invalid_source；已知外改冲突保留缓冲内容并标 source_conflict、complete=false，冲突本身不等于范围截断。无法核对冲突返回 SOURCE_UNAVAILABLE，不静默声明无冲突。取消检查覆盖投影轮次及记录收集，既有编译与可选关键词索引阶段不可抢占。

CLI 为 `wl world-object DIR --target KIND:ID --json`、`wl world-context DIR --target KIND:ID [--options-json '<OPTIONS>'] --json`；RPC 为 world.object、world.context。通过 authoring.world_context.v1 发现能力，协议仍为 1。旧 query_relations 仍只表示独立正式关系。

## 时间先后解释与环见证

比较两个事件时，core 区分 before、after、same_event、unordered_same_root、different_roots、invalid、unknown。同根无约束不等于同时，独立根不推断日历先后；1.9–1.12 不因新查询放宽不同直接时段的旧比较范围。at UINT 仍是原有数字序号，不解释为日期。

before/after 返回实际 follows 边构成的最短证据链，同长路径采用稳定字典序规则；不从 rank、画布坐标或声明次序创造先后。真正强连通环与被环阻断的下游分开显示，见证给出可回源码的真实闭环。它证明该分量存在环，不保证遍历分量内全部成员或枚举所有环。

保留 A213 错误码、原诊断数量和 partial 保护。任一编译错误下比较保持 invalid，不以局部看似正常绕过完整性；修复并重新编译后旧证据失效。存在未决外改或恢复冲突时，机器比较返回 CONFLICT、comparison:null；不覆盖任何一侧。

CLI 为 `wl timeline compare DIR --left ID --right ID [--expected-baseline BASELINE] --json`；RPC 为 temporal.compare，通过 authoring.temporal_explanations.v1 发现。旧基线返回 STALE_BASELINE。Timeline 新增 cycles、blocked 等加法字段，消费者按既有约定忽略未知响应字段。

## 人物焦点工作台与问题定位

人物入口保留索引、档案和旧关系创建，默认展示当前人物的一跳局部图与同源分类列表。提供定位所选、适配当前结果、缩放、平移与恢复局部布局；全人物旧关系图以最多 250 节点分页说明范围，当前身份保持。

图与列表区分引用类型、平行边、限定范围和完整性；来源点击复用作者导航与返回历史。只读上下文边没有会误写成旧人物关系的统一建边操作。筛选、相机与布局属于个人临时状态，不写世界语义。

局部图按实际宽高比布局与适配，当前卡片保底可读，标签避开卡片；自动适配随可用空间调整，手动平移、缩放或拖点后保留人工视角。辅助档案按需展开，空选择不占空列；窄窗主要动作仍可达。

时间问题区优先显示真环、受阻事件与 follows 来源，并用名称优先的 picker 选择比较对象，可选直接 ID 输入。逐字符未知前缀保持焦点；证据体随剩余高度滚动，关闭动作固定。Tab 焦点自动滚入证据区域，Enter 可导航真实来源；受视口压缩的窗口在空间恢复时恢复高度，主动缩小保持。

F6 / Shift+F6 在人物索引、图与结果、档案间切换，Escape 关闭本轮新增最上层临时区并返回。上层搜索、设置或保护确认与 IME 组合事件有守卫。导航继续保留未应用稿件，不因布局优化自动提交或清空。
