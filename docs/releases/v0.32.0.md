# 0.32.0：把当前稿安全带过完整作者流程

本说明对应产品版本0.32.0；公开发行状态以本版本 GitHub Release 及其附件为准。默认语言1.9、最高既有显式版本1.13，不新增DSL，不自动升级作品，也不新增作品持久schema。

本版连接四件创作中的连续工作：处理外部改稿、试演未应用正文、按同一书稿范围审稿交付，以及把同一资料查询带到地图和正式关系中巡检。

## 普通外改：看清三方，明确采纳，再保存

保存基线、本地已应用缓冲和本次捕获的磁盘文件分别保留完整身份、原始字节和缺失状态。逐文件明确选择一侧、删除或手工全文；没有默认获胜侧。core重验完整候选和工程问题，未解决项不能采纳。

采纳只改变工程内存，留下本次撤销；保存是另一个明确动作，并再次检查外改。关闭或Escape保留手工材料，未应用正文及表单阻止采纳。纯源码错误可明确保留为不可运行的未完成稿；未知能力、坏原始字节、只读目标及未解决保存事务仍会阻断。

此入口处理已跟踪源码和已注册JSON的普通冲突，不接管附件，也不代替事务恢复。浏览器只核验导入快照，不持续监视磁盘。

[外部改稿的完整操作与保护边界](https://github.com/ikzerok/worldedit/blob/v0.32.0/docs/workspace-reconciliation.md)

## 未应用正文：先用独立快照真实试演

从书稿或试玩页选择「试演当前正文草稿…」，明确核对全部已改变的正文文件草稿、代次和未纳入表单后开始。每个源文件只有一份正文缓冲，至少需要一份真实改变的活动源草稿；试演遵守作品原有入口，不从任意章节跳过初始化。

正文、选择、条件和状态来自这份草稿的真实独立执行。暂停与继续保留同一快照，修改后旧证据只读保留，继续选择和回源须重新试演。有可确认且仍一致的作者位置时，可以返回原草稿的章节、模式、选区和滚动；不能确认时说明原因，不按相似位置猜测。

普通试玩与作者保存状态保持独立。草稿模式不提供正式存档、轨迹或检查点导出；需要正式记录时，先明确应用正文，再开启新的普通试玩。普通书稿从既有管理动作行的「试演」菜单进入，紧凑布局使用「书稿工具」；试演内的「试演操作」提供重新试演、切回已应用稿和关闭入口。

[草稿试演的完整操作、预算与平台边界](https://github.com/ikzerok/worldedit/blob/v0.32.0/docs/draft-rehearsal.md)

## 同一书稿筛选：连续全分支审稿与作者Markdown

单书稿现有文字、状态、POV及分节筛选贯穿全部匹配章、连续审阅和Markdown交付；导航页和折叠状态不会缩小范围。重复编排逐次保留，缺源和坏章显示错误占位，不跳过后续章节。

条件分支、各选择、台词、动态文字和未展开调用按静态源码保留；不求值、不执行，不把编排读序当成真实路线。明确生成后可回到准确原文。仅打开原文查看再返回仍保持材料有效；真实修改使旧材料过期，来源、复制和导出停用；同一旧材料仍在时可返回其原批次与滚动，重新生成须明确操作。

完整Markdown原文、复制和导出使用同一个core字符串。材料标为作者私密，不扩大读者发布白名单，不附带源文件全文、隐藏JSON、批注、运行值或附件。完整性不足或超过预算时拒绝交付；零命中会明确说明零章。

桌面只导出到工作区外的全新.md文件，已有文件不会覆盖。浏览器只报告已请求下载，不能确认已经落盘。首版交付格式为Markdown。

[同范围审稿、原文返回与Markdown交付](https://github.com/ikzerok/worldedit/blob/v0.32.0/docs/manuscript-delivery.md)

## 同一资料查询：地图位置与正式关系巡检

同一份完整查询快照连接对象、逐处地图绑定、一至两层正式关系和真实来源。一个对象在多图、多标记或矢量图元中的位置逐处保留；明确区分命中、仅关系上下文、未解析端点和无已知位置。普通文字提及与装饰线段不会生成正式关系，上下文也不增加查询命中数。

地图画布最多标注当前地图前500处匹配绑定，全部命中及绑定仍可分页检查。巡检不改坐标、默认显隐、锁定或公开选择；隐藏和只读位置继续遵守现有保护。改稿和真实外部刷新使旧范围失效，显式刷新后显示新范围，不混用旧位置与新内容。

小窗口通过「范围操作」返回同一查询、返回巡检位置、刷新或清除；地图工具在「地图操作」，关系页可切换「关系图／范围列表／关系上下文」，通过独立可滚动的「关系操作」页调整层数、方向和分页，「完整网络检查器」另开一页，两页均可返回关系图。清除恢复进入前的个人视图；身份已经变化时说明不能恢复的部分，不猜同名替身。临时范围不写入新集合文件。

[查询范围的完整操作、数量与预算](https://github.com/ikzerok/worldedit/blob/v0.32.0/docs/catalog-scope.md)

## 协议、升级与外观

CLI/RPC共用core/runtime，新增能力标识 `authoring.workspace_reconciliation.v1`、`authoring.draft_rehearsal.v1`、`authoring.manuscript_delivery.v1` 和 `catalog.scope.v1`；协议版本仍为1。请求、结果及完整编码行各有预算。一次性CLI的内存采纳不表示保存，使用project_id的RPC资料范围查询只读取已打开会话的已应用快照，外改须另行明确刷新。

runtime0.32继续精确检查运行版本：0.31及更早的ReplayTrace和ReplayCheckpoint不能在0.32重放、比较或生成已验证审阅，应重新录制。合法旧轨迹可只读查看，读取成功不代表可执行。普通Story Save仍按格式、能力和指纹独立校验。升级前请保留完整工程和旧记录。

Studio仍为默认；Studio、Manuscript、Technical、Focus、Ledger五种结构，以及十组十七个实际明暗配色成员完整保留，继续使用个人设置、预览、应用和取消。新建作品仍为空白骨架。发行包排除独立样例工程、规范样例与演示HTML，保留产品模板及必要回归输入。

资料模板保持输入焦点时，后台问题检查触发重绘可能造成界面停住的问题已修复；草稿与取消保护仍按原规则保留。
