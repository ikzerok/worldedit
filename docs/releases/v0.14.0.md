# worldedit 0.14.0

本版把稿件范围、真实运行证据和既有语言能力连接为明确、可撤销的作者操作。

## 更新

- 开始试玩、重新开始和严格重放明确使用已应用工程稿。相关未应用输入按来源列出，作者可返回处理、取消或明确运行已应用稿；不会自动应用、保存或丢弃草稿。确认时再次检查真实快照和输入内容
- 试玩、调试器和条件证据统一接入暗色、亮色与系统主题语义色；保留警告、错误和禁用原因的文字
- choice 条件、enable、once、规则定义与错误/未求值证据可定位经 core 验证的声明头。来源过期或存在未应用改稿时安全拒绝；可沿作者历史返回，不再次求值或消费随机数
- 新建与现有作品可显式启用已有1.9—1.13语言与资料能力。core 提供具体 required_features、全文候选诊断、关键字解释变化和实际存档兼容影响；确认仅提交内存事务，可撤销，保存仍由作者决定

## 兼容

默认语言仍为1.9，最高1.13；没有新DSL，旧作品不自动升级。未知能力/格式按原始字节只读保留，受支持清单中的扩展字段保留。能力升级可能改变运行指纹：普通存档继续执行能力及指纹检查，运行检查点/轨迹仍受版本与指纹约束；入口轨迹须重新严格验证，不能保证沿用。证据来源是可选DTO扩展，默认解释输出维持既有形状。

完整作者使用与边界见 docs/explicit-authoring-0.14.md；事实、相信、所知和携带的组合示例见 worldline/docs/explicit-capabilities.md。

Windows、Web和双仓源码包的精确配对提交与CI链接见 release-pair.json；下载后核对 SHA256SUMS.txt。各平台实际验证边界通过独立版本更新报告说明。
