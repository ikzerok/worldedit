# 0.34.0 正式对白与同稿角色台本

本说明对应 worldedit 0.34.0 与配对 worldline/core/runtime 0.34.0。发行状态、精确配对提交及附件以 v0.34.0 Release 和 release-pair.json 的实际记录为准。

## 连续创作

正式角色、台词与演出备注在同一正文来源内编辑。文字、表达式和强链接使用 core typed parts；Enter 在本句换行，下一句是明确独立动作，组合输入不触发提交。正文、源码和对白共用按文件唯一 WritingBuffer，输入、纳入草稿、Project 应用、磁盘保存分层显示。

默认保留普通正文直接输入，不因文稿含 Say 自动接管。明确打开“逐句对白”，或选择插入与续句，进入同稿的 Text/Say 完整编辑界面；普通 Text 同样可预览、纳入、应用与撤销。取消勾选返回原正文，未纳入的字段继续保留，原文光标仅在来源身份仍匹配时恢复。

普通 Text 与正式 Say 的转换只接受 core 确认的单语句。glue/opaque tags 等不可无损转换的情况明确拒绝；Say 转旁白有备注损失时先预览并由作者明确确认。既有稳定本地化 ID 保留，kind 改变按既有规则将旧译文标为过期。

默认语言仍为 1.9。旧作品需要 Say 时先显式预览启用已有 1.11，展示关键字重分类、诊断、指纹及完整变更；语言清单与完整当前稿在同一事务应用、一次撤销，不自动升级或保存。最高既有版本仍为 1.13，不新增 DSL。

详见 [编辑器完整操作](https://github.com/ikzerok/worldedit/blob/main/docs/dialogue-production-workbench.md)、[正式对白契约](https://github.com/ikzerok/worldline/blob/main/spec/dialogue-authoring.md) 与 [作者用法](https://github.com/ikzerok/worldline/blob/main/docs/dialogue-authoring.md)。

## 同稿角色制作台本

当前目标、同一书稿的选中章节或工程活动定义可按正式 speaker 与 locale 生成不可变台本。角色不是章节 POV、参与者、文本提及或普通冒号前缀。结果来自当前稿，完整过滤后分页，按真实来源去重；重复章节出现、定义和静态调用点分别计数。

默认明确纳入所选范围的共享片段定义，以静态调用闭包收集，每个定义一次。关闭后材料标明直接范围，不能把省略片段的材料称为完整角色台本。表达式、条件、选择和调用均未执行，不展开路径树，不求值参数或 RNG，不推断实际发生次数。

指定 locale 的严格交付只要求所选最终单元完整翻译；未知语言、坏 sidecar、重复稳定 ID 等全局完整性错误仍阻断。缺译、过期和无效逐项可查；源文回退必须明确选择并标记。角色显示名与演出备注属于源语言作者元数据。

详见 [制作台本契约](https://github.com/ikzerok/worldline/blob/main/spec/production-script.md) 与 [制作台本用法](https://github.com/ikzerok/worldline/blob/main/docs/production-script.md)。

## 私密材料与机器入口

JSON、Markdown、CSV 和复制预览来自同一个 core 结果。默认不包含演出备注，也不通过原始 say 行、excerpt 或隐藏字段泄漏备注。作者显式选择后才纳入所选备注；没有自动向第三方发送步骤，不扩大 reader profile 白名单。

JSON 保存所选交付字段的精确值。CSV 每个字段增加一个单引号显示前缀，再统一双引号包裹并转义，使用 UTF-8/CRLF；输出字节不同于源值，不是无损回导，不保证所有表格软件或再次另存后的通用安全。Markdown 对作者内容转义，不生成执行脚本或外部链接。

原生只向工作区外全新目标文件写入，发布前重验，不覆盖已有目标；取消、过期或失败清理暂存。WASM 请求下载相同字节，不能声称已保存至用户磁盘。CLI/RPC 使用同一 typed query/preview/apply/export；默认 apply 只改本进程内存，保存另行明确执行。

详见 [机器接口](https://github.com/ikzerok/worldline/blob/main/spec/dialogue-machine.md)。原有全分支审稿、本地化工作台、真实 runtime、地图/世界资料和发布能力继续保留。

## 界面与兼容

Studio 继续默认；五种布局、十组十七套配色与三种密度保留。对白沿用连续文稿的正文层级，控制边界和角色身份按需展开，不另建第二份台词项目。

原生窗口标题显示版本、已打开工程的短名称与稳定短标识，便于辨认同名目录。未打开工程有明确标记，切换与重开跟随实际工程位置更新，标题不展示绝对路径。

runtime 0.34 的 ReplayTrace / ReplayCheckpoint 仍精确匹配版本：0.33 及更早运行记录需要重新录制。只读打开旧 JSON 不代表可以执行。普通 Story Save 沿用格式、能力与语义指纹守卫；locale 记录另需匹配展示身份。

发行包不附带样例工程、规范演示或独立 demo HTML，新工程仍为空白。规则/片段签名编辑、录音管理、云协作和可执行公开网站不属于本批范围。
