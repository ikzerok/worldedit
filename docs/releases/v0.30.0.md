# worldedit / worldline 0.30.0

本轮重做同一套 Rust/egui 作者工作台的视觉，并补齐从空白作品起笔与一致对象检索。默认语言 1.9、最高既有显式版本 1.13 保持，不引入新 DSL，也不自动升级作品。本文记录 0.30 的功能、已完成本地验证与未测边界，公开发行状态以对应 GitHub Release 为准。

## 新的作者工作台

- [设备外观](../appearance-0.30.md)提供五种独立结构：Studio 编辑台、Manuscript 稿纸、Technical 工具台、Focus 专注、Ledger 档案。Studio 为默认；原版皮肤不作为可选主题保留
- 雾松、梅墨、纸铜、海盐、石墨、樱花和印刷黑白各有浅色与深色；终端绿、霓虹夜景仅深色，羊皮墨仅浅色，合计十组十七套基础配色。结构、配色、三档密度独立组合；可选受控强调色、比例/等宽正文、正文与源码字号、行距、阅读宽度、80–200%界面缩放、高对比与减少动态
- 系统/浅色/深色是保留的个人明暗偏好。固定模式配色明确显示其实际模式，不覆盖此偏好；例如选中终端绿时始终深色，切回雾松后继续使用原先的跟随系统或指定明暗。风格化配色不附加闪烁、辉光或另一套字体布局
- 设置先在整个工作台预览。应用提交并留在窗口；确定提交并关闭；取消、Esc、标题栏 X 撤回最近一次应用后的改动。恢复默认也只是可取消的外观预览，不重置作品、作者位置或个人布局
- [统一工作台](../workbench-shell-0.30.md)保留全部工作区与创作功能。Focus 用导航/文件和参考抽屉保留单一主要内容区，导航快捷键是 Ctrl/Cmd+Shift+E；Ledger 在窄窗口把侧题签移到正文上方。临时收起不覆盖原导航宽度、参考停靠与固定对象选择
- 旧设备设置在原存储键迁移到 schema 2：保留明确明暗意图、合法阅读值、原布局和位置，切换为新视觉。未来 schema 或无法完整读取的设置保留原字节并显示保护提示；这类会话的个人设置不写回，作品保存仍可独立使用

Web 与桌面绘制同一个 WorldeditApp。Web CSS 只控制画布外加载状态与背景；作品导出的读者页不是设备外观的持久化容器。

## 从空白作品开始写作

[开始写作](../start-writing-0.30.md)把书名与章名放在前面，作者明确选择复用正式来源或新建空事件。core 原子计划同时核对书稿注册、编排、源码、入口引用、工作区库存与保存基线；界面展示将改动的文件、入口与运行指纹影响，再明确创建。

- 成功后直接进入该章节的正文，仍使用同一份 WritingBuffer。空正文插入槽由 core 提供，空格、前导空行、中文与换行不会让 UI 自行生成另一种语言语义
- 书稿编排只决定阅读顺序；新建来源不会替作者接入现有执行路线。复用已有来源保持入口和运行指纹，新建事件可能改变指纹，预览会明确说明
- 创建进入工程缓冲，可一次撤销；正文草稿另行应用，保存全部才写入磁盘。取消、返回、重复操作、外部变化与其他未提交表单都保留原输入
- 未能插入的输入按来源路径、完整对象身份与位置分别保留，另一章成功不能覆盖它。撤销新章后仍有未应用源稿时提供恢复入口
- 试玩范围会明确列出未应用的新事件意图与保留正文；纯书稿排序或引用既有来源不被误当作新的执行内容。旧确认必须重新核对完整输入签名

## 一致的对象检索

所有对象候选由 core 的筛选分页接口提供，UI 不再裁剪 Catalog 后自行检索。名称、ID、类型、别名和按需开启的源码路径检索使用同一规则；允许类型及实体类型筛选保留完整身份，按总目录预算失败时明确反馈。

快速命令、通用选择器、模板类型引用、事件插链、源码 @、当前稿对象检索及资料索引保持相同分页和真实来源。当前稿解析失败时明确使用已应用目录；过期结果和失效来源不能悄悄跳转。查询、翻页或来源更新会取消旧候选确认，鼠标按下到松开之间发生更新也不能选中替换后的对象。

机器入口同步提供 `manuscript.chapter.preview/apply`、`world.objects.search` 与 CLI `manuscript-chapter`、`object-search`，复用同一 core。预览不写盘；CLI 应用只有显式 `--save` 才保存，保存失败会区分已应用与未保存状态。

## 升级、分发与边界

- ReplayTrace / ReplayCheckpoint 继续精确核对 runtime_version。0.29 及更早轨迹/运行检查点在 0.30 不能重放、比较或生成已验证审阅，应重新录制，即使作品指纹未变。合法旧轨迹可只读查看，读取成功不代表能够执行
- 普通 Story Save 沿用格式、能力、指纹与状态约束，不因本次仅更换外观而宣称必须失效；改变可执行内容仍会触发现有守卫
- 新建作品只有可直接结束的空白骨架。应用和源码发行包不附独立样例工程、规范演示文件或视觉演示 HTML；必要最小测试、产品字段模板和既有历史产品证据保留
- 个人外观不改变项目 dirty、内容指纹或导出作品；地图中作者自己设定的图形与文字颜色仍是作品数据，不随编辑器主题重写。浏览器仍是导入快照，不监视磁盘，也不提供云端共同编辑
- Linux 模拟输入、headless egui、Node/WASM 与编译各自记录；不把它们写成物理输入法、读屏、Windows/macOS GUI 或真实浏览器 Worker 宿主验收

### 最终配对与发行要求
