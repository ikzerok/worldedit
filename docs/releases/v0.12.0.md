# worldedit v0.12.0：可信重放与时间约束编辑

本版将重放判定、事件时间表单和完整作者练习一起交付。产品版本为 0.12.0；最高语言仍为显式 1.13，既有工程默认语言仍为 1.9，没有新增 DSL。

## 重放只比较实际语义

片段调用帧的源码文件和行号属于定位信息。插入空行、复制同一作品目录或合法移动共享片段后，运行指纹与叙事行为未变时，不再仅因位置变化报告分歧。原始轨迹和当前源码定位仍保留。

只排除已定义的调用帧顶层 `file` / `line`，不会忽略调用层级、片段身份、调用者、语句位置、参数、局部值、状态、随机数、输出或菜单变化。调试轨迹与检查点仍严格匹配 runtime/schema 版本；0.11 轨迹不会隐式升级为 0.12。已兼容版本的旧 JSON 可选字段形状继续读取。普通 Story 存档沿用自己的读取与运行指纹规则，不与调试轨迹的精确版本绑定混为一谈；不兼容存档继续拒绝。

## 前驱表单与世界时间线一致

事件检查器使用 core 提供的合法范围与拒绝原因：语言 1.9–1.12 仍限定同一直接时段；显式 1.13 可在同一明确时间根内选择跨时段前驱。已选关系始终可见，切换所属时段不会静默清空已有约束。

不合法的已选前驱留在表单中并说明原因，须明确取消或恢复合法时段后再应用。自身、时间环、独立时间根、已有后继受影响等情况均交完整工程校验。只读、不完整分析、过期草稿和工作区越界继续拒绝写入并保留输入。候选提供身份、时段、根与来源，可筛选滚动；应用与取消保持可达。

## 从资料写到可验证故事

新增“栖雪山站”最小正式示例和作者路线，串起世界资料与来源、强引用、世界偏序与独立叙事顺序、双路线后果、共享片段、存档与重放，以及跨文件改稿和保稿步骤。

应用更改仅更新工程缓冲，保存工程才写入磁盘。批注锚定、未应用输入、外部变更冲突、撤销重做及恢复保护保持既有边界；本版不增加全局事件或文件安全改名、完整历法、协作服务或新的叙事排序体系。

## 下载与校验

发行包含 Windows 程序、Web 包、两仓源码、`release-pair.json` 与 `SHA256SUMS.txt` 共六项资产。使用配对记录中的精确双仓提交；下载后核对 SHA256。平台构建、完整自动门禁及本版 Linux 原生 AI 模拟验收的实际范围在独立版本更新报告中说明，不将未实测平台、输入法或读屏能力称为通过。
