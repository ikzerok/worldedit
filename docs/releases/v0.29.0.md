# worldedit / worldline 0.29.0

本版完善资料强引用查询、地图对象检索、可信路径交换、可释放试玩会话与发布前公开页审阅。工具版本为 0.29.0；默认语言 1.9、最高显式语言 1.13 保持，不新增 DSL，也不自动升级作品。

## 五项作者工作流

1. [资料组合查询](https://github.com/ikzerok/worldedit/blob/v0.29.0/docs/catalog-views.md)显式支持 query v3 的强引用等值，按完整 kind/ID 匹配；普通字符串、空字符串、单空格、未填属性、0 和 false 分开处理。v1/v2 保持原规则，保存查询保留扩展字段，未知能力和过期草稿不覆盖已有定义。
2. [地图对象查找](https://github.com/ikzerok/worldedit/blob/v0.29.0/docs/maps.md)共用 core 分页检索，支持名称、ID、类型和别名。反查每页20条、绑定每页8条，显示完整总数、身份和来源。临时绑定在查询或快照变化后要求重新确认；取消不会留下可复活的创建重试。既有未解析矢量引用保持完整身份，未改引用的合法名称/几何编辑仍由 core 校验。
3. [路径交换](https://github.com/ikzerok/worldedit/blob/v0.29.0/docs/replay-exchange.md)使用 runtime 的紧凑 JSON，按实际 UTF-8 字节限制为4 MiB、20,000步，并拒绝重复键。录制、导出和重新导入遵守同一边界；失败不清掉已有记录或推进 live Story。CLI 显式 `--trace-exchange` 保护已有目标；原 `--trace-output` 的 pretty 输出和覆盖行为继续保留。
4. [拥有型试玩会话](https://github.com/ikzerok/worldline/blob/f22f3b5b4bb5f78843515b43204bfd8adc210b46/spec/owned-story.md)持有程序与分析快照，重启或关闭时释放旧会话；原借用 API、随机流、片段、once、状态、检查点和有界执行语义保留。查看、交换和回源不会替作者推进故事。
5. [公开页目录](https://github.com/ikzerok/worldedit/blob/v0.29.0/docs/reader-page-directory.md)位于发布前审阅窗口，只搜索已验证公开投影的标题、正文和相对路径。结果每页至多12项，支持键盘候选、明确打开和返回，保留查询与页码；同名页面按输出路径区分。原上一页/下一页仍按全部公开页顺序浏览，新的预览或过期来源清除旧目录。

## 无样例分发与兼容

新建作品只生成可直接试玩至结束的空白 `world.wl`。Windows、Web 和双仓源码发行归档不分发 worldline 根 `examples/`、`spec/examples/` 或独立视觉演示 HTML。字段模板位于 `spec/templates.catalog.json`；必要回归夹具、已有产品视觉验收资料及默认关闭的开发原型代码继续保留。没有新增截图、原始运行日志、竞品调研或独立样例工程进入本次代码变更。

源码附件由对应提交的 `git archive` 和 `.gitattributes export-ignore` 生成；配对源码解压后仍可构建和测试。核对源码对应关系时比较完整文件集合和每个文件字节，并检查 ZIP 的提交标记；不同平台的压缩字节不作为源码相等的唯一依据。历史演示链接需完整 Git 检出，已有历史产品证据不代表本轮验收。

ReplayTrace / ReplayCheckpoint 继续要求精确 `runtime_version`：旧轨迹可只读查看不代表能在0.29执行，跨版本重放、比较和已验证审阅需要重新录制。普通 Story Save 按格式、能力和指纹独立校验。路径原始记录可能包含作者正文与状态，不等于已获得读者发布授权；读者白名单、字段/附件选择及最后确认保持。

## 实际验证

从已排除样例的双仓源码归档执行：

- core：1488通过、0失败、8忽略
- worldedit 默认：922通过、0失败、7忽略；开发原型：937通过、0失败、8忽略
- fmt、Rust文件600行检查、native/WASM严格 clippy、双原生 release 和双 Trunk 构建通过
- 发行脚本83项、配对脚本9项通过；Python以 UTF-8 和警告视为错误运行
- 新编译的 CLI/RPC 实进程矩阵45场景、148条显式断言通过，包含44次CLI调用与45条持久RPC请求；不是将历史295条验收记录重新计数
- Linux 原生实际完成空白新建/保存/关闭重开/试玩、中英正文保存重开、强引用与空值查询、地图完整分页与临时绑定保护、公开目录搜索/末页/返回，以及路径导出再导入、重复键拒绝和旧runtime执行保护
- 原生运行时与真实编译的 Node/WASM 生命周期探针分别完成1000个合成角色记录上的重启、切换、关闭、检查点、取消、错误和语义一致性检查；其内存观察属于独立运行时进程/WASM线性内存，不是编辑器GUI RSS
- 两份实际 Web 构建在 Node 中初始化，完成Unicode CSV工作入口及5类无效协议输入拒绝检查

Linux操作使用 CUA 鼠标/键盘与原生剪贴板，未验证物理IME、读屏、Windows/macOS真实GUI、HiDPI或实际浏览器Worker宿主。本机目录选择器未出现，因此不把显式路径启动和关闭重开冒称同进程工作区切换验收。Windows精确提交CI和正式制品的门禁、构建、打包烟测由既有发行工作流记录；双仓完整SHA与实际main CI见发行配对清单。
