# worldedit / worldline 0.29.0（开发中）

本版统一完善资料强引用查询、地图对象检索、可信路径交换、可释放试玩会话与读者公开页审阅。当前文件记录开发范围，尚未完成全部验证，不能视为正式发行或完成报告。

## 五项作者工作流

1. 资料组合查询显式启用强引用等值；空文本、未填属性和空格保持不同含义。旧查询版本与只读保护不变
2. 地图反查与对象绑定共用core分页检索，包含既有名称/ID/类型与别名；显示完整身份、总数和后续结果
3. [路径交换](https://github.com/ikzerok/worldline/blob/main/spec/replay-exchange.md)按实际UTF-8字节计量，严格拒绝重复键；导出与导入闭合，旧runtime可读取不代表可重放
4. [拥有型试玩会话](https://github.com/ikzerok/worldline/blob/main/spec/owned-story.md)安全保活并释放其程序与分析快照；保留原借用API和故事执行语义
5. [公开页目录](https://github.com/ikzerok/worldedit/blob/main/docs/reader-page-directory.md)只查已有公开投影，支持分页、直接定位与返回，不增加公开授权

## 兼容与保护

工具版本0.29.0，不新增DSL。默认语言1.9、最高显式1.13保持。查询的新增能力只在作者显式使用后进入文档，旧格式不暗升。路径交换、报告/比较业务预算、运行版本守卫是独立边界；不将读取成功当作实际重放成功。完整工程备份、读者白名单与作者路径含私密数据的边界保持。

## 验证状态

实现、完整Linux测试、原生交互、native/WASM构建、精确Windows CI、配对和公开资产检查均待本轮完成后填写。已有版本的通过结果不能代替本版验收。Linux合成输入、Node/WASM检查不代表物理IME、读屏、Windows/macOS真实GUI或HiDPI已验证。
