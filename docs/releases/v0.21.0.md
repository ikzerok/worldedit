# 0.21：世界资料批量导入与修订

本版把人物与实体资料表接入现有语言真源：明确映射每一列，先看整批字段差异和存档影响，再一次应用、撤销或保存。后续修订按稳定身份更新原对象，不按显示名猜匹配，也不整块重写已有设定。

工具版本统一为 0.21.0。默认语言仍为 1.9，最高既有显式语言仍为 1.13；没有新增 DSL。最终双仓完整 SHA、精确 main CI 与资产校验以本次 `release-pair.json` 和 `SHA256SUMS.txt` 为准。文档合入不等于已公开发行。

## 语言 core 与机器接口

- `core::catalog_import` 统一处理 CSV、列映射、类型、差异与事务，编辑器不另写 CSV 或语言语义解析器
- 身份仅由 `kind + id` 决定；支持 `character`、`entity`，同名不合并，同 ID 不同 kind 仍是不同对象；重复完整身份阻断整批
- 可映射 `display`、实体的 `entity_type` / `description`，以及明确类型的 text、number、bool、ref 属性；每列必须明确映射或 Ignore，不猜表头、类型或空值
- 正式 lexer 的字段字节补丁保留未映射属性、关系、注释与源码布局；语义未变时不重写字节。新对象写入选定的既有活动 `.wl`，更新对象留在原声明文件
- 完整候选统一编译与 schema 校验，同批前向、循环及自引用遵守既有语言规则。错误不允许前面有效行先应用
- 预览绑定 CSV 快照、映射、空值策略、目标、工作区身份、内容基线、全部差异及真实运行指纹；应用重新规划并复核摘要、磁盘、源码库存、链接与恢复事务
- 一批只形成一次内存事务和一条撤销记录；无变化不置脏、不增加历史、不重排原文

CLI 使用 `wl catalog-import preview|apply PROJECT --request-json DTO [--csv FILE] --json`。apply 另需 `--plan-digest DIGEST`；只有显式 `--save` 才落盘，不加时返回 `saved:false` 并说明进程退出后内存候选会丢弃。

RPC 提供 `catalog.import.preview`、`catalog.import.apply` 和显式 `project.save`，初始化能力为 `catalog_import_v1`，协议版本仍为 1。本功能 JSON 拒绝重复键、未知字段、未知枚举及版本，保留完整 u64 指纹精度。

解析、规划或内存应用拒绝时不产生部分修改。保存仍走既有可恢复 journal，不承诺跨文件磁盘物理原子；保存失败明确区分 `applied:true`、`stage:save`、`saved:false`，保留缓冲并说明可能存在待恢复事务，不假称磁盘零写入。

## 编辑器完整操作

1. 从工程菜单、世界资料区或任务命令打开「世界资料导入」
2. 读取 UTF-8 CSV 快照，为每列明确映射或忽略，并选择新增对象的既有源码位置
3. 刷新预览，逐行核对新增、更新、无变化、阻断及真实字段前后值；批次详情列出忽略列、修改来源、换行规范化与运行指纹
4. 审阅存档影响后明确勾选确认，再一次应用整批。应用只改当前 Project 内存
5. 可查看资料或回到来源；一次撤销或重做处理全批，「保存全部」才持久化
6. 同一快照和映射再次预览应无变化，不重复新建或增加历史

导入快照不持续监视原 CSV，原文件变化需明确重新读取。替换已有快照先确认，取消保留原输入。切页、Esc、查看资料和回源保留映射；未应用作者输入、关闭或切换工程继续受现有草稿保护。导入任务不随工程保存自动持久化。

后台预览可取消，取消或过期结果不会采用；原生不可抢占的检查阶段可能先运行到结束。最终应用同步复核，可能短暂停顿。源码、映射、目标或基线变化使旧确认失效，不自动重跑或应用。

桌面保留系统文件选择器，并提供可见的「按完整文件路径读取 CSV（备用）」入口。两者共用 2 MiB 有界只读流程，只读明确选中的普通文件；拒绝目录、链接和设备。不存在、权限、大小或编码错误保留输入和旧快照，不扫描目录寻找替代文件，路径不写入个人持久设置或作品。

Ignore 只表示不写入语言字段，不代表脱敏或删除原 CSV。若 CSV 本在作品目录，既有完整备份仍按原规则保留该普通文件及其全部列。

## 排版与交互

批量映射和审阅放在主工作区，固定主操作区，列表与完整字段详情独立滚动。修复真实 Linux 原生验收发现的右侧详情越过页脚问题；按实际剩余空间限制视口，不靠缩小字体或截短字段掩盖内容。

键盘新焦点滚入可见区域，持续焦点不抢走作者滚动；合成 IME 事件及组合输入期间不能确认应用。主题与已有字体、间距保持一致。

执行图访问次数从固定浅绿色改为主题 SUCCESS 色，保留「访问 ×N」文字。悬浮说明用不随画布缩放的字号保留完整计数。绘制回归按实际卡片与阴影颜色合成，亮暗、选中、悬浮和搜索淡出组合均断言至少 4.5:1；这是绘制指令与相对亮度计算，不是实际像素采样或整产品无障碍认证。

## 输入和兼容边界

- CSV：2 MiB、500 数据行、64 列、单个解码字段 64 KiB；允许起始 BOM、LF/CRLF、带引号的逗号与换行及双写引号。引号内 CRLF 规范化为 LF 并明示；孤立 CR、重复或空表头、错列数、非法引号和非 UTF-8 阻断
- 映射：最多 64 项，property key 最多 256 UTF-8 bytes，destination 最多 1024 UTF-8 bytes；在工程扫描和候选展开前拒绝超限
- 完整预览：4 MiB；错误详情最多 100 条，但所有独立错误都计入总数并阻断。结构已损坏时不假称解析了后续行
- 空值：默认 Error；Keep 跳过并保留旧值；EmptyText 仅允许的文本字段设空串。空格不 trim，0、false、null 或波浪号字样不是删除哨兵
- Number：有限 JSON 十进制 f64，整数限安全整数范围，拒绝非零十进制下溢为零；不保证所有小数可十进制精确表示。Bool 只接受 true / false；Ref 明确目标 kind，单元格填目标 ID
- CLI 只读加载完整工程最多 4096 个普通作者文件、合计 64 MiB，含附件与未登记文件；内部事务与检查点另按既有规则处理。待恢复事务不会为预览自动恢复

缺少既有语言或资料能力时，进入显式启用流程后重新预览；导入不会自行升级清单。人物显示名及部分非引用属性会改变 runtime fingerprint，旧 Story Save / checkpoint 可能不兼容；预览展示真实前后值，导入不迁移旧存档或降低严格重放守卫。

本轮真实 0.20 普通 Story Save 在未改作品上的已结束状态可由 0.21 恢复，变量、访问和选择覆盖保持；这不代表中途续玩或所有跨版存档已验。真实 0.20 trace 在 0.21 被 runtime_version 守卫拒绝，未执行或迁移。

不包含 CSV 导出、工作簿/TSV、持续同步、其他对象种类批量维护、schema 定义或绑定写入、属性/对象删除、稳定 ID 改名、声明移动或附件批量处理。

## 验收与性能口径

最终产品代码通过本地官方 19 项配对门禁，含普通与 prototype 的 native/WASM 构建及严格 Clippy。Linux core workspace 1215 通过、8 忽略；editor 普通 721/7，prototype 736/8。最终 pin 的 Windows CI 中 core 全量 1212/8、editor 普通 720/7、prototype 735/8；各配置及 focused 回归互有重叠，不相加。

独立 CLI 99 项与实际产品 Worker 的 Node/WASM 74 项通过，覆盖严格 DTO、CSV 边界、陈旧请求、全量诊断、同批引用、字节保真及 u64 精度。Node/WASM 不是实际浏览器：没有声称验证同源加载、真实 postMessage transfer 或浏览器 WorkerHost。

Linux 原生在 1188×848 完成正式路径读取、不存在文件错误、重复加载取消、5 列键盘映射、预览、内存应用、一次撤销/重做、保存、无变化重导入、回源及停止后重开。系统 picker、原生完整长字段滚轮操作、正常窗口关闭草稿提示未完成同层实测；后两类相应逻辑有合成 egui / 生命周期回归。真实浏览器、Windows/macOS GUI、物理 IME、读屏和高 DPI 不在已验范围内。

Linux 本机单次 release CLI：500 条既有人物、约 2 MiB 原稿，仅改 age 并保留每条 4 KiB note，preview 0.114s，apply + save 0.160s；500 新建为 0.013s / 0.019s。计时含进程启动、只读加载和复核，不是 GUI 帧时间、统计基准或跨产品排名。
