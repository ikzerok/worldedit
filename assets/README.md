# worldedit 图标

图标采用青蓝色螺旋分支，背景为不透明的深石墨蓝。

上升螺旋表示世界线，多层分支与交织表示故事的分化与关联，圆形端点表示事件。背景与深色 GUI 配套，无金属材质或立体底座。

- `worldedit-icon-master.png`：最终带背景的原始设计，1254 × 1254。
- `worldedit-icon.png`：256 × 256，嵌入编辑器窗口。
- `worldedit.ico`：Windows 图标包，包含 16、24、32、48、64、128、256 像素尺寸，可用于快捷方式与发行打包。

PNG 和 ICO 均由同一原图缩放导出，七个尺寸均检查为完全不透明。图标使用时保持比例，避免裁切事件节点。当前窗口图标已接入；ICO 可用于快捷方式与发行打包，尚未嵌入 Windows 可执行文件资源。
